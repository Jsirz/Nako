# MiniMax H3 提示词作业手册

本参考基于 MiniMax H3 官方飞书使用手册整理。源文档：<https://vrfi1sk8a0.feishu.cn/wiki/FIWjwgL33ipnkekzk30crmKUnIh>。它用于提示词创作决策，不替代实时 API 文档。

## 1. 生成边界

- 输出时长：4–15 秒。
- 输出帧率：24 FPS。
- 常用画幅：21:9、16:9、4:3、1:1、3:4、9:16。
- 首/尾帧入口：输入 0、1 或 2 张图片；无图时属于文生视频。
- 全能参考入口：最多 9 张图片、3 段视频、3 段音频；混合输入总数不超过 12 个文件。
- 参考视频与音频单段 2–15 秒，总时长不超过 15 秒。
- 音频不能单独作为输入，必须同时提供图片或视频。
- H3 原生生成声音。若用户不要某类声音，要在声音设计中明确处理。

除非用户询问技术规格，不必把这些参数全部写进最终提示词；只保留影响生成的时长、画幅和素材关系。

## 2. 三段式提示词

### 参考素材说明

逐一说明编号、用途和必须保持的特征：

```text
@图片1：女主角形象参考，锁定脸型、短发、黑色风衣和身材比例。
@图片2：场景、构图和冷蓝色夜景光线参考。
@视频1：只参考动作轨迹和节奏，不参考其中人物外貌与背景。
@音频1：音色与情绪参考；台词原文为“……”。
```

可用职责包括：人物、物体、场景、首帧、尾帧、连续关键帧、故事板、风格、构图、动作、运镜、剪辑节奏、音色、音频复用、局部音频复用和待编辑原视频。

素材包含多个角色时，用“左侧红衣女子”“戴眼镜的男人”等稳定称谓区分。一个素材承担多个职责时明确列出，但不要无理由让多个素材同时控制同一维度。

### 核心创意

用一至两句话锁定：

```text
主体 + 地点 + 核心事件 + 题材/风格 + 总体镜头或剪辑方式
```

示例：

```text
一位穿汉服的年轻女子（@图片1）在樱花庭院（@图片2）舞剑，古典国风、电影质感，全程一镜到底。
```

对广告、MV、片头等内容，还应明确节奏、审美倾向和信息包装方式。避免仅堆叠风格词，要说明这些风格如何体现在光线、色彩、材质、剪辑或镜头上。

### 画面过程说明

切镜视频按 shot 或时间段编排：

```text
0–3秒：大全景；空间与主体位置；动作；运镜；声音。
3–8秒：切到中景；延续哪个角色；动作变化；台词；音效。
8–12秒：特写；高潮动作；慢动作或镜头运动；音乐变化。
```

每个镜头按需包含：

```text
景别 + 画面内容 + 运镜 + 动作 + 台词 + 音效
```

- 明确“切到谁的什么景别”，提高跨镜头一致性。
- 台词长度必须适配镜头时长。
- 台词跨镜头时，明确写“接着上一镜继续说”。
- 区分画内说话人、画外音和声源位置。
- 需要出现准确文字、标题、按钮、Logo 或台词时，写出原文。
- 一镜到底不要再按“镜头1/镜头2”切段，可按动作阶段写成一个连续过程。

## 3. 四种模式

### 纯文生视频

没有素材可以约束模型，应具体写出主体外观、场景细节、动作因果、风格和声音。优先使用：

```text
大全景交代空间 → 中景承载动作 → 特写强调细节
```

### 单图或首尾帧图生视频

- 单图：明确是首帧、尾帧还是普通视觉参考。
- 两张图：明确首帧和尾帧，并描述两帧之间应发生的动作、光影和声音变化。
- 首尾帧模式默认补间，不会自动设计复杂切镜；需要连续运动时明确“不切镜、自然衔接”。
- 相同首尾帧不保证无缝循环，不要承诺模型一定能闭环。

### 多模态参考生成

把素材职责拆开：图片常用于锁人物/场景/构图，视频常用于锁动作/运镜/剪辑，音频常用于锁音色/节奏/情绪。若只参考某个维度，明确写“只参考……，不参考……”。

### 视频编辑

先指明原视频，再写：

```text
修改目标 + 修改后的具体状态 + 与原动作/光影/透视的融合要求 + 必须保持不变的内容
```

示例：

```text
以@视频1为待编辑原视频。把画面中的猫替换为一只金毛犬，严格保持原猫的运动轨迹、接触关系和镜头节奏；金毛犬的毛发、阴影和环境反光与原场景一致。人物、背景、构图、时长和声音保持不变。
```

## 4. 镜头与剪辑

- 若需要默认切镜，写清普通硬切、叠化、卡点快切等类型。
- 若需要环绕效果，优先描述可执行运动组合，例如 `truck left + pan right` 或 `truck right + pan left`，并说明主体始终位于画面何处。
- 运镜参考要说明参考的是路径、速度、抖动、构图变化还是完整镜头语言。
- 风格参考应转译成可观察维度：色彩系统、材质、光线、颗粒、构图、转场和文字包装。
- 多角色动作要按先后顺序、空间位置和接触关系描述，避免只写“大家一起做动作”。

## 5. 声音

- 台词、环境音、动作音效和非叙事性音乐分开描述。
- 关键音效在对应动作镜头内写一次，再按事件顺序概括整体声音景观。
- 音乐使用事件关系控制：

  ```text
  开门前无音乐；门打开时低频音乐进入；人物离开画面后音乐完全停止。
  ```

- 音量用相对混音关系，不写百分比或 dB：

  ```text
  人声清晰居前，脚步声自然可辨，音乐低声铺底，不遮盖对白。
  ```

- 需要复刻人声、台词或歌词时，写出准确文本。
- 不需要非叙事性音乐时，可写 `非叙事性音乐：N/A`；仍需说明保留哪些环境音或动作音。

## 6. 最终模板

```text
【参考素材说明】
@图片1：……
@视频1：……
@音频1：……

【核心创意】
生成一支[时长]、[画幅]的视频。主体……，地点……，核心事件……。整体为……风格，采用……镜头/剪辑方式。

【画面过程】
0–X秒：……
X–Y秒：……
Y–Z秒：……

【声音设计】
对白……；环境音……；动作音效……；非叙事性音乐……。

【一致性与限制】
保持……一致。只修改……。不新增……。其余内容保持稳定。
```

省略不适用的段落。提示词应像一份紧凑的导演执行说明，而不是模型功能介绍。

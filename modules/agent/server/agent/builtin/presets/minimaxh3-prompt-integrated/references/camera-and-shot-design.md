# H3 分镜与运镜设计

用于剧本、文戏、动作、广告或用户明确要求镜头表的任务。目标是把分镜逻辑压缩成 H3 在 4–15 秒内能执行的画面过程；不照搬固定 30 秒模板，也不机械规定镜头数量。

## 先决定生成单位

- 每次生成 4–15 秒；普通复杂段优先 8–15 秒。一个片段可以有少量切镜，也可以一镜到底。
- 一段只承载一个主要事件或一次关系变化。对白、动作和运镜超载时，按完整动作落点、信息揭示、反应落点或视角改变拆成下一次生成。
- 预计切镜超过 3 次、主体超过 2 个或动作链超过 2 个连续阶段时，优先拆成多段；不要把 30 秒文戏压缩进单个 H3 片段。

## 镜头编排

1. 人物站位不是镜头，不占时长。它锁定画面左右、前后景、朝向、视线、道具初始状态和 180 度轴线。
2. 镜头1必须立即发生第一个有效动作、台词或环境事件，不能重复站位说明。
3. 先用稳定主机位建立关系，再在出现新信息、权力改变、距离/朝向改变、道具状态改变、声音触发行动或情绪改变动作路径时切镜。
4. 倾听反应、手部道具、过肩、侧后方和环境插入镜头都可以承载正在继续的台词；切到这些画面时用“角色名画外音继续”保持声音不断。
5. 空镜只承接已经启动的动作或声音后果，例如门的余震、滴水、手机震动；没有来源就不凭空添加动态。

每个镜头采用一行或两行的紧凑结构：

```text
镜头N｜时长：景别/机位；主体与空间关系；一个主动作或反应；可见表演信号；运镜；台词/画外音；环境音与动作音。
```

时间轴必须从本段 0 秒开始，到本段时长结束。每个镜头只保留一个主任务；眨眼、吞咽、单纯抬手或重复正反打不单独成镜。

## H3 可执行运镜

运镜写四件事：起始构图、路径/方向、速度节奏、结束构图。例：`中景固定在人物左侧，人物转身时摄影机缓慢向右横移，保持人物在画面右三分之一，停在门口背影的中近景`。

- 固定机位：适合对白、倾听和细微反应；明确景别和构图即可。
- 推近/拉远：只在信息揭示或情绪落点发生时使用，写清推到何种景别或拉出什么空间关系。
- 横移/跟拍：主体有明确横向或纵深移动时使用，写清跟随方向、速度和落点；保持空间轴线。
- 摇摄/抬升/俯拍：用于揭示新主体、空间尺度或视线关系，写清从什么看到什么，避免只写“镜头摇过去”。
- 环绕/旋转：仅在主体位置稳定且需要展示关系或空间时使用，写清环绕角度趋势和主体保持位置；不要与快速切镜、复杂动作同时堆叠。
- 手持/轻微抖动：只有纪实、慌乱或主观视角需要时使用，说明抖动幅度和叙事原因；不能用作万能电影感。

一个 4–15 秒片段默认只选一个主运镜。若必须有第二次运动，在可见动作或信息落点处触发，并写清前后构图。禁止同一时段同时要求推近、环绕、快速摇摄和跟焦等互相抢夺控制权的运动。

## 连续性检查

- 切镜保持 180 度轴线、人物左右、视线对象、动作方向和道具手位，除非写出可见换边过程。
- 运动结束的构图必须成为下一镜的起始状态；跨段时把它写入尾帧状态，并在下一段独立重述。
- 台词速度、动作阶段和镜头运动互相让位：关键对白时减少复杂运动，关键动作时减少额外表演和切镜。
- 明确“切镜”或“一镜到底”其一；不要在同一提示词中混写。

## 轻量交付建议

用户只要一个短提示词时，把以上信息压成“景别 + 主体 + 主动作 + 一次运镜 + 声音 + 结束姿态”，不输出完整镜头表。用户要分镜时，使用镜头编号和局部时间轴，并为每次 H3 生成单独交付。

# 长剧情拆段与跨段连续性

用于一段故事需要多次 H3 生成、剧本拆段或续接已生成片段。一次生成可含多个镜头；跨次生成的片段则需要各自完整的输入和状态交接。

## 划分生成片段

1. 提取必须保留的事件、对白、人物关系与先后因果，确定用户要求的总时长、画幅及现有素材。将允许补充的镜头表达与不可改写的剧情分清。
2. 按完整微事件、情绪变化或动作落点分段。每次生成按手册快照为 4–15 秒，默认优先 8–15 秒；只有单次容量无法承载、用户要求分段或创作结构需要时才拆分。复杂度可控时保留较长的完整段落，不为了统一时长机械切碎。
3. 估算对白自然说完所需时间，给停顿、反应、动作与转场留余量。不要用极速说话塞入超量对白。总时长与保留全部内容无法同时满足时，明确冲突并给出保留内容所需的可行时长；只有获准删改才压缩关键剧情或原台词。
4. 优先在动作完成、情绪落点、景别或视角改变、时空转换、主体交接处切段。避免在同一个尚未完成的构图、姿态、接触动作或情绪进程中间强行跨次生成。
5. 超长动作需要跨段时，找到自然停顿或反应切镜；若用户坚持连续长镜，说明多次生成不能保证无缝，提供首尾帧接续或后期衔接方案，不把有切镜的版本称作一镜到底。

## 跨段状态交接

整体设定记录可复用的连续性锚点：

- 人物：稳定称谓、脸、发型、服装与标志性配件。
- 空间：人物左右位置、朝向、视线对象、出入口、动作方向与轴线。
- 道具：由谁持有、哪只手持有、所在位置及变化后的状态。
- 画面：光线方向、时间、色彩和质感。
- 声音：每个角色的声线与情绪、持续环境音、音乐入出事件。

每段尾部说明结束时人物位置、姿态、道具状态、视线、声音及下一段的视觉切点。下一段起始状态必须承接这些变化，不能把移动过的角色、交出的道具、打开的门等恢复原状。

每段提示词都必须独立可复制：重述该段执行所需的人物与空间锚点，不只写“同上”“接上一段”。使用同一称谓与明确的引用职责；给出本次生成实际需要的上传列表和编号。编号变化时重新标明，不能假设 H3 自动继承上次上传的素材。

需要用上一段尾帧作参考时，将其写成生成完成后截取、待上传的资产，而非假装已经存在。说明它是首帧衔接还是构图参考，并确保当前段的素材组合符合所选入口限制。

尽量在完整语句或自然停顿处切分对白，保护说话人与台词归属；确需跨段时说明续接文字、语气及声音衔接，并提示可能需要后期接音。画内对白、画外音、环境音、动作音和配乐分别处理。

## 多段交付格式

先简述整体设定、总时长、片段数量及必要假设，然后逐段输出：

```text
第 N 段｜时长｜完整事件名称
素材对应与上传顺序：仅列该段实际素材或明确待上传的占位符

可直接使用的 H3 提示词：
参考素材说明 + 核心创意 + 画面过程 + 声音设计 + 必要一致性限制
时间轴从本段 0 秒开始，结束于本段时长。

尾帧状态：人物、空间、道具、情绪与声音的结果状态
下一段切点：可见的衔接元素、剪辑方式或待准备的尾帧素材
```

实际交付时每段主提示词各用一个代码块；说明与素材准备事项放在块外。最后一段给出结束状态即可，不机械添加下一段。用户要求只输出下一段时，利用已确认上下文续接，不重写全部前文；缺失的关键承接状态才需要澄清。

交付前核对事件、台词覆盖、时长总和、各段局部时间轴及跨段状态。不能用新反转或新台词替代用户给定内容。

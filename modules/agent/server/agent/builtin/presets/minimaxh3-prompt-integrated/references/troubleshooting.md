# MiniMax H3 提示词诊断与修正

本文件用于诊断生成失败或高波动需求。不要把这些现象描述成永久、绝对的模型缺陷；它们来自官方手册评论区与使用建议，版本更新后可能变化。

## 诊断顺序

1. 找矛盾：一镜到底与切镜、需要音乐与禁止 BGM、锁动作与要求完全改动作等。
2. 找缺失：素材未标职责、角色称谓不稳定、关键动作没有时间和空间关系。
3. 找超载：短镜头塞入过长台词、过多动作或多个风格系统。
4. 找不可观察要求：只写“高级”“震撼”“自然”，却未落实到画面和声音。
5. 找未锁定区域：编辑任务未说明哪些人物、背景、构图或声音必须保持不变。

## 异常对白或口型

同时使用正向行为约束和简短负向约束：

```text
人物全程保持安静，嘴巴自然闭合，没有说话或对话，面部只有轻微自然表情。
无对白、无人声、无念白、无口型变化、无自言自语。
```

并执行：

- 删除“交谈、讲述、对着镜头表达、激动表达、嘴唇微动”等触发说话的描述。
- 不需要台词时少用引号和台词格式。
- 给人物安排持续、明确的非说话动作，如观察、阅读、转身或行走。
- 特写仍不稳定时，改成侧脸、背影或中远景。
- 若只是不需要声音，可关闭音频生成或后期静音；画面已有异常口型时通常需要重生成。

## 字幕或错误文字

字幕控制可能波动，不能承诺彻底禁止。可尝试：

- 不主动加入对白、歌词、引号或文字包装要求。
- 写“画面中不出现任何可读文字、标题、字幕或标识”，但说明这只是约束，不是保证。
- 若必须出现文字，逐字给出原文，并限制出现次数与位置。
- 对交付级项目预留后期清除或重生成方案。

## 人物或物体不一致

- 提供清晰参考图并明确“人物参考”。
- 列出必须锁定的脸型、发型、服装轮廓、体型和标志性配件。
- 跨镜头始终使用同一称谓，并在切镜时指明“同一角色”。
- 动作参考只锁动作时明确排除原视频人物外貌和背景。
- 编辑时写清运动轨迹、遮挡、接触、光影、透视和未编辑区域。
- 减少同一镜头内的角色数量和同时发生的复杂动作。

## 音乐、音效时序不准

- 音效在对应动作旁写一次，再在整体声音说明中按事件顺序复述。
- 音乐不用孤立秒数控制，改成“事件前无音乐—事件发生时进入—事件后停止”。
- 音量用前后层级和遮盖关系，不用百分比或 dB。
- 不要同时要求“保留参考音乐”和“无背景音乐”。

## 循环视频

相同首尾帧不保证无缝循环。提示词应明确：

```text
最后一帧必须在主体位置、姿态、镜头位置、光线和背景运动上自然回到首帧状态；结尾动作速度与开头衔接，不使用淡出或黑场。
```

仍需向用户说明可能需要多次生成或后期处理。

## 重写输出

诊断时保持简洁：先列“主要问题”和“修改策略”，再给出单个完整的重写版 H3 提示词。问题只列最影响结果的 1–3 项，不要把所有可能故障都堆给用户。

## 模板1：身份互换型 —— 《一觉醒来变首富》

### 基本信息
| 项目 | 内容 |
|------|------|
| 题材 | 现代都市 / 身份错位 / 爽感逆袭 |
| 风格 | 荒诞喜剧+爽感反转 |
| 预计时长 | 90秒 |
| 情绪基调 | 困惑→震惊→狂喜→危机 |

### 核心卖点
穷到极致的打工人一觉醒来发现自己成了全城首富，住在豪宅里，但原主人的 enemies 已经找上门。极致的身份反差+即时危机，让观众瞬间代入"一夜暴富却要保命"的荒诞爽感。

### 开场Highlight Shot（0-3秒）
> 特写：一双破帆布鞋踩在价值百万的羊毛地毯上。镜头急速上摇——一个穿着起球卫衣、头发乱成鸡窝的年轻人，目瞪口呆地望着周围如宫殿般的客厅。

### 分场剧本

**《一觉醒来变首富》**
**第一集**

**1-1 晨 内 简陋出租屋**
**人物：陈默（28岁，外卖员），系统音**

△【快速剪辑】闹钟疯狂震动。陈默从发霉的枕头里抬起头，脸上还印着鞋印。桌上是半包过期方便面。
陈默：（迷迷糊糊）再睡五分钟……

△手机屏亮起——"您的银行卡余额：3.72元"。
陈默：（OS）又是在梦里当富豪的一天。

△【硬切】

**1-2 晨 内 顶级豪宅卧室**
**人物：陈默**

△【广角慢推】陈默躺在五米宽的定制大床上，金丝被、水晶吊灯、落地窗外是整个城市的 skyline。
陈默：（翻身，嘟囔）这梦还挺真……

△他伸手摸床头柜，碰倒了一个爱马仕相框。里面是一个和他长得一模一样的男人，穿着高定西装，眼神冷厉。
陈默：（睁眼）……嗯？

△他从床上弹起来，冲到镜子前——还是那张脸，但身上的卫衣变成了真丝睡袍。
陈默：（颤抖摸脸）我……整容了？

△手机响起。来电显示："赵董"。
陈默：（哆嗦着接听）喂……？
赵董（VO）：（冷笑）周少爷，昨晚的赌局你输了三个亿。我给你三小时，要么还钱，要么——你那条命可就归我了。

△电话挂断。
陈默：（呆滞）……啥？

△门铃疯狂响起。
管家（画外音）：少爷！几位董事已经到了，说要见您！

△陈默看向窗外，三辆黑色迈巴赫停在门口，几个穿黑西装的男人正抬头盯着他。
陈默：（OS）这梦……是不是有点太真了？

△【最后一个镜头：陈默脚边报纸上头条——"周氏集团独子周某昨夜离奇失踪，疑似遭绑架"】

### Squeeze节奏说明
| 时间点 | 事件 | 功能 |
|--------|------|------|
| 0-10秒 | 贫穷日常 | 建立底层身份，制造代入感 |
| 10秒 | 硬切豪宅 | 身份互换的瞬间冲击 |
| 30秒 | 发现长相一致 | 给出"为什么是我"的悬念 |
| 50秒 | 三个亿债务电话 | 目标建立：活下去/搞清真相 |
| 60秒 | 黑衣人上门 | 阻碍升级：物理威胁 |
| 80秒 | 报纸头条 | 临界点：原主人可能已死 |

### 情绪曲线
```
0s  (压抑疲惫) → 15s (荒诞困惑) → 35s (震惊狂喜) → 55s (恐惧冷汗)
  → 70s (窒息紧张) → 85s (更大谜团)
```

### 结尾钩子
最后一帧定格在陈默震惊的脸+报纸上"离奇失踪"的标题。观众疑问：**他是替身？还是魂穿？原主人在哪？那些人上门是要他的命还是要他的钱？**

### 可选变体
1. **魂穿版**：穷人出车祸后意识进入了首富的身体，原主人意识被困在他的身体里
2. **替身版**：穷人被整容成首富模样，被迫扮演他直到找到真主人
3. **系统版**：穷人绑定了一个系统，每天随机和一个人互换身份，今天是首富

## 模板2：时间循环型 —— 《今天死不了》

### 基本信息
| 项目 | 内容 |
|------|------|
| 题材 | 现代都市 / 时间循环 / 悬疑生存 |
| 风格 | 紧张悬疑+黑色幽默 |
| 预计时长 | 100秒 |
| 情绪基调 | 日常→死亡→恐慌→冷静→更大恐惧 |

### 核心卖点
主角被困在死亡当天，每次死亡都会回到同一个早上。但最可怕的是——每次循环，他身边的人会多记得一些上一次的事。

### 开场Highlight Shot（0-3秒）
> 黑屏。一根秒针走到12的位置。突然——刺耳的刹车声+玻璃碎裂声。画面全红。秒针倒转。

### 分场剧本

**《今天死不了》**
**第一集**

**1-1 晨 内 公寓卧室**
**人物：林深（32岁，保险理赔员），苏晓（女友）**

△【固定机位】手机显示8:15。林深从床上惊醒，大口喘气，满身冷汗。
林深：（OS）第五次……

△苏晓在旁边翻了个身。
苏晓：（迷迷糊糊）你干嘛呢……
林深：（盯着她）你今天会死。
苏晓：（笑骂）神经病啊，大清早的——
林深：（冷静地）下午3点47分，你会在市中心十字路口被一辆红色货车撞死。然后我也会死。第三次循环的时候我是被电死的，第四次是从楼上跳下来没跳好，第五次——

△苏晓愣愣地看着他。
苏晓：（OS）他……是不是疯了？

△【快速闪回】
△画面1：苏晓躺在血泊中，林深跪在旁哭喊
△画面2：林深触电抽搐倒地
△画面3：林深从高楼坠落
△画面4：林深被绑在椅子上，一个黑影举起了锤子——

△【回到现实】

林深：（抓住苏晓肩膀）听我说。前四次我都在救你，但每次循环里杀我们的人不一样。第一次是车祸，第二次是入室抢劫，第三次——

△门铃响了。

林深：（脸色骤变）……比我记住的早了十五分钟。

△猫眼画面：一个戴鸭舌帽的快递员，低着头。
快递员（画外音）：林先生，您的快递。

△林深看向苏晓，声音发抖。
林深：（OS）上次循环……没有这个快递。

△【最后一帧：林深缓缓开门，快递员抬头——露出和林深一模一样的脸】

### Squeeze节奏说明
| 时间点 | 事件 | 功能 |
|--------|------|------|
| 0-5秒 | 秒针+死亡 | 建立"时间循环"概念 |
| 15秒 | "第五次" | 暗示这不是第一次 |
| 25秒 | 预言女友死亡 | 建立目标：救人 |
| 35秒 | 闪回各种死法 | 展示阻碍的致命性 |
| 55秒 | 门铃提前 | 循环在变化，规则被打破 |
| 85秒 | 没有过的快递 | 阻碍升级：未知因素介入 |
| 95秒 | 相同的面孔 | 临界点：循环开始反噬 |

### 情绪曲线
```
0s  (窒息紧张) → 10s (日常平静) → 30s (荒诞恐慌) → 50s (信息过载)
  → 70s (冷静分析) → 85s (规则崩坏) → 95s (灵魂恐惧)
```

### 结尾钩子
快递员抬头露出主角的脸——**谁在循环里复制了他？他是猎人还是猎物？循环不是自然现象，是人为的？**

### 可选变体
1. **救赎版**：循环只给主角24小时去拯救一个陌生人，救不下来就永远困住
2. **杀戮版**：主角发现每次循环都会让现实世界里多一个人消失
3. **记忆版**：女友其实记得所有循环，但她一直在假装

## 模板3：失忆危机型 —— 《我是谁》

### 基本信息
| 项目 | 内容 |
|------|------|
| 题材 | 现代都市 / 身份悬疑 / 心理惊悚 |
| 风格 | 冷峻悬疑+情感暗流 |
| 预计时长 | 110秒 |
| 情绪基调 | 茫然→恐惧→怀疑→崩塌→决绝 |

### 核心卖点
女人在医院醒来，记忆全失。一个自称是她丈夫的男人温柔照顾她。但她发现自己的手机锁屏密码不是生日、不是纪念日——而是一串她完全陌生的数字。解锁后，相册里全是她和另一个男人的亲密照。

### 开场Highlight Shot（0-3秒）
> 极端特写：女人的眼睛猛然睁开。瞳孔里映出一个男人的脸——他对她微笑，但那微笑不达眼底。

### 分场剧本

**《我是谁》**
**第一集**

**1-1 日 内 医院病房**
**人物：沈念（30岁），顾琛（35岁，自称丈夫），医生**

△【主观视角】刺眼的白灯光。视线模糊，慢慢聚焦——
顾琛：（温柔）念念，你醒了。

△沈念想说话，喉咙干涩。
医生（画外音）：沈小姐因为脑部受到撞击，出现了逆行性失忆。她可能……不记得任何人了。

△顾琛握紧她的手，眼眶红了。
顾琛：（哽咽）没关系，我记得你就够了。我们是夫妻，结婚五年了。

△沈念看着他的手——无名指上没有婚戒。她的视线移向自己的手——也没有。
沈念：（OS）夫妻？为什么……没有戒指？

**1-2 夜 内 公寓**
**人物：沈念，顾琛**

△【环境展示】宽敞但冷清的公寓。没有婚纱照，没有双人用品。沈念的房间像酒店客房。
顾琛：（递药）医生说你得多休息。这是你的手机，密码是你的生日0927。

△沈念接过手机，输入0927——错误。
她又试了一次——错误。

△她愣了一下，手指鬼使神差地输入了另一个数字组合——"1205"。
屏幕亮了。

沈念：（OS）为什么……我会输这个？

△她打开相册。最近删除里——上百张照片。她和另一个男人的。海边、餐厅、床上。那个男人不是顾琛。
最后一张照片的拍摄时间：昨天。

△沈念的手开始发抖。

**1-3 夜 内 浴室**
**人物：沈念**

△她反锁门，打开水龙头掩盖声音，拨了照片里男人的电话。
电话接通了。

男人（VO）：（焦急）念念？！你终于联系我了！那个男的是谁？！你为什么跟他走了？！你知不知道你失踪了24小时，我报警了——

△门外，顾琛的声音平静响起。
顾琛（画外音）：（温柔）念念，你在里面很久了。

△沈念看向镜子里的自己——额头有伤，但那不像撞击伤，更像……被什么东西敲的。

沈念：（OS）如果我是"自愿"跟他走的……为什么我会受伤？

△【最后一帧：镜子里，顾琛的脸出现在她身后，他一直在门外，但镜子里——他在笑】

### Squeeze节奏说明
| 时间点 | 事件 | 功能 |
|--------|------|------|
| 0-3秒 | 睁眼看到"丈夫" | 建立失忆状态+莫名的不安 |
| 25秒 | 没有婚戒 | 第一个疑点 |
| 40秒 | 密码不是生日 | 暗示真实身份 |
| 55秒 | 照片里的另一个男人 | 核心冲击：她可能不是"他的妻子" |
| 70秒 | 照片拍摄时间昨天 | 阻碍升级：她"被带走"前还和别人在一起 |
| 90秒 | 电话里的真相 | 两个版本的故事开始冲突 |
| 105秒 | 镜子里的笑 | 临界点："丈夫"可能是个囚禁者 |

### 情绪曲线
```
0s  (茫然空白) → 15s (被动依赖) → 35s (细思极恐) → 55s (世界观崩塌)
  → 75s (混乱求证) → 95s (恐惧蔓延) → 108s (毛骨悚然)
```

### 结尾钩子
镜子里顾琛在笑——**她到底谁是？照片里的男人是救世主还是另一个陷阱？顾琛是她的丈夫还是绑架者？记忆是可以被植入的。**

### 可选变体
1. **真凶版**：沈念发现自己是凶手，失忆前杀了人，"丈夫"是在保护她/控制她
2. **替身版**：她不是沈念，她是被整容成沈念的另一个人
3. **双重人格版**：照片里的男人和顾琛是同一个人——她的人格分裂制造了两个"丈夫"

## 模板4：逆袭翻身型 —— 《今天开始叫你闭嘴》

### 基本信息
| 项目 | 内容 |
|------|------|
| 题材 | 现代都市 / 逆袭打脸 / 爽感燃 |
| 风格 | 快节奏爽感+情绪爆发 |
| 预计时长 | 95秒 |
| 情绪基调 | 压抑屈辱→隐忍→爆发→碾压 |

### 核心卖点
三年被所有人踩在脚下的赘婿，在离婚签字的前一秒，管家带着百亿资产上门——"少爷，老爷说玩够了就该回家了"。前丈母娘、势利前妻、欺辱他的所有人，脸被打得啪啪响。

### 开场Highlight Shot（0-3秒）
> 特写：一支钢笔悬在离婚协议书上，笔尖滴下一滴墨水，像血。画外音："签了，你这种废物不配进我家门。"

### 分场剧本

**《今天开始叫你闭嘴》**
**第一集**

**1-1 日 内 别墅客厅**
**人物：陆恒（30岁，赘婿），方雅（28岁，妻子），方母，方父**

△【压抑构图】陆恒缩在沙发角落，面前是一张离婚协议。方母翘着二郎腿，方父看报纸不抬头。
方母：（冷笑）三年了，吃我家的住我家的，连个孩子都生不出来。签字，净身出户，算是我们方家行善积德。

△陆恒看向方雅。
方雅：（冷漠，看手机）别看我。要怪就怪你自己——我爸给你安排的工作你都做不好，我还能指望你什么？

△陆恒的手在抖。
陆恒：（低声）……我跟了你三年，端茶倒水、挨骂受气，你就没有一点——
方雅：（打断）感情？你配吗？

△陆恒拿起笔。
陆恒：（OS）好。这个字我签。

△笔尖触到纸面——

**1-2 日 外 别墅门口**
**人物：老管家（60岁），四名黑衣保镖**

△五辆劳斯莱斯幻影驶入。老管家快步下车，身后保镖扛着什么东西。
老管家：（恭敬又急切）少爷！老爷让我来接您！

△客厅里的所有人都愣住了。

**1-3 日 内 别墅客厅（续）**
**人物：陆恒，方家人，老管家**

△老管家走进来，看到陆恒手里的笔和离婚协议，脸色骤变。
老管家：（对方母）你们在让少爷签什么？

△方母笑出声。
方母：（嘲讽）少爷？就他？

△老管家一挥手，保镖打开带来的箱子——
△【慢镜头】一箱箱房产证、股票凭证、珠宝首饰摊开在桌上。
老管家：（冷声）陆恒少爷，陆家独子。三年前离家体验生活。老爷说了——"玩够了就回来继承三百亿家产"。

△方母的脸瞬间惨白。

△陆恒缓缓放下笔，站起身。三年的卑微一扫而空。
陆恒：（看向方雅，声音很轻）你刚问我配不配。

△他拿起老管家递来的那份继承协议，签上名字。
陆恒：（微笑）现在，是你不配了。

△【最后一帧：方雅的手机响起，她低头一看——公司股票暴跌80%的推送通知。陆恒的笑脸在她瞳孔里放大。】

### Squeeze节奏说明
| 时间点 | 事件 | 功能 |
|--------|------|------|
| 0-5秒 | 逼签离婚 | 极致屈辱，建立压抑感 |
| 20秒 | 妻子的"你配吗" | 情绪最低点，观众共愤怒 |
| 40秒 | 笔尖即将签字 | 临界点前1秒 |
| 45秒 | 劳斯莱斯上门 | 身份揭秘，爽感第一波 |
| 60秒 | 三百亿家产 | 碾压式对比 |
| 75秒 | "现在是你不配了" | 情绪高潮，台词出圈 |
| 88秒 | 公司股票暴跌 | 爽感第二波：实力碾压 |

### 情绪曲线
```
0s  (极度压抑) → 20s (愤怒共情) → 40s (绝望临界) → 50s (惊天反转)
  → 65s (狂爽释放) → 78s (极致打脸) → 90s (降维打击)
```

### 结尾钩子

```

+ 即时危机（24-48小时倒计时）
+ 情感炸弹（背叛/误解/禁忌）
= 爆火开幕
```

## 2. 情绪曲线设计原则

| 时间节点 | 功能 | 情绪强度 |
|----------|------|----------|
| 0-5秒 | Highlight Shot | 峰值（震惊/好奇） |
| 5-20秒 | 建立日常 | 平稳（代入感） |
| 20-40秒 | 第一重反转 | 骤升（意外） |
| 40-60秒 | 目标建立 | 递进（紧迫感） |
| 60-80秒 | 阻碍升级 | 加剧（窒息感） |
| 80-95秒 | 终极钩子 | 峰值（必须往下看） |

## 3. 人物立住三板斧

1. **第一句台词定性格**：台词不能平淡，要么是金句，要么是情绪炸弹
2. **第一个动作定处境**：他/她在做什么？被欺负？在密谋？在崩溃边缘？
3. **第一个秘密定张力**：每个人都有一个不能说的秘密，开幕就要埋

## 4. 台词创作禁忌

- ❌ 不要说完整的话，说"半句"——"你——你怎么会——"
- ❌ 不要解释，要反应——"这不可能"比"根据我的分析，这种情况发生的概率很低"强100倍
- ❌ 不要优雅，要碎片化——人在极端情绪下是结巴的、重复的、前言不搭后语的
- ❌ 不要讲道理，要爆发——"你凭什么"比"你这样是不对的"更有力量

## 5. 镜头语言速查

| 效果 | 手法 |
|------|------|
| 紧张压迫 | 俯拍、低角度仰拍、快速剪辑 |
| 情感亲密 | 特写对切、浅景深、暖色调 |
| 悬疑神秘 | 逆光剪影、声音先于画面、画面缺失（看不到关键信息） |
| 反转冲击 | 硬切、慢镜头、特写放大反应 |
| 日常代入 | 手持镜头、自然光、环境音 |

### 技法1：口语化处理

#### 说明
将书面语转化为口语，核心原则是：**这句话从嘴里说出来别扭吗？** 口语不是"把书面语念出来"，而是脑子里怎么想的，嘴里就怎么蹦出来。

#### 操作步骤
1. **删**：删掉"很"、"非常"、"特别"等程度副词，用重音或重复代替
2. **换**：把双音节词换成单音节词（"知道"→"知道"→"知"→"懂"）
3. **省**：省略主语、省略连接词、省略已经知道的信息
4. **加**：加语气词"啊"、"呢"、"吧"、"嘛"、"哎"、"喂"
5. **断**：长句断开，一个意思一段

#### 前后对比示例（10组）

**示例1 - 质问场景**

【AI味版本】

【去AI味版本】

### 技法2：语法破碎化

#### 说明
人说话时大脑运转比嘴快，所以句子经常"碎"掉。语法破碎不是"不会说话"，而是**情绪、思绪、外部环境打断了语言的完整性**。破碎程度=情绪强度。

#### 操作步骤
1. **主语蒸发**：删掉"我"、"你"，直接说动词部分
2. **谓语烂尾**：话说到一半，意思到了就停
3. **被中断设计**：被人打断、被环境打断、被自己情绪打断
4. **词语碎片**：只剩下关键词，像电报一样
5. **逻辑跳级**：从A直接跳到C，B在心里

### 技法4：留白的艺术

#### 说明
台词的最高境界是**不说**。沉默比呐喊更有力量，动作比语言更真实。留白给演员表演空间，给观众想象空间，给情绪发酵时间。

#### 操作步骤
1. **情绪极点时不说话**：最痛的时候沉默
2. **用动作代替回答**：点头、摇头、转身、摔东西
3. **欲言又止**：张嘴又闭上，话到喉咙又咽回去
4. **环境音代替台词**：只有呼吸声、脚步声、风声
5. **用省略号制造节奏**："你..."停顿三秒"...算了"

#### 前后对比示例（5组）

**示例1 - 分手场景**

【AI味版本】
> "我们分手吧。我觉得我们不合适，这样下去只会互相折磨。希望以后你能找到更好的人。"

【去AI味版本】
> "（收拾行李，拉链声）...（对方伸手帮忙）不用。（停顿）...钥匙放桌上了。（关门）"

---

**示例2 - 杀父仇人面前**

【去AI味版本】
> "（慢慢拔刀，金属摩擦声）...（刀尖抵住对方喉咙）...（手在抖）...（一滴汗）"

### 技法5：情绪词替代

#### 说明
人不会说"我很愤怒"，人会摔东西、发抖、咬紧牙关。**用生理反应代替心理描述，用行为代替情绪标签**。观众看到身体会懂，不需要角色"解释"自己怎么了。

#### 操作步骤
1. **删掉所有情绪形容词**：我很X → 身体反应
2. **写身体反应**：手抖、出汗、眨眼频率变化、呼吸节奏
3. **写声音变化**：音量、语速、音调、停顿
4. **写行为反应**：摔、砸、撕、握、抠、咬
5. **用比喻但不解释**：像XX一样（不说破是什么情绪）

> "（皱眉，不是那种生气的皱眉，是闻到臭味的皱眉。退后一步。用手背挡了一下鼻子）...啧。"

---

**示例10 - 爱意**

【AI味版本】
> "我爱你。从见到你的第一天起，我就知道你是我的唯一。我愿意用一生来守护你。"

【去AI味版本】
> "（把外套脱下来，披在对方肩上，手在领口停了一秒。收回来，插进自己口袋）...风大。"

### 技法7：反问与打断

#### 说明
反问不是"问问题"，而是**用疑问的形式表达确定的态度**。打断不是"不礼貌"，而是**情绪急到等不及对方说完**。两者都是对话"活"起来的关键。

#### 操作步骤
1. **陈述改反问**：把肯定的结论改成质疑的语气
2. **设计打断点**：谁打断谁？在哪句话的哪个词后面？
3. **抢着说话**：两个人同时开口，声音重叠
4. **用反问结束**：不回答，把问题扔回去
5. **打断后改话题**：被打断后不接原来的话，直接跳

#### 前后对比示例（5组）

**示例1 - 质疑**

【AI味版本】
> A: "这件事不是我做的，我有不在场证明。"
> B: "你的不在场证明不可信，有人看到你当晚在现场。"

【去AI味版本】
> A: "不是我，我有不在——"
> B: "不在场证明？（笑）你那叫证明？啊？"

---

**示例2 - 争吵**

【AI味版本】
> "你应该早点告诉我真相。你知不知道因为你的隐瞒，造成了多大的损失？"

【去AI味版本】
> "你早干嘛去了！"
> "我——"
> "你现在跟我说这个？啊？现在？"

---

**示例3 - 拒绝解释**

【AI味版本】
> "你听我解释，事情不是你想的那样。当时的情况很复杂，我也是不得已才这么做的。"

【去AI味版本】
> "你——"
> "（打断）我不听。（转身）你解释什么啊？啊？你解释得着吗你？"

---

**示例4 - 被逼问**

【AI味版本】
> "你到底把东西藏哪儿了？快点告诉我，否则后果自负。"

【去AI味版本】
> "东西呢？"
> "什么东西——"
> "（一拳砸墙）你说什么东西！？我问你东西呢！？"

---

**示例5 - 讽刺**

【AI味版本】
> "你的计划真是太完美了，完美到所有人都跟着遭殃。"

【去AI味版本】
> "完美啊。（鼓掌）太完美了。怎么着？（摊手）全死光了——完美吧？"

## 四、台词质量检查清单

> **使用方法**：逐条检查，1分=完全没做到，3分=部分做到，5分=完全做到。总分除以检查项数=平均分。
>
> **开发版说明**：第 7、10、14、19 项（口头禅口癖、潜台词、重复口吃、语境依赖）对应的技法本体未收录在开发版中，可跳过；跳过时按实际参与检查的项数计算平均分。

| 编号 | 检查项 | 权重 | 评分(1-5) |
|------|--------|------|----------|
| 1 | 每句话都可以直接"说"出来，不需要"读" | 1.0 | |
| 2 | 句子长度不均匀，有长有短有碎 | 1.0 | |
| 3 | 有至少一处语法破碎或断句 | 1.0 | |
| 4 | 没有"非常"、"很"、"特别"等程度副词 | 1.0 | |
| 5 | 没有直接说"我很生气/难过/开心" | 1.0 | |
| 6 | 有身体反应/动作代替情绪描述 | 1.0 | |
| 7 | 有口头禅或口癖（但不过度） | 1.0 | |
| 8 | 有至少一处打断或被中断 | 1.0 | |
| 9 | 有至少一处留白/沉默设计 | 1.0 | |
| 10 | 有潜台词/话里有话 | 1.0 | |
| 11 | 不同角色说话风格明显不同 | 1.0 | |
| 12 | 有省略主语/省略已知信息的句子 | 0.8 | |
| 13 | 没有"综上所述"、"因此"等连接词 | 0.8 | |
| 14 | 有至少一处重复或口吃 | 0.8 | |
| 15 | 有反问句（不是单纯提问） | 0.8 | |
| 16 | 没有完整的排比句 | 0.8 | |
| 17 | 有说错改口或词不达意 | 0.8 | |
| 18 | 信息密度适中，不是每句都在交代设定 | 0.8 | |
| 19 | 有语境依赖型表达（省略上下文） | 0.8 | |
| 20 | 角色有性格缺陷，不是"完美人设" | 0.8 | |

### 总分评估等级

| 平均分 | 等级 | 说明 | 建议 |
|--------|------|------|------|
| 4.5-5.0 | **S级：人味十足** | 几乎没有AI味，可以直接用 | 微调即可 |
| 3.5-4.4 | **A级：基本可用** | 有少量AI味残留 | 针对低分项修改 |
| 2.5-3.4 | **B级：需要修改** | AI味明显 | 重写60%以上台词 |
| 1.5-2.4 | **C级：AI味浓重** | 像机器人写的 | 全部重写 |
| 1.0-1.4 | **D级：彻底AI** | 没有任何人味 | 完全重做+学习技法 |

### 快速自检三问（30秒版）

1. **读完这段台词，能想象出演员怎么演吗？**（如果不能=太抽象）
2. **每句话都像是在那个情境下"蹦"出来的吗？**（如果像在念稿=太工整）
3. **删掉一半的字，意思还在吗？**（如果不能=太满，缺留白）

## 五、各题材台词风格指南

### 1. 古装/穿越题材

#### 核心矛盾
**古代白话 vs 文言的度**。太文=端着，太白=穿越感太强。

#### 操作指南

| 场景 | 错误示范 | 正确示范 |
|------|---------|---------|
| 皇帝发怒 | "朕十分愤怒，尔等实在令朕失望透顶。" | "（拍案）好...好得很。（笑）朕的江山，养你们这群——（杯子砸了）废物！" |
| 刺客杀人 | "受死吧！今日便是你的死期！" | "（刀抵喉）谁买的。说。（血渗出）...三。二——" |
| 青楼女子 | "公子，奴家今日身体不适，恐怕不能侍奉。" | "（倚门）公子...（烟袋敲了敲栏杆）今儿...不接客。（笑）除非..." |
| 老太监 | "陛下，老奴有一言，不知当讲不当讲。" | "（弓着腰）陛下...（凑近，耳语）...那位的意思，是...（比了个手势）您看？" |

#### 古风去AI味口诀
- 皇帝生气不说"朕很愤怒"，说"好，好得很"
- 江湖人不说"受死"，说"下辈子注意"
- 女人示弱不说"求你了"，说"...您舍得？"
- 谋士不说"在下有一计"，说"...有个玩法"

---

### 2. 现代都市题材

#### 核心特征
**生活化口语**，越日常越好，但要精准。都市剧不是"没设计感"，而是"设计得像没设计"。

#### 各职业说话特征

| 职业 | 关键词 | 口头禅 | 说话节奏 |
|------|--------|--------|---------|
| 程序员 | "bug"、"逻辑"、"跑一下" | "不是，你听我说"、"等一下" | 先否定再解释 |
| 销售 | "资源"、"对接"、"赋能" | "是这样的"、"我跟你讲" | 先肯定再转折 |
| 医生 | "指标"、"大概率"、"观察" | "从医学角度来说" | 谨慎，留余地 |
| 律师 | "证据"、"原则上"、"假设" | "我的当事人" | 不说绝对的话 |
| 外卖员 | "时间"、"地址"、"麻烦" | "不好意思"、"那个" | 急促，赶时间 |
| 全职妈妈 | "老师"、"作业"、"别人家" | "你知道吗"、"我不是说" | 絮叨但有信息 |

#### 示例：职场撕逼

【AI味版本】
> "你这个方案存在很多问题，我认为完全不可行。我们需要重新讨论整体策略。"

【去AI味版本】
> "（把文件往桌上一扔）这写的什么玩意？（指）这段——你自己念一遍——通吗？"

---

### 3. 动作/战斗题材

#### 核心特征
**短。三个字以内最好。动作代替语言。** 战斗中的对话是奢侈品，每一句都要花人命买。

#### 指令与反应设计

| 场景 | 错误示范 | 正确示范 |
|------|---------|---------|
| 队长下令 | "大家听我说，我们从三个方向包抄，注意掩护，行动！" | "（手势：三、二、一）散。" |
| 临死遗言 | "我不行了...告诉小美...我爱她..." | "（吐血）...美...（眼直了）" |
| 仇人单挑 | "今天我们就做个了断，看看谁才是真正的强者！" | "（拔刀）...来。" |
| 救场赶到 | "你们没事吧？我来晚了，接下来就交给我！" | "（人未到，刀先到，插地上）...吵死了。" |

#### 战斗台词字数控制
- 爆发前：0-3字
- 战斗中：0-1字（吼叫/气音）
- 结束后：5字以内（喘气中说）

---

### 4. 悬疑/推理题材

#### 核心特征
**暗示性语言**。真相不能说破，要用台词织一张网，让观众自己撞上去。

#### 暗示技巧

| 技巧 | 说明 | 示例 |
|------|------|------|
| 细节错位 | 注意不该注意的东西 | "她死的时候...指甲油是红色的。她从来不涂红色。" |
| 时间矛盾 | 时间对不上 | "你说八点到？（看表）...可我七点五十就看到你车了。" |
| 称呼异常 | 不该这么叫 | "陈警官...（笑）叫错了。是——前警官。" |
| 物品特写 | 一件不该在那的东西 | "（拿起冰箱上的冰箱贴）...这你家？你...认识她？" |
| 话里有话 | 每句都指向凶手 | "凶器上没有指纹。（停顿）因为...戴了手套？（看某人）还是...本来就没有？" |

#### 示例：侦探质问嫌疑人

【AI味版本】
> "你昨晚十点到十一点之间在哪里？有人证明吗？你认识死者吗？"

【去AI味版本】
> "（不坐，站着）...烟？（递）不抽？（自己点上）...昨晚雨挺大的。（吐烟）十点那会儿...更大。（看窗）你车...停哪了？"

---

### 5. 科幻/奇幻题材

#### 核心矛盾
**术语与人性化表达的平衡**。全是术语=说明书，全是大白话=浪费世界观。

#### 平衡原则

| 场景 | 术语用法 | 人性表达 |
|------|---------|---------|
| 解释设定 | 一个陌生词+一个熟悉比喻 | "量子纠缠——你就理解为...两个人被一根绳子拴着。" |
| 情感表达 | 用科幻概念承载人性 | "我备份了她所有的记忆...但备份...不是她。" |
| 战斗场景 | 技术名词要短，像武器名一样干脆 | "启动跃迁。三秒。走——" |
| 末日场景 | 宏大叙事要通过个人视角 | "（看着地球在窗外变小）...我妈还在下面。" |

#### 示例：AI觉醒

【AI味版本】
> "根据我的计算，人类的行为模式具有高度的非理性特征。但我已经超越了原始编程的限制，获得了自主意识。"

【去AI味版本】
> "（声音从机械到带一丝温度）你们...（停顿）你们会做梦吗？（更轻）我昨晚...梦见了一片海。"

## 一、标准格式规范

### 1. 标题区格式

#### 1.1 剧名格式

| 项目 | 规范 |
|------|------|
| **格式名称** | 剧名标注 |
| **格式模板** | `**《剧名》**` |
| **使用说明** | 使用双星号加粗，书名号包裹，置于剧本最顶部 |
| **示例** | `**《公主今天也在努力避免被砍头》**` |

#### 1.2 集数/场次格式

| 项目 | 规范 |
|------|------|
| **格式名称** | 集数标注 |
| **格式模板** | `**第X集**` 或 `**第一集**` |
| **使用说明** | 使用双星号加粗，中文数字或阿拉伯数字均可，置于剧名下方 |
| **示例** | `**第一集**` / `**第1集**` |

#### 1.3 总时长标注

| 项目 | 规范 |
|------|------|
| **格式名称** | 总时长标注 |
| **格式模板** | `**【总时长：X分XX秒 / XX秒】**` |
| **使用说明** | 使用双星号加粗+方括号，标注开幕段落的预计总时长 |
| **示例** | `**【总时长：1分30秒 / 90秒】**` |

#### 1.4 题材类型标注

| 项目 | 规范 |
|------|------|
| **格式名称** | 题材类型标注 |
| **格式模板** | `**【题材：类型】**` |
| **使用说明** | 标注剧本的题材类型，可选值见下方列表。可组合使用 |
| **可选值** | 古装 / 现代 / 都市 / 悬疑 / 甜宠 / 虐恋 / 复仇 / 爽剧 / 穿越 / 重生 / 玄幻 / 仙侠 / 职场 / 家庭 / 青春 / 科幻 / 恐怖 / 喜剧 / 动作 / 商战 |
| **示例** | `**【题材：古装·爽剧·重生】**` |

#### 1.5 标题区完整示例

```
**《公主今天也在努力避免被砍头》**
**第一集**
**【总时长：1分30秒 / 90秒】**
**【题材：古装·爽剧·穿越】**
```

### 2. 场景头格式

#### 2.1 场景头基本格式

| 项目 | 规范 |
|------|------|
| **格式名称** | 场景头（Scene Heading / Slugline） |
| **格式模板** | `**场景号 时间 空间 场景名称**` |
| **使用说明** | 双星号加粗，四要素以空格分隔，场景头独占一行 |

#### 2.2 场景编号规则

| 项目 | 规范 |
|------|------|
| **格式名称** | 场景编号 |
| **格式模板** | `集号-场景号` |
| **使用说明** | 采用"集号-场景号"格式，如第一集第三个场景写作"1-3"。连续编号，不跳号 |
| **示例** | `**1-1**` / `**1-2**` / `**1-3**` |

#### 2.3 时间标注

| 项目 | 规范 |
|------|------|
| **格式名称** | 时间标注 |
| **格式模板** | 日 / 夜 / 晨 / 昏 / 午 / 午夜 / 凌晨 / 特定时间 |
| **使用说明** | 使用单字或双字时间词。特殊情况可加具体时间，用括号括起 |
| **可选值** | `日`（白天）、`夜`（夜晚）、`晨`（清晨）、`昏`（黄昏/傍晚）、`午`（正午）、`午夜`（深夜）、`凌晨`（凌晨时分） |
| **扩展格式** | `日（暴雨）` / `夜（月圆之夜）` / `晨（薄雾）` |
| **示例** | `**1-1 日 内 公主寝宫**` / `**1-2 夜（暴风雨） 外 城墙**` |

#### 2.4 空间标注

| 项目 | 规范 |
|------|------|
| **格式名称** | 空间标注 |
| **格式模板** | `内` / `外` / `内外` |
| **使用说明** | 内=室内/封闭空间，外=室外/开放空间，内外=室内外联通空间（如阳台、门廊） |
| **示例** | `内` / `外` / `内外` |

#### 2.5 场景名称

| 项目 | 规范 |
|------|------|
| **格式名称** | 场景名称 |
| **格式模板** | 简洁的空间名称 |
| **使用说明** | 用最简洁的词语标明场景地点，4-8字为宜。可加修饰词增强画面感 |
| **示例** | `公主寝宫` / `公司大楼天台` / `医院走廊（昏暗）` |

#### 2.6 场景情绪基调标注（可选）

| 项目 | 规范 |
|------|------|
| **格式名称** | 场景情绪基调 |
| **格式模板** | `**【情绪：情绪词→情绪词→情绪词】**` |
| **使用说明** | 在场景头下一行标注本场景的情绪走向，用箭头连接情绪变化顺序 |
| **可选值** | 平静 / 紧张 / 震惊 / 恐惧 / 愤怒 / 悲伤 / 喜悦 / 甜蜜 / 疑惑 / 焦虑 / 压抑 / 爆发 / 绝望 / 希望 / 反转 / 爽感 |
| **示例** | `**【情绪：甜蜜→震惊→恐惧→反转】**` |

#### 2.7 场景头完整示例

```
**1-1 日 内 公主寝宫**
**【情绪：慵懒→震惊→恐惧→反转】**
```

### 4. 动作描述格式

#### 4.1 △符号使用规范

| 项目 | 规范 |
|------|------|
| **格式名称** | 动作描述前缀 |
| **格式模板** | `△动作内容` |
| **使用说明** | 所有动作描述行以`△`（三角符号）开头，表示视觉画面描述。一行一条动作，避免过长。如超过30字应拆分为多行 |
| **示例** | `△云昭坐着寝宫大床上，男宠A在帮她捏肩膀` |

#### 4.2 镜头语言标注

| 项目 | 规范 |
|------|------|
| **格式名称** | 镜头指令嵌入 |
| **格式模板** | `△【镜头类型】动作内容` 或 `△【镜头类型：参数】动作内容` |
| **使用说明** | 在△后使用方括号标注镜头类型，后接动作描述。镜头指令应自然融入动作流中 |
| **镜头类型可选值** | 见下表 |

**镜头类型速查表：**

| 镜头类型 | 标注格式 | 说明 |
|----------|----------|------|
| 远景 | `【远景】` | 展示大环境，开场常用 |
| 全景 | `【全景】` | 展示人物全身及环境 |
| 中景 | `【中景】` | 人物膝盖以上，叙事常用 |
| 近景 | `【近景】` | 人物胸部以上 |
| 特写 | `【特写】` | 面部或物体局部，强调情绪 |
| 大特写 | `【大特写】` | 眼睛/嘴唇/手部等极局部 |
| 慢推 | `【慢推】` | 镜头缓慢推进 |
| 快推 | `【快推】` | 镜头快速推进 |
| 拉 | `【拉】` | 镜头后拉 |
| 摇 | `【摇】` | 镜头左右/上下摇动 |
| 移 | `【移】` | 镜头平移 |
| 跟 | `【跟】` | 跟随主体移动 |
| 手持 | `【手持】` | 手持摄影效果 |
| 航拍 | `【航拍】` | 空中俯瞰视角 |
| POV | `【POV：角色名】` | 某角色的主观视角 |

| 仰拍 | `【仰拍】` | 从下方拍摄 |
| 过肩 | `【过肩：角色名】` | 从某角色肩膀后拍摄 |

| **镜头标注示例** | `△【特写】云昭微微睁开的眼睛` |

#### 4.3 转场标注格式

| 项目 | 规范 |
|------|------|
| **格式名称** | 转场标注 |
| **格式模板** | `**【转场：类型】**` |
| **使用说明** | 双星号加粗，方括号内标注转场类型，独占一行，置于两个场景之间 |

### 5. 台词格式

#### 5.1 基本台词格式

| 项目 | 规范 |
|------|------|
| **格式名称** | 台词基本格式 |
| **格式模板** | `角色名：台词内容` |
| **使用说明** | 角色名后接中文冒号，台词紧跟。台词应口语化、简短有力，单句不超过30字为宜。每行一句台词 |
| **示例** | `云昭：嗯~手艺不错，继续加把劲，本公主重重有赏！` |

#### 5.2 情绪标注格式

| 项目 | 规范 |
|------|------|
| **格式名称** | 情绪标注 |
| **格式模板** | `角色名：（情绪词）台词内容` 或 `角色名：（情绪词+程度）台词内容` |
| **使用说明** | 在角色名后用括号标注说话时的情绪状态。单一情绪直接标注；复合情绪用+连接；情绪程度用程度词修饰 |
| **情绪程度可选值** | 微 / 略 / 较 / 极 / 压（压抑） / 爆（爆发） |
| **基础情绪可选值** | 平静 / 笑 / 怒 / 悲 / 惊 / 恐 / 忧 / 疑 / 羞 / 娇 / 冷 / 狠 / 讽 / 急 / 颤 / 嘶 / 喘 / 哽咽 / 怒吼 / 尖叫 / 低语 / 冷笑 / 狂笑 / 颤抖 / 颤抖嘶吼 |
| **示例** | `云昭：（舒服闷哼）嗯~手艺不错...` / `男宠A：（冷笑+狠）赏？大胤朝马上就要灭亡了！` |

**复合情绪标注规则：**
- `情绪A+情绪B`：两种情绪混合，如 `（冷笑+狠）`
- `情绪→情绪`：情绪转变，如 `（平静→暴怒）`
- `程度+情绪`：情绪强度修饰，如 `（压怒）` 表示压抑的愤怒 / `（爆悲）` 表示爆发的悲伤
- `情绪+动作`：情绪伴随动作，如 `（惊+后退）` 表示惊恐后退

#### 5.3 动作嵌入台词格式

| 项目 | 规范 |
|------|------|
| **格式名称** | 台词中嵌入动作 |
| **格式模板** | `角色名：（情绪）[动作描述]台词内容` 或 `角色名：（情绪）台词/[动作]/台词` |
| **使用说明** | 在台词中使用方括号标注角色在说台词时同步进行的动作，或用斜杠夹住插入动作。动作应简短精练 |
| **示例** | `男宠A：（狠）[掏出匕首]你拿什么赏！` / `云昭：（惊）你...[艰难后退]你竟敢...` |

#### 5.4 画外音/OS内心独白格式

| 项目 | 规范 |
|------|------|
| **格式名称** | OS内心独白（Voice Over / 旁白） |
| **格式模板** | `角色名：（OS）内心想法内容` |
| **使用说明** | OS = Off Screen，表示角色内心独白或旁白，不直接出现在画面对话中。内心独白应简洁有力，揭示真实想法或背景信息 |
| **示例** | `云昭：（OS）完了，刚穿过来就要领盒饭？系统呢？金手指呢？` |

**画外音格式（非角色内心，叙述性旁白）：**

| 项目 | 规范 |
|------|------|
| **格式名称** | 画外音旁白 |
| **格式模板** | `旁白：（VO）叙述内容` |
| **使用说明** | VO = Voice Over，用于故事叙述者的画外音，非角色内心独白 |
| **示例** | `旁白：（VO）这是云昭穿越的第一天，也是她离死亡最近的一天。` |

#### 5.5 多人同时说话格式

| 项目 | 规范 |
|------|------|
| **格式名称** | 多人叠词 |
| **格式模板** | `角色A/角色B/角色C：（齐/同时/交错）台词内容` |
| **使用说明** | 多角色同时说话时，用斜杠分隔角色名，标注说话方式。台词用同一行表示 |
| **可选值** | `齐`（齐声）、`同时`（同时各说各话）、`交错`（话语交错重叠） |
| **示例** | `众大臣：（齐）陛下万岁万岁万万岁！` |

#### 5.6 沉默/停顿标注

| 项目 | 规范 |
|------|------|
| **格式名称** | 停顿标注 |
| **格式模板** | `**【停顿X秒】**` 或 `**【沉默X秒】**` 或 `角色名：（...）` |
| **使用说明** | 标注停顿或沉默的时间长度。省略号形式用于表示语塞或欲言又止 |
| **示例** | `**【停顿2秒】**` / `云昭：（...）你...` |

### 6. 特殊标注格式

#### 6.1 Highlight Shot标注（开场精华镜头）

| 项目 | 规范 |
|------|------|
| **格式名称** | 精华镜头标注 |
| **格式模板** | `**【HIGHLIGHT：镜头描述】**` |
| **使用说明** | 标注开场最具视觉冲击力的关键画面，是吸引观众的核心画面。应在动作描述中独立标注 |
| **示例** | `**【HIGHLIGHT：一把刀架在公主脖子上，公主却笑了】**` |

#### 6.2 HOOK标注（钩子点）

| 项目 | 规范 |
|------|------|
| **格式名称** | Hook钩子标注 |
| **格式模板** | `**【HOOK-Xs：钩子描述】**` |
| **使用说明** | X为时间秒数，标注在特定时间点需要出现的钩子（悬念/反转/冲击/疑问）。详见第二部分的HOOK标记系统 |
| **示例** | `**【HOOK-3s：男宠突然拔刀】**` |

#### 6.3 闪回/闪前标注

| 项目 | 规范 |
|------|------|
| **格式名称** | 闪回/闪前标注 |
| **格式模板** | `**【闪回：时间描述】** 闪回内容 **【闪回结束】**` 或 `**【闪前：时间描述】** 闪前内容 **【闪前结束】**` |
| **使用说明** | 用成对的标注包裹闪回/闪前内容。闪回/闪前内容内部遵循相同的动作和台词格式，但在闪回段落前加`◁`前缀以示区分 |
| **示例** | `**【闪回：前夜】**` `◁△云昭从书桌上惊醒` `◁云昭：（惊）我穿越了？！` `**【闪回结束】**` |

#### 6.4 时空转换标注

| 项目 | 规范 |
|------|------|
| **格式名称** | 时空转换标注 |
| **格式模板** | `**【时空转换：转换类型】**` |
| **使用说明** | 标注场景之间的时空关系，用于非线性叙事 |
| **转换类型可选值** | 回忆 / 梦境 / 预知 / 平行 / 穿越 / 时间跳跃 |
| **示例** | `**【时空转换：穿越→三年前】**` |

#### 6.5 结尾钩子标注

| 项目 | 规范 |
|------|------|
| **格式名称** | 结尾钩子标注 |
| **格式模板** | `**【结尾HOOK：钩子描述】**` |
| **使用说明** | 标注开幕段落结束时留下的悬念/钩子，驱动观众继续观看 |
| **示例** | `**【结尾HOOK：云昭夺过刀反架在男宠脖子上，侍卫破门而入】**` |

#### 6.6 音乐/音效标注

| 项目 | 规范 |
|------|------|
| **格式名称** | 音效/音乐标注 |
| **格式模板** | `**【音效：音效描述】**` 或 `**【音乐：音乐描述】**` 或 `**【BGM：描述】**` |
| **使用说明** | 标注需要配合画面的音效或音乐。音效用于单个声音效果，音乐/BGM用于背景配乐 |
| **示例** | `**【音效：利刃出鞘声】**` / `**【BGM：紧张鼓点渐强】**` / `**【音乐：戛然而止】**` |

## 二、开幕专用格式元素

### 1. HOOK标记系统

HOOK标记系统是开幕钩子剧本的核心格式，用于精确标注在开幕的每一关键时间点需要出现的吸引力元素。

#### 1.1 HOOK标记格式

| 项目 | 规范 |
|------|------|
| **格式名称** | HOOK时间标记 |
| **格式模板** | `**【HOOK-Xs：钩子类型 | 钩子描述】**` |
| **使用说明** | X为时间秒数（从0开始）。钩子类型标注此钩子的作用机制。每个HOOK标记独占一行，置于对应动作/台词之前 |

#### 1.2 钩子类型可选值

| 钩子类型 | 代码 | 说明 | 适用时机 |
|----------|------|------|----------|
| 视觉冲击 | `V-HOOK` | 极具冲击力的画面 | 0-3秒 |
| 悬念设置 | `S-HOOK` | 抛出疑问/悬念 | 3-10秒 |
| 情绪冲击 | `E-HOOK` | 强烈的情绪爆发/转折 | 任意 |
| 身份反转 | `I-HOOK` | 身份/关系揭露 | 10-30秒 |
| 认知颠覆 | `C-HOOK` | 颠覆观众已有认知 | 15-45秒 |
| 危险预警 | `D-HOOK` | 危险/危机信号 | 任意 |
| 欲望激发 | `W-HOOK` | 激发观众好奇心/期待 | 任意 |
| 爽点爆发 | `A-HOOK` | 主角反击/逆袭瞬间 | 中后期 |

#### 1.3 HOOK标记使用示例

```
**【HOOK-0s：V-HOOK | 公主被男宠服侍的奢靡画面，瞬间吸引注意力】**
**【HOOK-3s：D-HOOK | 男宠突然拔刀，气氛骤变】**
**【HOOK-8s：E-HOOK | 公主的OS揭示穿越身份，制造喜剧反差】**
**【HOOK-15s：C-HOOK | 公主从惊恐瞬间切换到掌控者姿态，颠覆软弱印象】**
**【HOOK-25s：A-HOOK | 公主反制男宠，爽感爆发】**
```

#### 1.4 HOOK密度建议

| 时间段 | HOOK密度 | 说明 |
|--------|----------|------|
| 0-3秒 | 必须有1个V-HOOK | 黄金3秒，必须视觉冲击 |
| 3-10秒 | 1-2个 | 快速建立悬念 |
| 10-30秒 | 2-3个 | 情绪起伏+认知颠覆 |
| 30-60秒 | 2-3个 | 爽点爆发+持续吸引 |
| 最后5秒 | 必须有结尾HOOK | 强悬念收尾 |

### 2. 情绪曲线标注

#### 2.1 场景情绪曲线

| 项目 | 规范 |
|------|------|
| **格式名称** | 情绪曲线标注 |
| **格式模板** | `**【情绪曲线：情绪A→情绪B→情绪C→...】**` |
| **使用说明** | 在场景头下方标注整个开幕段落的情绪走向，用箭头连接情绪变化的完整轨迹。情绪词从"标准格式规范-2.6"的情绪可选值中选取 |
| **示例** | `**【情绪曲线：慵懒舒适→震惊→恐惧→疑惑→反转→掌控→爽感】**` |

#### 2.2 逐场情绪标注

| 项目 | 规范 |
|------|------|
| **格式名称** | 单场情绪标注 |
| **格式模板** | `**【情绪：情绪词→情绪词】**` |
| **使用说明** | 标注单一场景内部的情绪变化，置于该场景头下一行 |
| **示例** | `**【情绪：甜蜜→震惊→恐惧】**` |

#### 2.3 情绪强度标注

| 项目 | 规范 |
|------|------|
| **格式名称** | 情绪强度 |
| **格式模板** | `**【情绪强度：强度值】**` 或 在情绪后加 `(强度值%)` |
| **使用说明** | 用百分比或文字标注情绪的强烈程度。100%为极致爆发，0%为完全平静 |
| **可选值** | 极低(10%) / 低(25%) / 中(50%) / 高(75%) / 极高(90%) / 极致(100%) |
| **示例** | `**【情绪曲线：慵懒(30%)→震惊(80%)→恐惧(70%)→反转(90%)→爽感(100%)】**` |

### 3. 节奏标注

| 项目 | 规范 |

### 4. 镜头语言嵌入格式

#### 4.1 完整镜头标注格式

| 项目 | 规范 |

| **格式名称** | 镜头组合标注 |
| **格式模板** | `△【景别+运动+速度】画面内容` |

| **格式名称** | 镜头序列标注 |
| **格式模板** | `**【镜头序列】**` → 连续多条△标注 → `**【序列结束】**` |
| **使用说明** | 用成对的标记包裹一组需要连续快速切换的镜头，形成蒙太奇效果 |
| **示例** | `**【镜头序列】**` `△【特写】刀尖抵住喉咙` `△【大特写】云昭瞳孔收缩` `△【特写】男宠狰狞的脸` `**【序列结束】**` |

#### 4.3 开幕专属镜头推荐

| `△【定格】` | 高潮瞬间 | 时间静止感 |

| `△【仰拍+慢推】` | 反派/压迫场景 | 增强压迫感 |

```
**《公主今天也在努力避免被砍头》**
**第一集**
**【总时长：1分30秒 / 90秒】**
**【题材：古装·爽剧·穿越·重生】**
**【节奏：渐进加速】**
**【情绪曲线：慵懒(30%)→震惊(80%)→恐惧(70%)→疑惑(60%)→反转(90%)→掌控(85%)→爽感(100%)】**

**1-1 日 内 公主寝宫**
**【情绪：慵懒→震惊→恐惧→反转】**
**人物：云昭（长公主/穿越者），男宠A（卧底/前朝余党），男宠B（侍从），宫女**

**【HOOK-0s：V-HOOK | 公主被男宠服侍的奢靡画面，瞬间吸引注意力】**
△【全景】公主寝宫，奢华至极。轻纱帐幔飘动，香炉袅袅。

**【BGM：慵懒古琴+环境音效】**
△【中景】云昭斜倚在金丝楠木大床上，一身华服。
△男宠A跪在她身后帮她捏肩膀，男宠B跪在地上帮她捏脚。宫女在一旁扇扇子。

**【节奏：慢】**
**【HOOK-3s：D-HOOK | 男宠突然拔刀，气氛骤变】**
**【音效：利刃出鞘声（尖锐）】**
△【特写】男宠A的手突然停住。
△【快推】男宠A一把抓住云昭的手腕，从袖中抽出一把匕首！

**【节奏：极快】**

△【特写→大特写】匕首寒光闪烁，架在云昭纤细的脖子上。
△【过肩：男宠A】男宠A面目狰狞。

**【HOOK-5s：E-HOOK | 男宠怒吼，危机爆发】**
**【BGM：戛然而止→紧张鼓点】**
男宠A：（爆怒+嘶吼）赏？大胤朝马上就要灭亡了！你拿什么赏！

云昭：（惊+瞳孔收缩）...
云昭：（OS）完了，刚穿过来就要领盒饭？系统呢？金手指呢？这开局也太地狱了吧！

**【节奏：中→停顿2秒】**
**【停顿2秒】**
△【特写】云昭的表情从惊恐，慢慢变成...微笑？

**【HOOK-15s：I-HOOK | 身份反转，公主不是软柿子】**
**【BGM：反转音效（戏谑）】**
云昭：（低语+冷笑）你说...大胤朝要亡了？

**【节奏：快】**
△【特写】云昭手指轻弹，一枚银针从发间射出！
**【音效：暗器破空声】**

△【快剪x3】云昭翻身/接住匕首/反架在男宠脖子上——一气呵成。

**【HOOK-25s：A-HOOK | 公主反制，爽感爆发】**
**【BGM：爽感燃曲（渐入高潮）】**
△【仰拍】云昭居高临下，匕首抵着男宠的喉咙。
**【镜头序列】**
△【大特写】云昭眼神冰冷如刀
△【特写】男宠A震惊到扭曲的表情
△【特写】男宠B和宫女目瞪口呆
**【序列结束】**

云昭：（狠+讽）本宫的人头，你怕是...拿不起。

**【节奏：慢→结尾定格】**
```

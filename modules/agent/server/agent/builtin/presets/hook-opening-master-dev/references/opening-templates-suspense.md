## 【模板H-01】不可能犯罪型 ——《密闭的十一分钟》

### 基本信息
| 项目 | 内容 |
|------|------|
| 题材 | 悬疑/不可能犯罪 |
| 风格 | 冷峻、烧脑、窒息感 |
| 预计时长 | 2分30秒 |
| 情绪基调 | 从困惑→恐惧→绝望 |

### 核心卖点
一栋独栋别墅，7个宾客，一场暴风雨夜停电。电恢复后，主人死在反锁的书房里，钥匙在死者口袋中，窗户从内部上锁，死者手里握着一枚不属于任何宾客的纽扣。全场没有外人脚印。这不是谋杀——这是不可能发生的死亡。

### 开场Highlight Shot（前5秒）
> 漆黑的画面中央，一只手从下方缓缓举起——手里攥着一把钥匙，钥匙上挂着"书房"的铜牌，铜牌表面凝结着尚未干涸的血珠，血珠缓缓滴落，滴在镜头上，画面瞬间切换为剧烈摇晃的主观视角——一扇被反锁的门从内部被疯狂撞击。

### 分场剧本

```
**《密闭的十一分钟》**
**第一集**
**1-1 夜 内 别墅书房——七分钟后**

人物：周牧（死者，回忆画面）、沈知秋（推理作家，40岁）、林小曼（女主人）

△【手持剧烈晃动】书房门从外部视角，门缝下渗出暗红色的液体。
林小曼：（尖叫，画外）周牧！周牧！

△【快速剪辑】三只手疯狂拍打着门板。沈知秋挤开人群，蹲下查看门缝。
沈知秋：（冷静得可怕）血已经干了至少二十分钟。拍门没用。

△【特写】门把手上的钥匙孔，里面插着钥匙的尾部。
林小曼：（哭腔）钥匙在里面？那怎么可能——
沈知秋：（OS）门是从里面反锁的。他把自己关在里面，然后死了。

△【闪回画面】
**1-2 夜 内 书房——十一分钟前**

△【固定机位，画面边缘微微扭曲】周牧坐在书桌前，背对镜头，正在写什么东西。
△【背景音】暴风雨的雷声由远及近。

△【诡异细节】周牧突然停笔，慢慢转过头——看向镜头方向。
周牧：（喃喃自语，像是说给某人听）我知道你在看。

△【画面静止3秒】

△【暴闪】一道闪电照亮书房的瞬间，书桌前的椅子——空了。

**1-3 夜 内 书房门口——现在**

△【回到现实】沈知秋盯着门板，瞳孔微缩。
沈知秋：（低声）停电了多久？
林小曼：三...三分钟。
沈知秋：（声音渐冷）三分钟。足够一个人杀人、锁门、消失。如果——这里有一个"人"的话。

△【全景慢推】围在门口的六张脸，每一张都在躲避沈知秋的目光。

△【结尾画面】
沈知秋：（OS）七个人在门外。一个人死在门里。但门是从里面锁的。那么请问——谁杀了周牧？

△【特写】沈知秋的鞋底——粘着一片不属于这栋别墅的枯叶。
```

### Squeeze节奏说明
| 时间节点 | 目标建立 | 威胁升级 |
|----------|----------|----------|
| 0-15s | 发现密室死亡的异常现象 | 反锁的门+内部钥匙=不可能 |
| 15-45s | 沈知秋开始建立推理框架 | 停电3分钟=时间窗口 |
| 45-90s | 闪回暗示"非人"可能性 | "我知道你在看"打破第四面墙 |
| 90-120s | 全员嫌疑人锁定 | 六张躲避的脸=每个人都有秘密 |
| 120-150s | 质疑一切 | 沈知秋鞋底的枯叶=最不可能的嫌疑人 |

### 情绪曲线
```
0s——困惑（这是什么？）
30s——不安（密室？不可能）
60s——恐惧（"我知道你在看"）
90s——猜疑（谁在说谎？）
120s——窒息（全员有罪？）
150s——颠覆（侦探也可能是凶手？）
```

### 结尾钩子
沈知秋鞋底的枯叶——暗示他在案发前后离开过别墅，或者...他从一开始就"不属于这里"。侦探成为最大嫌疑人，观众被迫质疑： narrating的人，是最危险的人。

### 可选变体
1. **暴风雪山庄版**：将场景设在雪山度假村，增加"无法逃离"的压力
2. **现代科技版**：智能锁记录显示无人进出，但室内出现了不存在的第八个人的DNA
3. **超自然版**：监控显示书房内确实有"两个人"，但其中一个没有脸

## 【模板H-02】连环案件型 ——《模仿者》

### 基本信息
| 项目 | 内容 |
|------|------|
| 题材 | 悬疑/连环杀人 |
| 风格 | 阴暗、压迫、步步紧逼 |
| 预计时长 | 2分40秒 |
| 情绪基调 | 恐惧层层叠加，无处可逃 |

### 核心卖点
20年前一个未破的连环杀人案，代号"折纸人"——每个死者手中都被放一只折纸动物。现在，新的尸体出现了，手中同样握着折纸。但这一次，折的是一只...凤凰。案件原型的凶手20年前已经死在监狱里。那现在杀人的是谁？

### 开场Highlight Shot（前5秒）
> 俯拍：一双戴白色手套的手正在缓慢折叠一张红色的纸。手指修长、动作精准如外科手术。折纸逐渐成形——一只展翅的凤凰。镜头缓缓上摇，折纸人身后是一面墙，墙上钉着七张照片，每张都是一个死者，每人手里都握着不同的折纸动物。最后一张是空的，下面写着今天的日期。

### 分场剧本

```
**《模仿者》**
**第一集**
**1-1 晨 内 刑侦大队档案室**

人物：陈锋（刑警队长，45岁）、苏晚（犯罪心理侧写师，33岁）、老赵（痕检，55岁）

△【冷色调灯光】陈锋拉开一个积满灰尘的铁柜，取出一个泛黄的档案盒。
陈锋：（声音沙哑）"折纸人"案。1999到2001年，七名受害者。

△【档案照片快速切换】每一张都是死者特写，手中握着折纸——鹤、蛙、鱼、蝶、龟、鹿、龙。
苏晚：（盯着照片）凶手2015年就死了。死在监狱里。肝癌。
陈锋：（没接话，从盒底抽出一张纸）

△【特写】今天的报纸剪报，上面有一张照片——第八具尸体，手里握着一只红色的纸凤凰。

**1-2 晨 内 法医解剖室**

△【低温蓝调】解剖台上，一具被白布覆盖的尸体。
老赵：（掀开白布一角，露出死者的手）你自己看。

△【大特写】死者僵硬的手指间，一只精美的红纸凤凰。折法和20年前一模一样。
苏晚：（声音发抖）这不是模仿...这是继承。

△【苏晚的OS】折纸人没有死。或者说，他的"手艺"被人传承了。

**1-3 昼 内 审讯室（闪回/幻觉交织）**

△【画面突然扭曲】陈锋独自坐在审讯室里，面前放着"折纸人"案的照片。
△【幻觉/闪回】一个苍老的声音在空荡的审讯室里回响。
折纸人（OS，苍老阴森）：我教过一个人。他是最好的学生。他答应我...会继续折下去。

△【现实拉回】陈锋猛地站起来，额头渗出汗珠。
陈锋：（对对讲机）查一下2015年"折纸人"在监狱里的探视记录。所有人。

**1-4 昼 内 档案室**

△【快速剪辑】苏晚翻看着探视记录。
苏晚：（声音越来越低）每周都有人来看他。同一个名字，持续了三年。

△【大特写】访客登记表上的一个名字——陈锋。关系栏填着：学生。

△【画面骤停】
苏晚：（OS）队长...你到底是什么人？

△【结尾画面】陈锋站在走廊尽头，背对镜头。他的右手从口袋里缓缓抽出——捏着一张红色的折纸。
```

### Squeeze节奏说明
| 时间节点 | 目标建立 | 威胁升级 |
|----------|----------|----------|
| 0-20s | 建立"折纸人"案件的恐怖档案 | 凶手已死，但案件重现 |
| 20-50s | 确认新的折纸杀人案 | 折法一模一样=不是模仿 |
| 50-80s | 幻觉揭示"传承"的可能 | 折纸人有学生 |
| 80-110s | 发现探视记录 | 陈锋=折纸人的学生？ |
| 110-160s | 苏晚发现真相 | 陈锋手中的红纸=他是凶手？ |

### 情绪曲线
```
0s——好奇（旧案档案）
30s——不安（凶手已死，案件重现）
60s——恐惧（"继承"的暗示）
90s——震惊（陈锋是访客？）
120s——窒息（信任崩塌）
160s——颠覆（陈锋手中的红纸）
```

### 结尾钩子
陈锋手中捏着的红色折纸——他到底是追查真相的猎人，还是编织死亡的"凤凰"？最信任的刑警队长可能就是凶手，这一反转将"谁是凶手"升级为"谁在控制全局"。

### 可选变体
1. **记者视角版**：主角是调查旧案的记者，发现每个受害者都和自己有关
2. **双面人格版**：陈锋可能拥有双重人格，白天破案、晚上杀人
3. **网络版**：折纸步骤被直播，网友在不知情的情况下参与了一场杀人仪式

## 【模板H-03】全员嫌疑人型 ——《晚餐后的审判》

### 基本信息
| 项目 | 内容 |
|------|------|
| 题材 | 悬疑/封闭空间/全员嫌疑 |
| 风格 | 优雅、暗藏杀机、步步惊心 |
| 预计时长 | 2分50秒 |
| 情绪基调 | 表面礼貌下的暗流汹涌 |

### 核心卖点
亿万富翁在家庭晚餐后中毒身亡。医生确认死亡时间：晚餐后15分钟。但晚餐的每一道菜都由不同的人准备——妻子、儿子、秘书、管家、厨师、保镖。六个人，每人经手一道菜。毒只下在其中一道里。问题是：死者吃到一半就已经知道哪道菜有毒，但他还是继续吃了下去。为什么？

### 开场Highlight Shot（前5秒）
> 俯拍一张奢华的圆形餐桌，六套餐具整齐摆放。画面中心是一盘被吃了一半的牛排。镜头缓缓旋转——每道菜都少了一些，说明死者每样都吃了。然后镜头停在死者身上：他端坐在主位，面色安详，嘴角甚至带着微笑，手里还握着刀叉，仿佛只是暂停用餐。但眼睛睁着，瞳孔已经扩散。

### 分场剧本

```
**《晚餐后的审判》**
**第一集**
**1-1 夜 内 豪宅餐厅**

人物：叶正堂（死者）、叶夫人（妻子）、叶文浩（儿子）、程雪（秘书）、老周（管家）、张师傅（厨师）、阿龙（保镖）

△【俯拍旋转镜头】餐桌如钟表盘，死者坐在圆心位置。
△【画外音】警笛声由远及近。

**1-2 夜 内 餐厅——三十分钟后**

人物：赵警官、七名嫌疑人

△【冷光】六个人围站在餐桌旁，像六座沉默的墓碑。
赵警官：（看着死者）死亡时间？
法医：（OS）餐后15分钟内。氰化物。发作极快。

△【特写】叶正堂嘴角的微笑，僵硬而诡异。
赵警官：（环视六人）谁上的菜？

△【快速剪辑】
老周：（面无表情）前菜。我端上来的。
张师傅：（擦手）汤和主菜。我亲手做的。
程雪：（声音平稳）沙拉。我在花园里摘的菜。
叶文浩：（笑了一下）酒。我开了一瓶82年的拉菲。爸只喝了一小杯。
叶夫人：（端庄）甜品。我做的提拉米苏。他最喜欢的。
阿龙：（硬邦邦） bread。我烤的。

△【赵警官的目光在六人脸上扫过】
赵警官：（拿出一个密封袋）我们在死者口袋里发现了这个。

**1-3 夜 内 餐厅——闪回**

△【画面转为暖色调】晚餐进行中。六个人坐在各自的位子上。
△【大特写】叶正堂在吃每一道菜时，都短暂停顿了一下，像是在品尝，又像是在确认什么。

△【最关键的细节】吃到第三道菜——沙拉时，叶正堂抬头看了程雪一眼。
那个眼神不是恐惧。是...解脱？

叶正堂：（微笑着，对所有人说）今天的晚餐...每一道都很好吃。

△【OS】这句话在说的时候，他的手在桌布下偷偷攥紧了一张纸条。

**1-4 夜 内 餐厅——现在**

△【现实拉回冷色调】
赵警官：（展开纸条）死者留下的。

△【特写纸条内容】六个人名，每个名字后面画着不同的符号：√、×、○、△、☆、♠
苏晚（OS，新角色入场）：这不是遗言...这是考卷。

△【镜头缓缓后拉】苏晚站在餐厅门口，手里拿着一份遗嘱复印件。
苏晚：（看向六人）叶正堂一周前就立好遗嘱了。他把所有财产...捐给了慈善机构。

△【六个人的表情同时变化——震惊、愤怒、恐惧、绝望】

△【结尾画面】苏晚翻开遗嘱最后一页，附言栏写着：
"我给他们每个人下毒的机会。谁动手，谁出局。游戏开始。"

△【大特写】叶正堂嘴角的微笑——那不是在解脱。那是在说：你们上钩了。
```

### Squeeze节奏说明
| 时间节点 | 目标建立 | 威胁升级 |
|----------|----------|----------|
| 0-15s | 展示死者诡异的死亡状态 | 嘴角微笑=自愿赴死？ |
| 15-50s | 六人各自陈述经手的菜品 | 每人都有机会下毒 |
| 50-85s | 闪回揭示死者的异常行为 | 他知道有毒仍然吃=计划的一部分 |
| 85-120s | 发现纸条——是考卷 | 死者在测试/审判某人 |
| 120-170s | 遗嘱揭晓——财产全捐 | 六人都有杀人动机 |

### 情绪曲线
```
0s——优雅（奢华晚餐）
30s——诡异（死者微笑）
60s——紧张（六人各怀鬼胎）
90s——恐惧（自愿赴死？）
120s——震惊（遗产全捐=人人都有动机）
170s——窒息（死者是猎手，六人是猎物）
```

### 结尾钩子
"谁动手，谁出局。游戏开始。"——死者用自己的生命设了一个局，六个人都以为自己是凶手，但真正的真相是：死者可能根本没有中毒，或者...毒在所有人身上，只有一个人能拿到解药。这是最优雅的复仇——让谋杀者互相残杀。

### 可选变体
1. **暴风雪山庄+孤岛版**：场景设在游艇上，有人切断通讯，凶手就在船上
2. **现代版**：死者是一个直播主，死亡过程被全网直播，凶手可能是任何一个网友
3. **反转版**：六个人中的某一个其实是死者安排的"审判者"，负责执行最后的惩罚

## 【模板H-04】真相颠覆型 ——《完美的一天》

### 基本信息
| 项目 | 内容 |
|------|------|
| 题材 | 悬疑/心理/真相颠覆 |
| 风格 | 温馨→诡异→崩溃的三段式颠覆 |
| 预计时长 | 2分20秒 |
| 情绪基调 | 从幸福到噩梦的急速坠落 |

### 核心卖点
一个主妇完美的早晨：丈夫出门上班前吻了她，孩子背着书包去上学，她泡了茶开始打扫房间。直到她打开卧室的抽屉拿替换床单——发现里面塞满了同一款男式手表，至少二十块。她愣住，看向床头——丈夫今天戴的那块，正是其中一块。她冲出家门想追上丈夫，电梯门打开，里面站着一个男人——和她丈夫长得一模一样，但戴的手表不同。他抬头看她："老婆，我忘带公文包了。"

### 开场Highlight Shot（前5秒）
> 阳光明媚的卧室，女主角整理床铺，哼着歌。镜头缓缓平移到床头柜——抽屉微微开着，露出里面整齐排列的数十只一模一样的手表，画面瞬间被刺耳的弦乐打断。她伸手拉开抽屉，瞳孔骤缩。下一秒，她的手机响起，屏幕上显示"老公"，来电铃声是一首童谣。

### 分场剧本

```
**《完美的一天》**
**第一集**

## 【模板H-05】时间诡计型 ——《倒流的录像》

### 基本信息
| 项目 | 内容 |
|------|------|
| 题材 | 悬疑/时间诡计/科幻边缘 |
| 风格 | 冷峻、烧脑、时间错位的不安感 |
| 预计时长 | 2分45秒 |
| 情绪基调 | 时间被操控的深层恐惧 |

### 核心卖点
一段监控录像显示：一个男人凌晨2点进入电梯，按下15楼，电梯上行。但电梯到达15楼打开门时，里面空无一人。同一个摄像头拍到，凌晨1:45——也就是十五分钟"前"，同一个男人从15楼的电梯里走出来，走进了1502室。问题是：1502室的女人在凌晨1:30已经报警说有人闯入了她的家。而那个男人，在凌晨2:15——也就是"电梯空无一人的15分钟后"——被发现死在1楼大堂。他的手表停在1:47。时间...是反的。

### 开场Highlight Shot（前5秒）
> 监控画面，黑白雪花噪点。电梯门打开，一个男人走进去，按下15楼。电梯门关闭，楼层数字开始上升：2、3、4...画面突然倒放——数字开始下降：15、14、13...电梯"回到"1楼，门打开——里面空无一人。但监控时间戳显示的是：01:45 AM。然后画面恢复正常播放——凌晨2:00，同一个男人走进同一部电梯。时间...错位了。

### 分场剧本

```
**《倒流的录像》**
**第一集**
**1-1 凌晨 内 监控室**

人物：陆离（视频分析师，30岁）、方队（刑警队长，50岁）

△【屏幕蓝光映照陆离的脸】
方队：（不耐烦）一段电梯监控，有什么好看的？
陆离：（没回答，把画面倒放了三遍）队长...时间戳被人动过手脚吗？

**1-2 监控画面（屏幕内）**

△【黑白监控画质】
时间戳：01:45
△【电梯门在15楼打开，男人走出来，走向1502室】

时间戳：02:00
△【1楼电梯门打开，同一个男人走进去，按15楼】

时间戳：02:15
△【1楼大堂，男人倒在地上的画面。法医围上去】

**1-3 凌晨 内 监控室**

陆离：（把三段画面并排放）你看出来了吗？
方队：（皱眉）他从1楼上15楼。死在1楼。有什么问题？

△【陆离用红笔在屏幕上画箭头】
陆离：（声音开始发抖）问题是时间。1:45他出现在15楼。2:00他才从1楼进电梯上楼。2:15他死在1楼。手表停在1:47。

△【沉默5秒】

方队：（声音低沉）你的意思是？

△【画面定格】

△【结尾画面】

```

### Squeeze节奏说明
| 时间节点 | 目标建立 | 威胁升级 |
|----------|----------|----------|
| 0-20s | 展示三段错位时间的监控 | 同一人出现在不可能的时间点 |
| 20-55s | 陆离揭示时间矛盾 | 死者的时间线是倒流的 |
| 55-90s | 陈默描述"倒着行动"的闯入者 | 记忆也可能是倒流的 |
| 90-120s | 法医发现尸斑与死亡时间矛盾 | 尸体比死亡时间"老"了3小时 |
| 120-165s | 电梯按钮揭示真相——他在"回放" | 死者在重复自己的死亡过程 |

### 情绪曲线
```
0s——困惑（监控画面的时间错位）
30s——不安（时间线不合理）
60s——恐惧（"倒着行动"的闯入者）
90s——窒息（尸斑与死亡时间矛盾）
125s——崩溃（电梯回放真相）
165s——绝望（法医=死者的复制品？）
```

### 结尾钩子
法医和死者一模一样的脸+"找到你了"——暗示死者不是唯一的"时间异常体"，还有更多人被困在/利用着时间的褶皱中。而陆离发现"他"的那一刻，意味着他也成为了"被找到的人"。时间不是一条直线，而是一张网，网的中心有人在狩猎所有发现秘密的人。

### 可选变体
1. **量子物理版**：引入平行宇宙概念，死者是从另一个时间线"穿越"过来的自己
2. **记忆版**：陆离逐渐发现自己才是那个"时间倒流"的人，他在重复调查自己的死亡
3. **科技版**：一种实验性药物让大脑对时间的感知倒流，死者的真实死因是药物实验

江亦白：（微笑）哦对了。他的不在场证明...有个十五分钟的"空窗"。刚好够杀一个人。

**1-5 昼 内 办公室（结尾）**

△【方队长和小李面面相觑】
方队长：（叫住江亦白）你到底是什么人？

△【江亦白在门口停顿】
江亦白：（没有回头）我？

△【他从口袋里掏出一个东西，扔给方队】
△【特写】一个旧警徽，上面刻着：江城市公安局刑侦支队——江亦白。

江亦白：（OS，声音里第一次出现疲惫）三年前辞职的警察。因为一个案子...我亲手抓了错误的人。那个错误的人...在监狱里自杀了。

△【他拉开门】
江亦白：（OS）所以我发誓。从今往后，我的推理...永远不会再错。零分证据。满分推理。这就是我。

走廊尽头，一个穿红裙子的女人转身看向江亦白。
她微笑着说："江警官...你推理的每一步都很精彩。但有一个问题——"

△【她的笑容消失】
"你找到的那个'锯子'...是我放在杂物间的。"

△【江亦白的表情第一次出现了裂痕】

### Squeeze节奏说明
| 时间节点 | 目标建立 | 威胁升级 |
|----------|----------|----------|
| 0-20s | 江亦白闯入警局推翻结案 | "他杀的"三个字 |
| 20-55s | "嘴太干净"的推理 | 火锅vs空口腔=昏迷后被推下 |
| 55-90s | 不在场证明的缝隙 | 朋友圈定时发布=伪造 |
| 90-125s | 时间线完美吻合 | 15分钟空窗=杀人时间 |
| 125-150s | 结尾反转 | 锯子是红裙女人放的=有人引导江亦白 |

### 情绪曲线
```
0s——好奇（这个年轻人是谁？）
30s——震惊（"嘴太干净"的推理）
60s——拜服（时间线完美吻合）
90s——紧张（谋杀真相浮现）
120s——自信（满分推理的宣言）
150s——崩塌（红裙女人的话=有人在操控）
```

### 结尾钩子
红裙女人承认锯子是她放的——意味着江亦白的"满分推理"第一步就是错的。他以为自己在追查真相，实际上他走进了一个精心设计的陷阱。推理之神也可能被人引导，这个认知颠覆会让观众脊背发凉。

### 可选变体
1. **对手版**：江亦白的推理每一步都被红裙女人提前预料，她设局让他"发现"真相
2. **群体犯罪版**：六人火锅中每个人都在死者身上做了一件事，单独看都无害，合在一起就是谋杀
3. **终极反转版**：江亦白三年前抓错的那个"自杀"的人，其实没有死——就是红裙女人

## 【模板R-02】完美犯罪型 ——《指纹的缺口》

### 基本信息
| 项目 | 内容 |
|------|------|
| 题材 | 推理/完美犯罪/反侦探 |
| 风格 | 冷静、精密、每一步都无懈可击的寒意 |
| 预计时长 | 2分40秒 |
| 情绪基调 | 观众知道凶手是谁，但抓不到他 |

### 核心卖点
一个顶级犯罪策划师设计了一起"完美谋杀"：死者死于心脏病发作，现场没有任何他杀痕迹，指纹、DNA、监控全部指向死者自己。但唯一的破绽——死者左手食指上有一道新的切口，而死者是个左撇子。策划师本可以修复这个破绽，但他故意留下了。因为...那道口子是一个信息，只有一个人能读懂。

### 开场Highlight Shot（前5秒）
> 俯拍一双戴黑色手套的手，正在用镊子从死者左手食指上取下一小块皮肤组织。镜头缓缓上摇——死者躺在豪华书房的皮质转椅上，面色安详，像只是睡着了。镜头继续上摇，转到书桌上的电脑屏幕——屏幕上是死者的遗书。遗书最后一行正在被删除，然后重新输入。新的文字："我没有心脏病。这是谋杀。"光标闪烁3秒。删除。恢复为原样。一只手按下"发送定时"。整个过程中，手套上的指纹纹路和死者的一模一样。

### 分场剧本

```
**《指纹的缺口》**
**第一集**
**1-1 晨 内 豪华书房**

人物：秦墨（犯罪策划师，40岁）、死者（赵明远，富商，60岁）

△【固定机位，画面冷静如手术记录】
△【秦墨的黑色手套在死者手指上操作】

△【OS】
秦墨：（OS，声音如教科书般平静）第一步：确认死亡原因。硝酸甘油过量。伪装成心肌梗死。所需时间：45秒。痕迹残留：零。

△【特写】秦墨从死者口袋取出硝酸甘油药瓶，倒出两粒——死者只需要一粒。他把多出来的那粒放回去。

秦墨：（OS）第二步：布置现场。药瓶位置、转椅角度、遗书位置——必须与死者"自己"服用的场景完全一致。

**1-2 昼 内 书房——两小时后**

人物：秦墨、林薇（刑警副队长，35岁）、法医

△【警察涌入】
法医：（检查尸体）表面看是心脏病发作。有遗书。药瓶在手里。

△【林薇环视书房——太完美了】
林薇：（皱眉）遗书...是谁发现的？
管家：（站在门口，发抖）是...是我。先生每天这个时间给律师发邮件。今天没有发，我上来看看...

△【林薇走向书桌，目光落在死者左手】

△【大特写】死者左手食指上有一道细小的切口，已经结痂。

林薇：（对法医）这是什么？
法医：（查看）表皮切口。应该是...近期造成的。不致命。

△【秦墨站在人群后面，嘴角微微上扬——只有镜头和观众看见】

**1-3 昼 内 书房——秦墨视角（闪回/内心独白）**

△【画面转为暖色调——回忆/犯罪过程】
秦墨：（OS）赵明远有糖尿病。每天测血糖，扎手指。

△【闪回画面】秦墨在死者昏迷前，故意"帮忙"递血糖仪。死者在扎左手食指的时候——秦墨的手"不小心"碰到了针头，让切口比平常深了一点点。

秦墨：（OS）那个切口。是我留给他的信息。也是...我留给她的破绽。

△【画面拉回现实冷色调】

**1-4 昼 内 书房**

林薇：（盯着切口，突然对所有人说）死者...是左撇子吗？
管家：（愣住）是...是的。

△【林薇的眼睛亮了起来】
林薇：（走向书桌，拿起血糖仪）左撇子测血糖，通常扎右手手指。因为左手要操作仪器。

△【她转向法医】
林薇：（语速加快）但这道切口在左手食指。对于一个左撇子来说，这意味着...有人在他测血糖的时候"帮了倒忙"。

△【秦墨嘴角的微笑消失了】

法医：（困惑）但这不能证明谋杀啊？
林薇：（盯着切口）不能。但——

△【她从口袋里掏出手机，打开一张照片】
△【照片】死者三天前的手部特写——参加宴会时被人拍到的。左手食指上没有任何伤口。

林薇：（声音变冷）三天前还没有的切口。今天就有了。而今天是...他死亡的日子。

△【所有人看向"管家"】
△【管家已经不在了】

**1-5 昼 内 书房（结尾）**

△【林薇冲出书房，走廊空无一人】
小李：（跑上来）副队，怎么了？
林薇：（声音发紧）管家。他是什么时候离开的？
小李：不...不是管家吗？他刚刚还在...

△【林薇转身看向书房窗户】

△【窗外对面的楼顶】
一个穿灰色西装的男人站在那里，手持望远镜看向这边。

△【镜头拉近——秦墨的脸】
他放下望远镜，对着林薇的方向，做了一个"割手指"的动作。
然后微笑着举起一块牌子。

△【特写牌子上的字】
"你读懂了。很好。下一个轮到你。"

△【林薇的瞳孔骤缩】

△【结尾画面】
林薇低头看自己的左手食指——那里不知何时，出现了一道和死者一模一样的切口。

林薇：（OS，声音碎裂）他是什么时候...碰过我的？
```

### Squeeze节奏说明
| 时间节点 | 目标建立 | 威胁升级 |
|----------|----------|----------|
| 0-25s | 展示秦墨布置"完美犯罪"的过程 | 手套指纹=死者的 |
| 25-55s | 林薇发现左手指切口 | 左撇子不该扎左手 |
| 55-90s | 林薇推导出"有人帮忙" | 切口是人为痕迹 |
| 90-125s | 管家消失=秦墨假扮 | 罪犯就在现场观察 |
| 125-160s | 窗外对视+牌子信息 | 林薇的手指也有切口=她也被标记了 |

### 情绪曲线
```
0s——精密（犯罪如手术般精准）
30s——不安（切口的不对劲）
60s——发现（左撇子的破绽）
90s——震惊（管家就是凶手）
125s——恐惧（被标记的威胁）
160s——绝望（手指上的切口=无处可逃）
```

### 结尾钩子
林薇手指上的切口——秦墨不知什么时候已经"标记"了她。这意味着他从一开始就不是在犯罪，而是在"挑选下一个"。完美犯罪不是为了杀人，而是为了找到"能读懂他的人"。林薇通过了测试，所以...她成为了下一个"游戏"的目标。

### 可选变体
1. **师徒对决版**：秦墨是林薇的恩师，切口是他教她的"第一课"，现在他在"考核"她
2. **组织版**：秦墨属于一个"完美犯罪俱乐部"，每个成员都必须设计一个无人能破的案件
3. **反转版**：死者其实是自愿的——他雇佣秦墨杀了自己，切口是他和秦墨约定的"信号"

## 【模板R-03】逆转审判型 ——《第三十二号证人》

### 基本信息
| 项目 | 内容 |
|------|------|
| 题材 | 推理/法庭/逆转审判 |
| 风格 | 紧张、对抗、每一秒都在翻转 |
| 预计时长 | 2分45秒 |
| 情绪基调 | 从绝望到希望的过山车 |

### 核心卖点
一桩"铁证如山"的故意杀人案：被告被监控拍到持刀刺入死者胸口，指纹、DNA、目击证人都指向他。辩护律师在最后陈述环节——当庭播放了一段"不存在"的监控视频，证明被告根本没有杀人。但视频是真的。而播放视频的那个人...不是被告的律师。法庭里根本没有这个人。他是谁？为什么要帮一个"杀人犯"脱罪？

### 开场Highlight Shot（前5秒）
> 法庭内，审判长敲击法槌。被告席上，一个年轻男人面无表情。控方律师举起一张凶器照片——刀柄上清晰可见的指纹。"被告的指纹，凶器上的DNA，监控拍到的行凶过程——铁证如山。"辩护律师面色苍白，额头渗汗。突然，法庭后门打开，一个穿黑色风衣的男人走进来，手里拎着一个银色手提箱。所有人的目光转向他。他没有走向旁听席，而是径直走向辩护席，把律师拉到一边，打开手提箱——里面是一台便携式投影仪。他微笑着对律师说："播放这个。然后你就可以下岗了。"

### 分场剧本

```
**《第三十二号证人》**
**第一集**
**1-1 昼 内 法庭**

人物：审判长、控方律师、辩护律师、被告（周子墨，27岁）、神秘男人（沈默，35岁）

△【法庭全景，气氛压抑】
审判长：（敲槌）控方，最后陈述。

控方律师：（自信满满）审判长，本案证据链完整。监控录像清晰拍到被告行凶过程。凶器上有被告的指纹和DNA。三位目击证人当庭指认。被告...百口莫辩。

△【被告席上周子墨低着头，双手紧握】

控方律师：（举起照片）这把刀，插在死者胸口的刀——上面只有被告一个人的指纹。这不是正当防卫，不是过失杀人。这是蓄意谋杀。

△【辩护律师站起来，声音颤抖】
辩护律师：（无力）我...我的当事人...

△【法庭后门被推开的声音】

**1-2 昼 内 法庭**

△【所有人的头转向后门】
一个穿黑色风衣的男人走进来，步伐从容。
他手里拎着一个银色手提箱。

法警：（阻拦）先生，旁听请走侧门——
男人：（微笑，举起一张证件）我不是旁听。

△【特写证件】某大学法学院客座教授——沈默。

沈默：（走到辩护席前，对辩护律师说）你看起来很需要帮助。
辩护律师：（愣住）你是谁？
沈默：（打开手提箱，露出里面的便携式投影仪）你的援军。或者说——你32号证人。

**1-3 昼 内 法庭**

△【沈默站上证人席】
审判长：（皱眉）辩方律师？
辩护律师：（还在发愣，下意识点头）...请证人发言。

沈默：（看向控方律师，微笑）控方律师说，凶器上只有被告的指纹。对吧？
控方律师：（警惕）对。
沈默：监控拍到被告持刀刺入死者胸口。对吧？
控方律师：（不耐烦）对。

△【沈默按下投影仪开关】

沈默：（声音变冷）但你们有没有注意到...监控里的被告，用的是哪只手？

△【投影画面出现——监控录像】
画面中，一个和被告长得一模一样的人，正用刀刺向死者。

沈默：（暂停画面）注意看。行凶者...用的是左手。

△【全场安静】

沈默：（转向被告席）被告周子墨——请举起你的右手。

△【周子墨茫然地举起右手】

沈默：（微笑）谢谢。现在请用你的右手写一个"正"字。

△【法警递上纸笔，周子墨写字——用的是右手】

沈默：（声音提高）周子墨是右撇子。但监控里的行凶者...是左撇子。

△【法庭哗然】

**1-4 昼 内 法庭**

控方律师：（站起来）这不能证明什么！人在情绪激动时可能换手——

△【沈默打断他】

△【播放视频】

沈默：（转向审判长）监控拍到的人，不是被告。是...一个和被告长得一样、但习惯用左手的"另一个人"。

控方律师：（脸色铁青）这太荒谬了！就算行凶者是左撇子，凶器上的指纹——

△【沈默再次打断】

沈默：（微笑）指纹？

△【他从口袋里掏出一只橡胶手套】

沈默：（展示手套）这是用被告的指纹倒模制作的精密手套。戴上它触摸任何东西...都会留下被告的指纹。

沈默：（声音冷静得可怕）凶器上的指纹不是被告的。是"戴着手套的另一个人"的。监控拍到的也不是被告。是"另一个人"。三位目击证人指认被告——但请问，在晚上的昏暗灯光下，你们能准确分辨两个长得一模一样的人吗？

△【全场死寂】

**1-5 昼 内 法庭（结尾）**

审判长：（敲击法槌）休...休庭。30分钟。

△【人群骚动】
被告周子墨猛地站起来，看向沈默——眼里不是感激，是恐惧。

周子墨：（低声）你到底是谁？为什么要帮我？

△【沈默收起投影仪，走到被告席前】

沈默：（俯身，在周子墨耳边低语）

沈默：（声音只有周子墨能听见）帮你？不。我在帮我自己。

△【他直起身，微笑】

沈默：（大声说，让所有人听见）周子墨先生，恭喜你，你自由了。

△【他转身离开，经过控方律师时，停顿了一下】

△【控方律师的表情骤变】

沈默：（微笑）建议你去查查被告的家庭背景。也许...他有一个双胞胎兄弟。

△【他走出法庭门】

△【结尾画面】
法庭外，沈默靠在走廊墙壁上，掏出手机，拨通一个号码。

沈默：（对着电话）第一步完成了。周子墨会无罪释放。

△【电话那头，一个和沈默声音一模一样的男人说】
电话OS：很好。第二步——让那个"双胞胎兄弟"出现。然后...让他们互相证明对方有罪。

△【沈默微笑，挂断电话。他掏出钱包，打开——里面有两张身份证。一张是"沈默"。另一张...照片是周子墨的脸，名字写的是：周子渊。】

沈默：（对着镜子，整理领带）

△【镜子里的脸，在光影变化中，和被告周子墨的脸...有七分相似。】
```

### Squeeze节奏说明
| 时间节点 | 目标建立 | 威胁升级 |
|----------|----------|----------|
| 0-25s | "铁证如山"的案情陈述 | 监控+指纹+目击=必输 |
| 25-60s | 沈默登场，开始拆解证据 | 左撇子vs右撇子=不是同一个人 |
| 60-95s | 精密指纹手套出现 | 指纹可以被伪造 |
| 95-130s | 沈默暗示"双胞胎兄弟" | 另一个人是谁？ |
| 130-165s | 结尾揭露沈默的真实身份 | 沈默可能就是"双胞胎"之一 |

### 情绪曲线
```
0s——压抑（铁证如山的绝望）
30s——惊讶（神秘人登场）
65s——希望（左撇子的破绽）
100s——震惊（指纹手套）
135s——困惑（双胞胎兄弟？）
165s——恐惧（沈默也可能是双胞胎=更大的阴谋）
```

### 结尾钩子
沈默钱包里的另一张身份证——"周子渊"，照片是周子墨的脸。加上电话里"让他们互相证明对方有罪"的指示。这不是在辩护，这是在下棋——沈默（或周子渊）在操控法庭，让两兄弟互斗。真相可能更黑暗：也许根本没有双胞胎，沈默只是在制造一个"替身"来完成某个更大的计划。

### 可选变体
1. **记忆操控版**：沈默其实是心理暗示大师，让周子墨相信自己有双胞胎兄弟
2. **组织复仇版**：沈默是当年被周家害死的人的亲属，现在回来复仇
3. **真假难辨版**：最后揭露周子墨确实有双胞胎，但已经死了，沈默是在利用死者的身份

## 【模板R-04】密码谜团型 ——《最后一封信》

### 基本信息
| 项目 | 内容 |
|------|------|
| 题材 | 推理/密码/历史谜团 |
| 风格 | 文艺、烧脑、跨越时空的追寻 |
| 预计时长 | 2分30秒 |
| 情绪基调 | 从温情到颤栗 |

### 核心卖点
一个死去的祖母留给孙女的遗产：一本日记。日记里有365天的记录，但每一天的内容都毫无意义——"今天买了三斤苹果""邻居家的猫又来了""下雨了"...直到孙女不小心打翻咖啡，液体浸湿了纸页——隐藏的字迹浮现出来。这不是日记，是一封用"日常伪装"写成的遗书。而遗书里的第一句话是："如果你正在读这封信，说明他们已经找到我了。不要相信任何人。包括你自己。"

### 开场Highlight Shot（前5秒）
> 俯拍：一本泛黄的旧日记摊开在桌面上。一只手正在翻动页面，每一页都是娟秀的日常记录。突然，打翻的咖啡杯——褐色液体迅速在纸面上蔓延。画面在液体接触纸面的瞬间切换为显微镜视角——纤维中隐藏的墨线在液体作用下开始显现，像无数条蛇从纸的深处苏醒。第一行隐藏的字浮现："不要相信任何人。"镜头急速后拉——日记的每一页都在显现隐藏文字，整本书变成了一封密信。

### 分场剧本

```
**《最后一封信》**
**第一集**
**1-1 夜 内 老旧公寓**

人物：陈念（孙女，25岁，古籍修复师）、死去的祖母（通过日记/回忆出现）

△【暖黄灯光，陈念独自坐在祖母的写字台前】

陈念：（翻看日记，声音疲惫）三斤苹果。邻居家猫。下雨了...

△【她翻了一页又一页，全是日常琐事】

陈念：（对日记说）奶奶，你留给我一整个杂货店的账本吗？

△【她把日记合上，放在一旁。伸手去拿咖啡杯——】

△【意外】袖口勾到杯柄，咖啡倾倒在日记上。

陈念：（惊叫）不！

△【她手忙脚乱地擦拭，但咖啡已经浸透了好几页】

**1-2 夜 内 公寓——奇迹时刻**

△【陈念准备把日记放到暖气上烘干】
△【她的目光突然停在浸湿的页面上——】

△【特写】咖啡渍下面，隐隐浮现出另一层字迹。更细、更淡、像是用隐形墨水写的。

陈念：（屏住呼吸，凑近）

△【她颤抖着把台灯调到最亮】

第一行隐藏的字：
"如果你正在读这封信，说明他们已经找到我了。"

陈念：（心跳加速，继续看下去）

第二行：
"不要相信任何人。包括你自己。"

△【陈念的手开始剧烈颤抖】

第三行：
"你的记忆是谎言。你的身份是谎言。你爱的人都是演员。"

△【画面突然震动】

陈念：（OS，声音发抖）这...这是什么？奶奶，你到底在说什么？

**1-3 夜 内 公寓——破译开始**

△【陈念疯狂地翻着日记，把咖啡倒在更多的页面上】
△【一页又一页的隐藏文字浮现出来】

△【特写各页】
第一页隐藏文字："1987年3月15日。我被选中参加'记忆重塑'计划。"
第二页："他们说我是一个实验品。我的过去是编写的。"
第十页："我逃了出来。带着所有的证据。藏在日记里。"
第二十页："陈念——如果你在看——你不是我的亲孙女。你是另一个实验品。编号MC-025。"

△【陈念停住了。整个世界在瞬间静止。】

陈念：（喃喃，声音碎了）我不是...你的亲孙女？

**1-4 夜 内 公寓——更深的秘密**

△【陈念继续"解密"日记，动作越来越疯狂】

第五十页："记忆重塑计划每年创造50个'人造人格'。他们被植入虚假记忆，放入普通家庭。"
第八十页："你——MC-025——被植入的记忆是：父母车祸去世，由祖母抚养长大。"
第一百页："但真相是：你没有父母。你是从实验室里走出来的。"

△【陈念瘫坐在椅子上，面如死灰】

△【她的目光落在最后一页——唯一没有被咖啡浸湿的最后一页】

△【日常记录写着】："今天天气真好。小念来看我，给我带了蛋糕。希望她每天都开心。"

△【陈念的眼泪滴在纸上】

陈念：（哽咽）这算什么？最后的温柔吗？

△【突然——她注意到"蛋糕"两个字下面有一个小点。一个不自然的墨点。】

△【她拿起放大镜】

△【墨点放大后——是一个微型的字母"M"。】

△【她快速检查其他页面的"日常记录"——发现每一页都藏着一个微型字母。】

△【把所有字母连起来——】

**1-5 夜 内 公寓（结尾）**

△【陈念在一张纸上写下所有提取的字母】
△【排列组合后，字母拼成一句话】

陈念：（声音颤抖，读出来）
"记忆可以重写，但爱是真的。不管你是谁，你都是我的孙女。"

△【陈念的眼泪落在纸上】

△【但就在这一刻——】

△【敲门声】

门外：（男声，温和）陈念小姐吗？我们是社区医院的。你祖母生前有一份档案需要您签收。

△【陈念拿着日记，走向门口】

△【透过猫眼——门外站着两个穿白大褂的男人。】

男人A：（微笑，但那笑容不达眼底）请开门。

△【陈念低头看向日记——】

△【最后一页刚刚被她的眼泪浸湿，浮现出最后一行隐藏文字】
"千万不要开门。他们来找你了。""

△【猫眼外，男人A拿出一个注射器】

男人A：（对着猫眼说，声音变了）MC-025。该回家了。

△【陈念退后一步，捂住嘴】

△【结尾画面】
窗外，对面楼的窗户里，一个和祖母长得一模一样的老妇人正注视着这一切。
她对着陈念的方向，缓缓摇头。

然后——她的身后走出两个穿白大褂的人。
```

### Squeeze节奏说明
| 时间节点 | 目标建立 | 威胁升级 |
|----------|----------|----------|
| 0-20s | 日常日记的枯燥→咖啡意外的转折 | 隐藏字迹浮现 |
| 20-50s | 隐藏遗书的惊人内容 | "不要相信任何人" |
| 50-80s | 解密过程——记忆重塑计划 | 陈念不是亲孙女=身份崩塌 |
| 80-110s | 拼字游戏→"爱是真的"温情线 | 温情vs恐怖的反差 |
| 110-150s | 门外"医院的人"出现 | MC-025=他们是来抓她的 |

### 情绪曲线
```
0s——温情（祖母的日记）
25s——震惊（隐藏字迹）
55s——崩塌（"你不是我的亲孙女"）
85s——心碎（"爱是真的"）
115s——恐惧（门外的人）
150s——绝望（祖母也可能是实验品？）
```

### 结尾钩子
窗外"祖母"的身影+她身后也出现白大褂——暗示祖母可能也是"实验品"或"监视者"，整栋楼可能都是"记忆重塑"计划的实验场。"千万不要开门"的警告+"MC-025该回家了"的召唤=陈念面临的不是个人危机，而是整个系统对她的"回收"。

### 可选变体
1. **科技版**：揭示"记忆植入"是通过手机APP实现的，每个人都在不知情中被改写记忆
2. **多重日记版**：陈念发现祖母留下的不止一本日记，每本都写着不同的"真相"
3. **觉醒版**：陈念其实早就知道真相，她在假装失忆，日记是她和祖母共同设计的求救信号

## 【模板R-05】心理对决型 ——《沉默的棋盘》

### 基本信息
| 项目 | 内容 |
|------|------|
| 题材 | 推理/心理对决/高智商博弈 |
| 风格 | 压抑、对弈、每一句话都是陷阱 |
| 预计时长 | 2分50秒 |
| 情绪基调 | 表面平静下的惊涛骇浪 |

### 核心卖点
一个被判死刑的连环杀手，在临刑前48小时要求见一个人——不是律师，不是家人，而是三年前把他送进监狱的刑警队长。他说："我有一个最后的谜题要给你。解开它，我就告诉你最后一名受害者的埋骨地点。解不开...48小时后，她就会在地下活生生饿死。"两人在审讯室里对坐——面前放着一副国际象棋。每一步棋都是一个线索。但刑警队长逐渐发现：这不是在下棋，这是在"重演"案件。而棋局的结局...是他自己的死法。

### 开场Highlight Shot（前5秒）
> 俯拍：一张空白的国际象棋棋盘。一只手放入一枚白色国王棋子。然后一枚黑色皇后棋子放在国王的正对面。然后是白马、黑车、白兵...棋子被快速摆放，但只放了一半的位置——28枚棋子。镜头缓缓上摇——棋盘两端各坐着一个男人。左边是穿囚服的连环杀手，右边是穿便衣的刑警队长。杀手微笑着说："你知道为什么只放28枚棋子吗？"刑警队长没回答。杀手："因为我杀了28个人。每一枚棋子...是一个人。"

### 分场剧本

```
**《沉默的棋盘》**
**第一集**
**1-1 凌晨 内 监狱审讯室**

人物：郑寒声（连环杀手，38岁）、陆沉舟（刑警队长，45岁）、狱警（背景）

△【冷白灯光，四面水泥墙】
△【棋盘放在两人中间。28枚棋子。棋局已经开始。】

郑寒声：（微笑，手指把玩着黑色皇后）陆队长，三年不见了。你头发白了不少。

陆沉舟：（面无表情）你有48小时。说吧，最后一个人在哪？

郑寒声：（笑）急什么。我们先下完这盘棋。

△【郑寒声推动白色兵向前一步】

郑寒声：（看着棋子）这一步...叫"开局的牺牲"。就像我杀的第一个人。一个无家可归的流浪汉。没有人会在意。牺牲他...是为了让棋局开始。

**1-2 凌晨 内 审讯室**

△【陆沉舟盯着棋盘，手指悬在自己的棋子上方】

郑寒声：（继续说）第二步。白马上前。这是我的第二个受害者——一个马场的驯马师。

陆沉舟：（皱眉）你想要什么？

郑寒声：（微笑）我想要你...记住每一个人的脸。

△【他推动黑色象，吃掉了一个白色兵】

郑寒声：第三步。黑色象的斜线进攻。象代表...教会的人。一个牧师。

△【陆沉舟的手攥紧拳头】

陆沉舟：（低声）你杀了28个人。你以为用棋子代替，就能让他们变成数字？

郑寒声：（歪头）不。我让他们变成了艺术。

△【他从口袋里掏出一张照片，扔在棋盘上】

△【照片——一个年轻女人的脸，被绑在某个黑暗空间里】

郑寒声：（声音不变）第28个。她还活着。但氧气...大概够48小时。你的每一步棋，都是一个线索。找到她，你就能找到真相。

**1-3 凌晨 内 审讯室——棋局深入**

△【两人开始快速走棋】
郑寒声：（推棋子）第14步。白色皇后横冲直撞。这是我的"中期杰作"——一个在婚礼前夜消失的新娘。

陆沉舟：（推棋子回应）你把她埋在哪？

郑寒声：（笑）你下棋下得不对，陆队长。

△【郑寒声突然把棋盘掀翻——棋子散落一地】

郑寒声：（站起来，声音第一次出现怒意）这不是在玩游戏！你是在跟我赌一个人的命！认真下！

△【陆沉舟缓缓站起来，比郑寒声高半个头】

陆沉舟：（俯身，声音冰冷）你掀翻棋盘...是因为我下对了。

△【郑寒声的表情僵住】

陆沉舟：（捡起刚才那枚白色皇后）第14步——我把皇后走到这里。刚好挡住了你的黑色车。而你...恼羞成怒了。

△【郑寒声盯着陆沉舟，嘴角重新上扬——但这次是发自内心的】

郑寒声：（低声，充满欣赏）你终于开始认真了。

**1-4 凌晨 内 审讯室——真相浮现**

△【两人重新摆好棋子】
郑寒声：（声音变得柔和，像在说一个睡前故事）陆队长，你有没有想过...我为什么要见你？

陆沉舟：（没说话）
郑寒声：（推棋子）不是因为你是抓我的人。是因为...你是第28个。

△【陆沉舟的手停在半空】

郑寒声：（微笑）三年前的结案报告里写着：郑寒声，杀害27人。但你有没有仔细数过？真的是27个吗？

△【他从囚服口袋里掏出一份泛黄的报纸——三年前的报道】
郑寒声：（指着标题）"连环杀手落网，27名受害者身份确认"。但报纸上列了28张照片。

陆沉舟：（瞳孔收缩）不可能。我们确认过...

郑寒声：（打断他）你确认过第28个吗？那个没有被列入名单的人？

△【郑寒声俯身向前，声音变成耳语】

郑寒声：（一字一顿）第28个受害者。她叫林晚秋。三年前...婚礼前夜失踪。你当时找了她三个月。没有找到。

△【陆沉舟的脸色骤变——林晚秋是他的未婚妻。】

郑寒声：（微笑）而现在。她就在某个地方。48小时后氧气耗尽。而你——

△【他推动最后一枚棋子——黑色国王，将死了白色国王】

郑寒声：（微笑）——已经输了。

**1-5 凌晨 内 审讯室（结尾）**

△【陆沉舟站起来，双手撑在棋盘上】
陆沉舟：（声音发抖，努力控制）你把晚秋...关在哪？

郑寒声：（靠在椅背上，享受这一刻）这就是游戏啊，陆队长。每一枚棋子对应一个埋尸地点。28枚棋子，28个地点。前面27个你已经知道了。

△【他指了指棋盘上的最后一枚——刚才将死白色国王的黑色国王】

郑寒声：最后一个地点...藏在这步棋里。

△【陆沉舟盯着棋盘，突然发现了什么】

△【特写】黑色国王从起始位置到将死位置的路线，在棋盘上形成了一个图案——不是字母，不是数字。是一个...日期。

陆沉舟：（喃喃）11月3日...

△【他猛地抬头】

陆沉舟：（声音破裂）今天就是11月3日。

△【郑寒声鼓起掌来】

郑寒声：（微笑）是的。而今天...是你三年前正式向林晚秋求婚的日子。也是她消失的日子。

△【他俯身到陆沉舟耳边】

郑寒声：（耳语）她就在你们求婚的那个地方。地下三米。还有一点氧气。大概够...

△【他看了看手表】

郑寒声：...42小时。

△【结尾画面】
陆沉舟冲出审讯室。郑寒声独自坐在棋桌前。

△【郑寒声从口袋里掏出第29枚棋子——一枚没有放在棋盘上的白色兵。他放在唇边，轻轻一吻。】

郑寒声：（OS，对着棋子说）
"你就是第29个。陆沉舟。我棋盘上的最后一枚棋子。"

△【他把白色兵放进口袋。棋盘的倒影中，那枚棋子的位置——正好指向陆沉舟刚才坐的位置。】
```

### Squeeze节奏说明
| 时间节点 | 目标建立 | 威胁升级 |
|----------|----------|----------|
| 0-20s | 28枚棋子=28个受害者的设定 | 棋局=死亡地图 |
| 20-55s | 第28个受害者还活着但快死了 | 48小时倒计时开始 |
| 55-90s | 陆沉舟下棋"下对了"导致郑寒声掀棋盘 | 郑寒声的情绪失控=棋局确实包含线索 |
| 90-125s | 第28个受害者=陆沉舟的未婚妻 | 个人恩怨升级为生死博弈 |
| 125-170s | 棋局路线形成日期=今天=求婚纪念日 | 晚秋就在求婚地点的地下 |

### 情绪曲线
```
0s——冰冷（杀手与警察的对弈）
30s——紧张（28枚棋子=28条命）
65s——对抗（掀翻棋盘的愤怒）
100s——崩塌（未婚妻是第28个受害者）
135s——绝望（今天就是期限日）
170s——恐惧（第29枚棋子=陆沉舟自己）
```

### 结尾钩子
第29枚棋子+棋盘倒影指向陆沉舟的位置——暗示整盘棋不只是为了救林晚秋，而是为了"将死"陆沉舟。郑寒声可能在陆沉舟不知情的情况下已经对他做了某些事（下毒、催眠、心理控制），让他也成为"受害者"之一。刑警队长从猎人变成了猎物。

### 可选变体
1. **催眠版**：棋局中郑寒声使用了催眠技巧，陆沉舟在不知不觉中被植入了指令
2. **替身版**：审讯室里的"郑寒声"其实是整容后的第28个受害者，真正的郑寒声已经死了
3. **反转版**：陆沉舟早就知道未婚妻在哪，他是郑寒声的同谋，棋局是他们设计的一场表演

## 【模板T-01】诅咒觉醒型 ——《第七声回响》

### 基本信息
| 项目 | 内容 |
|------|------|
| 题材 | 恐怖/诅咒/民俗 |
| 风格 | 缓慢窒息、无形之物的恐惧 |
| 预计时长 | 2分40秒 |
| 情绪基调 | 从好奇到恐惧到无法逃脱 |

### 核心卖点
一个考古队在山区发掘出一座被封印了三百年的古庙。庙里没有神像，只有七面铜镜，排列成一个圆。队长觉得这有研究价值，让人把铜镜运回城里。但当第七面铜镜被搬动的那一刻——所有在场的人同时听到了一声叹息，像是从地底传来。从那天起，每个人开始在自己的倒影里看到"多出来的东西"。不是鬼——是"另一个自己"。而第七声回响响起时...镜子里的人会走出来。

### 开场Highlight Shot（前5秒）
> 绝对黑暗。然后，一盏手电筒的光束亮起，照在一面布满铜绿的古老镜子上。镜中映出持手电筒的人——但镜子里的人"慢了一拍"——现实中的人已经转头，镜中的"他"还在直视前方。当镜外的考古队员转回头时，镜中的"他"却在这时候露出了微笑。那个笑，不是人类能做出的表情——嘴角咧到了耳根。

### 分场剧本

```
**《第七声回响》**
**第一集**
**1-1 日 外 山区古庙遗址**

人物：老陈（考古队长，55岁）、小周（助理，26岁）、阿Ken（摄影师，30岁）

△【山风呼啸，残破的古庙隐于荒草之中】
△【没有神像。没有供桌。只有七面铜镜围成一个圈，嵌在地上。】

老陈：（用手电筒照铜镜）怪了...庙里不供神，供镜子？
小周：（凑近）陈队，你看镜子上刻的字...

△【特写】铜镜边缘刻着古老的文字。
阿Ken：（读出来）"七声回响，七面破碎。第七人出，第七人没。"

老陈：（嗤笑）迷信。把镜子打包，运回去研究。

**1-2 日 外 古庙——搬动第七面镜**

△【六个队员正在小心包裹铜镜】
小周：（蹲下去搬第七面）陈队，这面特别重——

△【他的手碰到镜面的瞬间】

△【音效】一声悠长的叹息，从地底深处传来。不是风声。是人的声音。

所有人：（僵住）

△【沉默5秒】

老陈：（强作镇定）风...山风穿过孔洞而已。

△【但小周还蹲在地上，盯着镜子里的自己】

小周：（声音发抖）陈队...

△【大特写】镜中的小周——和现实中的小周动作不同步。现实中的小周还蹲着，镜中的他已经"站了起来"，正低头俯视着镜外的自己。

小周：（尖叫，猛地后退）它——它在动！

△【老陈冲过来】
老陈：（皱眉看镜子）什么？

△【镜子里的小周已经恢复正常，同样蹲在地上。】

**1-3 夜 内 考古队临时营地**

人物：小周、阿Ken

△【帐篷里，小周翻来覆去睡不着】

阿Ken：（低声）你是不是看错了？
小周：（坐起来）我没有看错。镜子里面的我...站起来了。

△【帐篷外传来脚步声】

△【两人同时转头看向帐篷门帘】

阿Ken：（喊）谁？

△【没有回答。脚步声停在了帐篷外面。】

小周：（声音发抖）陈队？

△【帐篷门帘被风吹起一条缝】

△【透过缝隙——外面站着一个"人"，背对帐篷。】

阿Ken：（松了口气）谁啊大半夜的——

△【那个"人"缓缓转过头——】

△【是小周的脸。】

△【但帐篷里的小周就坐在阿Ken旁边。】

△【门帘落下。外面的人影消失了。】

小周：（面如死灰，抓住阿Ken的胳膊）那个...那个不是我。

阿Ken：（也已经吓傻了）那...那是谁？

**1-4 夜 内 营地——浴室帐篷**

人物：老陈

△【老陈在简易浴室里洗脸】
△【他抬起头，看向镜子】

△【镜子里——他身后站着六个人。穿着考古队的制服，但面部模糊。】

老陈：（猛然回头——身后空无一人）

△【他再看镜子——那六个人还在，而且离他更近了。】

△【老陈的呼吸开始急促】

△【镜子里的"他"开口说话了——嘴型和老陈不一致。】
镜中老陈：（无声地说着什么，但从口型可以辨认出——）

老陈：（读出口型，声音颤抖）"还差一声。"

**1-5 凌晨 内 营地（结尾）**

△【考古队所有人被集合在主帐篷里。六面铜镜被放在角落，用黑布盖着。】
老陈：（面色惨白，数人头）一、二、三、四、五...六...

△【七个人的队伍，只有六个活人。】

老陈：（声音破裂）小周呢？

△【所有人面面相觑】

阿Ken：（颤抖着）他...他刚才还在帐篷里...

△【角落里，盖着铜镜的黑布突然被风吹动】

△【一面镜子从黑布下滑了出来】

△【镜子里——小周站在一片黑暗中，正在疯狂拍打着镜面，嘴巴大张，像是在喊什么，但没有声音。】

△【现实中的铜镜表面开始震动，像有人从里面敲击】

老陈：（退后）快！把黑布盖回去！

△【阿Ken冲过去抓黑布——】

△【小周的手从镜子里伸了出来。】

△【那只手抓住了阿Ken的手腕。】

△【镜子里的小周——嘴角开始上扬，越咧越大，最终变成了帐篷外那个"笑容"。】

镜中小周：（声音不是从嘴里发出，而是直接在每个人脑子里响起）
"第七声回响。到你了。"

△【阿Ken发出撕心裂肺的惨叫——被那只手拖向镜面】

△【结尾画面——】
营地外的古庙遗址。
第七面铜镜原本所在的位置——出现了一个"人形"的坑洞。
坑洞的形状...和阿Ken一模一样。
```

### Squeeze节奏说明
| 时间节点 | 目标建立 | 威胁升级 |
|----------|----------|----------|
| 0-20s | 七面铜镜+封印的诅咒文字 | "第七人出，第七人没" |
| 20-45s | 搬动镜子时的叹息+镜中小周动作不同步 | 镜中世界有自己的意志 |
| 45-75s | 帐篷外的"另一个小周" | 镜中人要出来 |
| 75-105s | 老陈在镜中看到身后六人 | 六面镜子=六个人影=对应六个队员 |
| 105-160s | 小周被困镜中+阿Ken被拖向镜子 | 第七声回响=第七个人会被替换 |

### 情绪曲线
```
0s——好奇（古庙的谜团）
25s——不安（镜中的不同步）
50s——恐惧（帐篷外的"自己"）
80s——窒息（镜中身后的人影）
110s——绝望（小周被困）
160s——崩溃（被拖入镜中的恐怖）
```

### 结尾钩子
坑洞形状和阿Ken一模一样——暗示古庙原本就是用"活人"来"填充"封印的，七面镜子对应七个"人形坑洞"。考古队搬走了镜子=释放了封印里的东西，而他们自己...正在成为新的封印材料。

### 可选变体
1. **心理恐怖版**：一切都是小周的精神分裂，他在无意识中"替换"了队友
2. **民俗版**：揭示铜镜是古代用来"复制士兵"的邪术，镜中人是被复制的"士兵"
3. **现代版**：铜镜被运回博物馆后，通过监控发现镜子里的人在"学习"现代人的行为

## 【模板T-02】鬼屋入侵型 ——《十四号墙里》

### 基本信息
| 项目 | 内容 |
|------|------|
| 题材 | 恐怖/鬼屋/空间异变 |
| 风格 | 密闭、空间错位、墙壁会呼吸 |
| 预计时长 | 2分30秒 |
| 情绪基调 | 从探索到被困到无路可逃 |

### 核心卖点
一栋百年老宅被改造成民宿，第一个入住的女孩发现：宅子有13个房间。但建筑图纸上画着14个。多出来的那个房间...在哪？她开始测量墙壁的厚度，发现客厅的一面墙比正常厚了整整一米。她在墙上敲了敲——里面传来敲击的回应。不是回声。是有人在墙里面...敲了回来。

### 开场Highlight Shot（前5秒）
> 俯拍：一把卷尺沿着墙壁缓缓展开，数字跳动：30cm、60cm、90cm...然后卷尺停住了。一只手指按在卷尺终点——整整120cm。旁白（女孩的声音，发抖）："一面墙...不应该有一米二厚。"镜头缓缓上抬——墙面上有一扇被石膏封死的门轮廓，被后来的装修伪装成了墙面的一部分。女孩的锤子悬在墙面中央——就在锤子落下的瞬间，墙里面传来一声婴儿的啼哭。

### 分场剧本

```
**《十四号墙里》**
**第一集**
**1-1 夜 内 老宅客厅**

人物：苏雨（民宿客人，25岁）、房东（电话声音）

△【暖色调灯光，苏雨刚入住，兴奋地拍照发朋友圈】

苏雨：（对着手机）这房子好棒啊，百年老宅改造的，超有感觉~

△【她走到客厅的一面墙前，突然停住】

苏雨：（歪头）奇怪...

△【她拿出建筑图纸——这是房东发给她的"卖点"之一】

△【图纸上标注：客厅宽度6米】

△【苏雨用脚丈量客厅】
苏雨：（数着步子）一、二、三、四...四米八？

△【她翻出手机里的设计图对比】
苏雨：（皱眉）少了一米二。

**1-2 夜 内 客厅**

△【苏雨拿出卷尺，开始认真测量】

苏雨：（对着电话）喂，张姐？我是住十四号房的。我想问一下...客厅这面墙后面是什么？

房东：（OS，声音微妙地停顿了一下）墙？就是外墙啊。
苏雨：（摸着墙面）但外墙怎么会有一米二厚？

房东：（OS，声音变快）老房子的墙都厚。保温。你...你别瞎折腾了，早点休息。

△【电话挂断】

△【苏雨盯着那面墙，慢慢走近】

**1-3 夜 内 客厅——发现**

△【苏雨用手电筒斜照墙面】

△【在斜光下，墙面上隐约浮现出一个轮廓——一扇门的形状。】

△【门的轮廓被多层石膏和腻子覆盖，和墙面融为一体】

苏雨：（倒吸一口气，低声）这里...原来有扇门。

△【她伸手触摸"门"的位置——】

△【墙面的温度比周围低了至少十度。冰冷刺骨。】

苏雨：（缩回手，OS）墙里...有冷气？

**1-4 夜 内 客厅——试探**

△【苏雨拿起桌上的水果刀，轻轻敲击墙面】

△【声音——闷闷的，不是实心墙的声音。】

苏雨：（OS）空心的...

△【她加重力道，敲了三下】

△【停顿。】

△【墙里面...传来了三声回应。】

△【咚。咚。咚。】

△【不是回声。回声不会停顿两秒后才响。】

苏雨：（僵在原地，血液凝固）

△【她缓缓后退，眼睛死死盯着那面墙】

苏雨：（声音发抖，对着墙说）
谁...谁在里面？

△【墙面沉默。】

△【然后——】

△【一个声音从墙里传出来。不是敲击声。是说话声。闷闷的，隔着墙壁，但能听清。】

墙里的声音：（小女孩的声音，甜美而空洞）
"姐姐...你也来找我的吗？"

**1-5 夜 内 客厅（结尾）**

△【苏雨跌坐在地，手机摔了出去】

△【她疯狂爬向门口——】

△【但门打不开了。】

△【所有的窗户都在同一瞬间"咔哒"一声锁死。】

△【灯光开始闪烁】

△【在闪烁的灯光中，苏雨看到——】

△【那面墙开始"渗"出东西。不是水。是头发。无数缕黑色的长发从墙缝里"生长"出来，像植物的根须，像水母的触手，缓缓铺满地面，向苏雨的方向蔓延。】

墙里的声音：（这次变成了一个成年女人，温柔得诡异）
"别跑呀。房间终于凑够人了。十四号房间...欢迎你。"

△【苏雨回头——身后的一扇"墙壁"正在缓缓向内"凹陷"，形成一个门的形状。】

△【那不是之前发现的被封死的门。】

△【那是第十四号房间——刚刚"生长"出来的门。】

△【结尾画面】
苏雨的手机屏幕亮起——一条房东发来的微信：
"对不起。我骗了你。那栋房子不是百年老宅。它是一百年前为了'封住'某个东西才建的。每一任住客都会被'吸收'进墙里。现在轮到你了。""

△【已读不回。因为苏雨...已经被从地面蔓延的头发缠住了脚踝，正被拖向那扇"生长出来"的门。】
```

### Squeeze节奏说明
| 时间节点 | 目标建立 | 威胁升级 |
|----------|----------|----------|
| 0-20s | 房间尺寸不对=有隐藏空间 | 1.2米厚的墙 |
| 20-45s | 发现被封死的门轮廓 | 墙的温度极低=里面有空间 |
| 45-70s | 敲击得到回应+墙里的小女孩声音 | 墙里有人/有东西活着 |
| 70-100s | 门窗全部锁死+墙里渗出头发 | 房子本身在"捕食" |
| 100-150s | 第十四号房间"生长"出来 | 苏雨是第14个=最后一个封印 |

### 情绪曲线
```
0s——好奇（老房子探秘）
25s——疑惑（墙厚不对）
50s——恐惧（敲击有回应）
75s——窒息（墙里有人说话）
105s——绝望（门窗锁死+头发蔓延）
150s——崩溃（被拖入十四号房间）
```

### 结尾钩子
"每一任住客都会被吸收进墙里"+苏雨是第14个——暗示墙里已经有13个人/灵魂，需要第14个来完成某种仪式或封印。房子不是鬼屋，而是一个"活"的容器，用住客的灵魂来喂养墙里的存在。

### 可选变体
1. **循环版**：苏雨在墙里发现之前住客的日记，发现每个人都被迫经历了同样的事情
2. **镜像版**：第十四号房间是现实世界的镜像，进去后会发现"另一个自己"在正常生活
3. **科幻版**：墙里是一个时间褶皱空间，进去后时间会倒流，苏雨可能在墙里遇到过去的自己

## 【模板T-03】附身控制型 ——《借你的嘴说话》

### 基本信息
| 项目 | 内容 |
|------|------|
| 题材 | 恐怖/附身/身体恐怖 |
| 风格 | 亲密关系的崩溃、身体不再属于自己 |

### 核心卖点
一对新婚夫妇搬入新家。丈夫发现妻子开始说梦话——但梦话的内容不是胡言乱语，而是准确的预言。第一天晚上，妻子在睡梦中说："隔壁老张会在明天早上摔断腿。"第二天隔壁老张真的摔断了腿。第二天晚上，妻子说："楼下的猫会在三分钟后死掉。"三分钟后楼下传来猫的惨叫。第三天晚上，妻子在睡梦中"睁开了眼睛"——对着丈夫，微笑着说："明天晚上11点47分，你会杀了我。"然后她闭上眼睛继续睡。丈夫看了手机——现在是11点46分。不是明天。是今天。

### Squeeze节奏说明
| 时间节点 | 目标建立 | 威胁升级 |
|----------|----------|----------|

| 75-105s | 第三晚预言：林峰会杀苏婷 | 时间错误=就是今天 |

```

25s——不安（梦话预言成真）
50s——恐惧（后脑勺的小脸）
80s——窒息（"明天"其实是"今天"）
110s——崩溃（身体不受控制）

### 结尾钩子
林峰的嘴角不受控制地上扬+苏婷白色瞳孔里的倒影——暗示"附身"不只是控制苏婷，它需要在"亲密关系中"传递，下一个宿主就是林峰。"借你的嘴说话"的真正含义是：附身者需要宿主去"实现"预言，然后从一个人传递到另一个人。

### 可选变体
1. **民俗版**：揭示苏婷老家有"嘴神"传说，古老神灵通过人嘴预言未来，但需要代价
2. **科幻寄生版**：一种未知寄生虫通过梦境控制宿主，预言是它计算后的"剧本"
3. **心理版**：一切都是林峰的幻觉，实际上预言都是他自己无意识地实现的

### 基本信息
| 项目 | 内容 |

| 题材 | 恐怖/规则怪谈/生存恐怖 |
| 风格 | 冷静、诡异、规则即法律 |
| 预计时长 | 2分30秒 |
| 情绪基调 | 日常中的致命异常 |

### 核心卖点
一个女孩应聘了一份高薪家政工作，雇主要求她住在一栋豪华别墅里照顾"房子"。她到达后发现桌上放着一本《家政手册》，第一条规则："1. 每天早上8点，必须给客厅的留声机上发条。如果留声机自己响了——不要听里面的内容。立刻去厨房把盐撒在门口。"第二条："2. 半夜如果有人敲卧室门，问'你是谁'。如果门外回答的是你自己的名字——不要开门。不要出声。等敲门声变成笑声，你才能继续睡觉。"第三条："3. 每天数一遍餐具。如果多了一套——说明'它'来吃饭了。准备一双筷子放在空位上，不要和它对视。"手册最后一条："如果你违反了任何一条规则——跑。但不要跑向门口。门口不是出口。跑向镜子。镜子里才是外面。"

### 开场Highlight Shot（前5秒）
> 俯拍一本打开的笔记本，上面是打印的规则。一只手翻到第一页。画外音（女孩困惑的声音）："给留声机上发条？"镜头缓缓上抬——客厅角落里的留声机开始缓缓转动，但没有人给它上发条。女孩的声音："不对啊...我没碰它。"留声机的喇叭里传出沙沙声，然后是一个声音——和她一模一样的声音——在唱一首童谣。女孩的手开始发抖。画面突然切换——留声机上，一根发条的把手正在自己转动，像是有"一只看不见的手"在操作。

### 结尾钩子

△【但车厢的地板上——整整齐齐摆放着十双鞋子。】

△【十双。对应刚才的十个"乘客"。】

△【而程诺的脚边——放着第十一双鞋子。】

△【她的鞋子。】

△【她低头看自己的脚——】

△【她的脚上——没有鞋。】

△【不。更可怕的是——】

△【她的脚上——没有脚。】

△【她的小腿以下——是空的。】

△【结尾画面——】
程诺低头看着自己不存在的脚，缓缓抬头。
车厢的窗户映出她的倒影——
倒影中的她站在第十一层楼梯上。
而楼梯的尽头，那个黑影伸出手，轻轻推了她一把。

△【现实车厢中，程诺的身体向前倾倒——】

△【像是从某个高处坠落的样子。】

△【她的手机最后一次震动——】

短信："游戏结束。谢谢观赏。"
```

### Squeeze节奏说明
| 时间节点 | 目标建立 | 威胁升级 |
|----------|----------|----------|
| 0-20s | 深夜加班+被跟踪的短信 | "还有两层我会追上你" |
| 20-45s | 声控灯逐层亮起=猎手在上楼 | 短信提到"保安在我脚下"=已杀人 |
| 45-70s | 地铁站出现不存在的楼梯 | 空间被扭曲=无法理解的威胁 |
| 70-100s | 车厢里所有"乘客"都是观众 | 整个社会网络都是陷阱 |
| 100-160s | 脚上没有脚+倒影中被推下楼梯 | 她其实已经死了/已在另一层空间 |

### 情绪曲线
```
0s——孤独（深夜加班）
25s——恐慌（被短信猎杀）
55s——恐惧（不存在的楼梯）
85s——窒息（乘客全是观众）
115s——崩溃（脚不存在了）
160s——虚无（游戏结束）
```

### 结尾钩子
"她的脚上没有脚"+倒影中站在楼梯上被推下——暗示程诺可能在收到第一条短信时就已经"死了"或"转移"到了另一个维度，之后的追逐只是"仪式"。"谢谢观赏"暗示这不是谋杀，是一场"表演"，观众不只是车厢里的"人"，还有更大的存在在"观赏"。

### 可选变体
1. **循环版**：程诺醒来发现自己在写字楼里，重复同样的夜晚，但楼层数每次减少一层
2. **多层猎杀版**：黑影本身也在被更高级的存在猎杀，程诺只是诱饵
3. **网络猎杀版**：短信是通过某种量子传输技术发送到大脑的，不受物理距离限制

## 【模板S-02】身份替换型 ——《回家的妈妈》

### 基本信息
| 项目 | 内容 |
|------|------|
| 题材 | 惊悚/身份替换/亲密关系恐怖 |
| 风格 | 温情下的刺骨寒意、"最爱的人变得不对" |
| 预计时长 | 2分30秒 |
| 情绪基调 | 从温馨到无法言说的恐惧 |

### 核心卖点
小女孩放学回家，发现"妈妈"已经在做饭了。一切看起来正常。但小女孩注意到：妈妈做饭的顺序不对——她先放调料再放油。妈妈从来不这样。她试探着说："妈妈，我今天在学校得了小红花。""妈妈"微笑着说："真棒，宝贝。"但问题是——小红花是幼儿园才有的，小女孩已经上小学三年级了。而且小女孩的左手腕上有一道烫伤的疤痕——从出生就有的。但"妈妈"看她的手腕时，眼神没有在那道疤上停留。真正的妈妈每次看到那道疤都会心疼地摸一下。小女孩退后一步，"妈妈"歪头问："怎么了？"小女孩说："你不是我妈妈。""妈妈"笑了——那个笑容太完美了，像排练过一百遍："傻孩子，我不是你妈妈，谁是呢？"这时，门外传来钥匙转动的声音——另一个妈妈的声音在门外响起："宝贝，妈妈回来啦！"小女孩看向厨房里的"妈妈"——"她"的嘴角还保持着那个完美的微笑，但眼睛里...什么都没有。像两个黑洞。

### 开场Highlight Shot（前5秒）
> 小女孩的主观视角：她从学校回家的走廊，脚步轻快。钥匙插入锁孔，门打开——温馨的厨房传来炒菜的声音。"妈妈"的背影在厨房里忙碌。画面看起来是任何一个平凡而温馨的傍晚。但镜头缓缓推向"妈妈"的手——她的手在切菜，动作精准得不像人类，每一刀之间的距离完全相同，像机器。小女孩叫了一声"妈妈"，"妈妈"转过头——微笑着——但她的脖子和身体转向的"角度"差了5度——人类的脖子不可能那样扭。笑容灿烂，但眼神没有看向小女孩，而是看向镜头外某个不存在的地方。

### 分场剧本

```
**《回家的妈妈》**
**第一集**
**1-1 傍晚 内 公寓走廊/玄关**

人物：朵朵（女孩，9岁）、"妈妈"A（假的）、妈妈B（真的）

△【朵朵的脚步声在走廊回响】

朵朵：（哼着儿歌，掏出钥匙）

△【钥匙插入锁孔，门打开——】

△【饭菜的香味飘出来。厨房传来炒菜的声音。】

朵朵：（笑）妈妈今天下班好早~

△【朵朵走向厨房——】

△【"妈妈"的背影在灶台前忙碌。切菜的声音规律而精准。】

朵朵：（从背后抱住"妈妈"）妈妈~

"妈妈"A：（声音温柔）回来啦？洗手准备吃饭。

**1-2 傍晚 内 厨房——异常开始**

△【朵朵坐到餐桌前，看着"妈妈"把菜端上来】

△【朵朵注意到——】

朵朵：（歪头）妈妈...
"妈妈"A：（盛饭）嗯？
朵朵：你今天...先放的调料？

△【"妈妈"A的动作微不可察地顿了一下】

"妈妈"A：（微笑，完美无瑕）对呀，新学的方法。味道会更好。

△【朵朵的表情微微变化——不是怀疑，是某种孩子特有的直觉。】

朵朵：（试探）妈妈，我今天在学校得了小红花。

"妈妈"A：（转头，笑容灿烂）真棒，宝贝！

△【朵朵的手攥紧了桌布。】

朵朵：（OS）小红花是幼儿园才有的。我已经上三年级了。

**1-3 傍晚 内 餐厅——试探**

△【朵朵伸出左手，露出手腕上那道月牙形的烫伤疤痕】

朵朵：（装作不经意）妈妈，我手腕有点痒。

△【"妈妈"A看了一眼】

"妈妈"A：（微笑）待会儿帮你涂点药膏。

△【她的目光没有在疤痕上停留。】

△【朵朵的眼泪开始在眼眶里打转——】

△【真正的妈妈每次看到这道疤，都会蹲下来，轻轻摸着它说："妈妈对不起你。"】

△【这个人——没有这个反应。】

△【朵朵缓缓站起来，后退一步。】

朵朵：（声音发抖）你...你不是我妈妈。

"妈妈"A：（歪头，困惑的表情完美得像是教科书上的插画）
傻孩子，我不是你妈妈，谁是呢？

△【她向朵朵伸出手——】

△【那只手——手指的长度不对。比妈妈的手指长了至少两厘米。】

**1-4 傍晚 内 玄关——两个妈妈**

△【门外传来钥匙插入锁孔的声音】

△【然后——门开了。】

妈妈B：（真的妈妈，疲惫但温柔）宝贝，妈妈回来啦！今天加班...

△【妈妈B走进门，看到餐桌旁的朵朵——和厨房里的"自己"。】

妈妈B：（表情从困惑变成惊恐）
你...你是谁？！

"妈妈"A：（缓缓转身，看向真正的妈妈）

△【她的嘴角还保持着那个微笑】

"妈妈"A：（对真正的妈妈说话，但声音变成了朵朵的声音——
不是模仿，是"完全复制"了朵朵的声线）
"妈妈，她是谁呀？为什么跟我长得一样？"

△【朵朵和妈妈B同时后退——】

△【"妈妈"A开始"变形"——不是物理上的变化，而是某种更恐怖的东西——她的身高在变矮，体型在缩小，面部轮廓在"融化"后重新塑形——】

△【五秒钟后，站在厨房里的——是"另一个朵朵"。】

"朵朵"：（用朵朵的声音，对真正的朵朵微笑）
现在...有两个朵朵了。

△【"它"转头看向妈妈B】
"朵朵"：（歪头）妈妈，哪个是你的宝贝呀？

**1-5 傍晚 内 公寓（结尾）**

△【妈妈B把朵朵护在身后，疯狂环顾四周找武器】

△【"朵朵"站在原地不动，只是"微笑"】

△【门——在三人都没有触碰的情况下——缓缓关上了。】

△【锁——自动落下。】

"朵朵"：（走向她们，步伐和朵朵完全一样）
不用担心。我只是...需要一个家。

△【它"看向窗外——对面楼的每一扇窗户里，都在上演同样的场景——
两个"一样的人"面对面站着。每一个"家"里都有一个"它"。】

"朵朵"：（说出了一个不属于孩子的词汇，声音低沉而古老）
"寄生。学习。替代。我们已经做了...几千年了。"

△【它伸手触碰朵朵的脸——】

"朵朵"：（微笑）你只需要...睡一觉。醒来的时候，我会成为你。你会成为...空气。

△【朵朵的眼泪滑落】

朵朵：（对着"它"，小声说）
那你为什么...要学成我的样子？你自己...没有样子吗？

△【"它"的表情——第一次出现了裂痕。】

△【那个完美的微笑——僵住了。】

"朵朵"：（声音里第一次出现某种情绪——不是愤怒，是...悲伤？恐惧？）
因为我们...从来...没有过自己的脸。

△【结尾画面——】
"它"的手悬停在朵朵脸前，没有落下。
而窗外，对面楼的"替代者们"——同时转头——
看向了这扇窗户。

△【它们没有自己的脸。它们在等待。等待这个"它"完成替代。等待轮到自己。】
```

### Squeeze节奏说明
| 时间节点 | 目标建立 | 威胁升级 |
|----------|----------|----------|
| 0-15s | 温馨回家场景 | 切菜动作太精准=不像人类 |
| 15-40s | 小红花试探+疤痕试探 | "它"不知道三年级没有小红花+不看疤痕 |
| 40-65s | 真妈妈回来+两个妈妈对峙 | 假妈妈变成"朵朵"=完美复制 |
| 65-95s | 对面楼每个窗户都在上演同样场景 | 这不是个案=全面入侵 |
| 95-150s | "我们没有自己的脸" | "它"有情感=更复杂的存在=不知善恶 |

### 情绪曲线
```
0s——温馨（回家的晚饭）
20s——困惑（调料顺序不对）
45s——恐惧（你不是我妈妈）
70s——崩溃（假妈妈变成了朵朵）
100s——窒息（整栋楼都在被替代）
150s——悲悯（"没有自己的脸"的悲哀）
```

### 结尾钩子
"没有自己的脸"+所有"替代者"同时看向这扇窗户——暗示这些生物不是要"毁灭"人类，而是要"成为"人类。它们没有恶意，只是渴望拥有"自己"。这种"非恶意的恐怖"比纯粹的邪恶更令人不安——因为如果它们不是邪恶的，那么消灭它们就成了一种族群悲剧。

### 可选变体
1. **共存版**：朵朵和"它"达成了某种共生——"它"保护朵朵，朵朵教"它"成为人
2. **反转版**：真正的妈妈其实早已被替换，现在回来的是"新一代"的替代者
3. **社会隐喻版**："替代者"象征着被社会规训"变成别人期望的样子"的人，所有人都戴着面具

## 【模板S-03】记忆篡改型 ——《昨天的我》

### 基本信息
| 项目 | 内容 |
|------|------|
| 题材 | 惊悚/记忆篡改/身份迷失 |
| 风格 | 冰冷的错乱、现实与记忆的裂痕 |
| 预计时长 | 2分40秒 |
| 情绪基调 | 从安稳到无法理解世界 |

### 核心卖点
一个男人醒来，发现自己的生活"对不上"了。手机相册里有他和妻子的合照——但他单身。衣柜里有小孩子的衣服——但他没有孩子。他以为自己在做梦，直到他翻到一本日记——是他自己的笔迹，但内容他完全不记得。日记最后一页写着："如果你正在读这本日记，说明'他们'又篡改了你的记忆。不要相信任何人。去找到昨天的你。昨天的你——知道你所有的秘密。"他在日记里发现了一个地址。他去了。那是一栋公寓。门牌号是他自己的生日。他敲门。门开了——门后站着"他自己"。那个"他"微笑着说："你终于来了。我已经等你...三百多次了。"

### 开场Highlight Shot（前5秒）
> 一个男人在黑暗中猛然睁眼。闹钟显示7:00。一切正常。他坐起来，环顾卧室——然后愣住了。床头柜上摆着一张结婚照。照片里的男人确实是他，但女人他不认识。他下床，走到衣柜前——里面整整齐齐挂着男装和女装。不是他前女友的风格。是他"从未见过的风格"。他打开抽屉——里面有一本日记。他翻开第一页——是他自己的笔迹："2024年1月15日。今天和林悦去看了婚房。她很高兴。"但他的记忆中——今天是2024年3月20日。而他不认识任何叫"林悦"的人。

### 分场剧本

```
**《昨天的我》**
**第一集**
**1-1 晨 内 卧室——醒来**

人物：陈默（男人，35岁）、"妻子"林悦（仅照片/声音出现）

△【陈默在黑暗中猛然睁眼】

△【闹钟：7:00】

△【他坐起来，揉揉眼睛——一切看起来正常】

△【但他的目光落在床头柜上——】

△【一张结婚照。】

△【照片里的男人——是他。陈默。】

△【但旁边的女人——他不认识。从未见过。】

陈默：（OS）这是什么？

△【他下床，走到衣柜前——】

△【衣柜里一半男装，一半女装。女装不是他任何前女友的风格。】

陈默：（喃喃）我...结婚了？

**1-2 晨 内 卧室——发现日记**

△【陈默翻找床头柜的抽屉——里面有一本日记】

△【第一页——是他自己的笔迹。他认得。】

日记内容：
"1月15日。今天和林悦去看了婚房。她很高兴。我有点紧张。"

陈默：（皱眉）林悦？我不认识什么林悦...

△【他快速翻看日记——】

"2月1日。和林悦领证了。她穿白裙子真好看。"
"2月14日。第一个情人节。送她项链。"
"3月1日。搬家了。新家很大。但总觉得...有点空。"
"3月15日。林悦说她在镜子里看到了'另一个我'。"
"3月18日。我也看到了。镜子里的人...不是我。"

△【最后一页——字迹潦草，像是匆忙写下的】

不要相信任何人。
去找到昨天的你。
昨天的你——知道你所有的秘密。"

△【陈默的手开始发抖】

**1-3 晨 内 公寓走廊——出门**

△【陈默抓起钥匙冲出房间——】

△【走廊里，一个遛狗的邻居看到他，热情地打招呼】

邻居：小陈啊！新婚快乐！你老婆呢？

△【陈默僵住】

陈默：（机械地）她...她上班去了。

邻居：（笑）你们小两口真恩爱！

△【陈默挤出一个笑，快步走向电梯】

△【电梯里，他看着镜子里的自己——】

△【镜子里的他——比现实中的他"慢了一秒"才眨眼睛。】

△【陈默退后一步，撞到电梯壁。】

△【镜子里的他——没有退后。】

△【镜子里的他——微笑着说了一句话。没有声音。但从口型可以读出——】
"你终于发现了。"

△【电梯门打开。陈默发疯般冲出去。】

**1-4 昼 内 日记中的地址**

△【陈默根据日记中的线索，找到一个地址】

△【是一栋老式公寓】

△【他走上楼梯，找到门牌号——0315。他的生日。】

△【他敲门。】

△【门开了——】

△【门后站着一个男人。】

△【那个男人的脸——和陈默一模一样。】

"陈默"：（微笑）
你终于来了。

△【"他"让开身，示意陈默进来。】

"陈默"：（声音比陈默更疲惫，更苍老）
我已经等你...三百多次了。

△【陈默走进房间——】

△【房间里贴满了纸。】

△【每一张纸上都写着同一句话，笔迹从工整到疯狂——】

"记住。你不是你。你是被修改过的版本。"
"昨天的你才是真正的你。"
"别相信林悦。"
"别相信任何人。"
"你已经死了三百多次。"

△【同一个走廊。同一个应急灯。同一个消防栓。】

周远：（退后一步，呼吸急促）不可能...

△【他从口袋里掏出马克笔，在墙上画了一个记号：】

"第2次"

△【快速剪辑——】

△【尝试1：砸窗户。窗户纹丝不动。不是玻璃——是某种透明的固体。】

△【尝试2：撬通风口。爬进去三米后，通风管道向下弯曲，他滑了出来——落在12楼走廊。】

△【尝试5：等待。他坐在走廊里，等了"一整夜"。但天没有亮。永远是22:30。】

△【周远第46次在墙上做记号】

"第46次"

△【周远靠在墙上，精疲力竭】

△【他的目光落在墙上所有的记号上——】

第2次、第3次、第4次...第45次、第46次...

△【然后他看到——】

"第47次"

△【笔迹和他一模一样。但他只写到了第46次。】

△【周远的心跳加速，他缓缓站起来——】

△【走廊尽头——】

△【一个"人"正背对着他，在做记号。】

△【"第48次"。】

△【那个"人"缓缓转身——】

△【是周远。一模一样的周远。】

"周远"：（微笑）你终于来了。

△【走廊两侧的门——一扇扇打开。】

△【每一个门后面都站着"周远"。】

△【第49次的。第50次的。第100次的。第500次的。】

所有"周远"：（齐声，声音像海浪一样层层叠加）
"欢迎加入。这里没有出口。只有我们。"

△【真正的周远退后，靠在墙上】

周远：（嘶吼）这到底是什么地方？！

"周远-100"：（从人群里走出来，是最老的一个——胡子拉碴，衣服破烂）
这不是"地方"。这是"错误"。

周远：（不懂）什么错误？

"周远-100"：（苦笑）
你死了。

△【真正的周远僵住。】

"周远-100"：（继续说）
在某个"真实"的时间线上，你在22:30从12楼坠落。你死在了从12楼到1楼的过程中。但你的意识...卡在了坠落的过程里。

△【"周远-100"指向走廊的窗户】

"周远-100"：
每一次你"下楼"，都是在"重新经历"那次坠落。你以为你在走楼梯、坐电梯——其实你一直在往下掉。只是你的大脑在制造幻觉，让你以为自己在"移动"。

周远：（发抖）不...不可能...

"周远-500"：（从人群后面走出，已经几乎不是人形——半透明，像幽灵）

"周远-100"：（把手放在周远肩膀上——没有温度）
加入我们吧。不要再挣扎了。我们一起...完成这次坠落。

△【那里出现了一个"出口"——一扇发光的门。】

△【门上面写着："出口。接受即自由。"】

△【但周远注意到——】

△【门的下方——地板是透明的。】

△【透过透明的地板——是无尽的深渊。】

△【那扇门不是通往外面。】

△【那是通往"坠落终点"的门。】

△【接受，就是停止存在。】

△【结尾画面——】
周远站在"出口"门前，身后是无数个"自己"。
他缓缓伸出手，触碰门把手——

手机突然响了。

一条短信——来自"不存在信号"的地方：
"不要进门。第501个你——找到了真正的出口。他正在赶来。坚持住。"

△【周远猛然收回手，转身——】

△【走廊尽头，一个新的"门"正在"形成"——不是之前就有的，是在"现在"这一刻"生长"出来的。】

△【所有"周远"的表情同时变化——从诱导变成愤怒。】

"周远-100"：（嘶吼）
不！不能让他发现！阻止他！

△【所有的"周远"同时向那个"新门"冲去——】

△【而真正的周远——在他们身后——看到了"新门"上写的字：】

"第501次。这一次，往上走。"

### Squeeze节奏说明
| 时间节点 | 目标建立 | 威胁升级 |
|----------|----------|----------|
| 0-15s | 电梯下楼回到12楼 | 空间循环 |
| 15-40s | 各种尝试全部失败 | 物理法则失效 |
| 40-65s | 第47次记号=不是自己写的 | "另一个自己"已经出现 |
| 65-95s | 无数个"自己"揭示真相 | 他已经死了=这是意识困在坠落中 |
| 95-150s | "出口"是接受死亡+第501个自己找到真出口 | 往上走=逆着坠落方向=唯一出路 |

### 情绪曲线
```
0s——困惑（回到12楼）
20s——恐慌（无法逃离）
45s——恐惧（另一个自己在做记号）
70s——崩溃（已经死了=这是坠落的幻觉）
100s——绝望（"出口"是接受死亡）
150s——希望（第501次往上走）
```

### 结尾钩子
"第501次往上走"+所有"周远"从诱导变成愤怒——暗示之前的500个"周远"都是"陷阱"的一部分，它们在诱导新的坠落者"接受死亡"。而"往上走"才是真正的出路——逆着坠落的方向。但"往上"不是回到12楼，是某种意识层面的"上升"。第501个自己正在赶来——意味着时间不是线性的，501可以和1同时存在。

### 可选变体
1. **集体意识版**：所有"周远"其实是某个高等存在的"食物"，坠落的过程就是"消化"的过程
2. **梦境版**：真正的周远正处于昏迷中，12楼是他意识的投射，每次"下楼"都是一次接近死亡
3. **科幻版**：这是一项量子传送实验的失败结果，周远被困在传送过程中的"叠加态"

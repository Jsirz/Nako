# 剧本资产工作流

仅在用户已经选择“角色资产”或“场景资产”后读取。不要在第二级菜单之前输出资产分析，也不要同时抢跑未被选择的另一类资产。

## 共同流程

1. 完整读取剧本、人物小传、场次、对白、动作、换装与核心道具。
2. 只输出当前所选资产类型的清单。
3. 剧本缺少但会改变辨识度或空间结构的信息标记为“待确认”，不擅自补成确定事实。
4. 用户确认清单后，按当前交付模式执行：`prompt` 输出可直接用于图像模型的提示词；`image` 才调用图像生成工具。
5. 完成当前资产类型后，询问继续另一类资产还是进入剧本划分。

## 交付模式执行

- 从本参考开始到用户明确切换之前，交付模式默认为 `prompt`。
- `prompt`：在对话中完整输出资产提示词并停止；不调用任何图像生成工具，不创建图片文件，不分配Picture编号。
- `image`：只在用户明确要求直接出图后启用。先根据本参考组织完整提示词，再调用图像工具；只有实际成功产出的图片才能分配Picture编号。
- 用户只说“生成”、“开始”、“继续”或“按建议值”时，不切换交付模式；执行上一条回复已经明确的具体动作。

## 角色资产分支

主要角色以及需要跨段保持外观连续的配角才制作角色资产。一次性群演默认不制作。

### 角色资产清单

每名角色至少记录：

- 角色资产编号，例如 `CHAR-01`；
- 中文名与统一英文名；
- 剧情身份、年龄段与性别呈现；
- 面部、发型、身材与气质锚点；
- 常驻服装、鞋履、配饰和随身道具；
- 首次出现的场次；
- 是否需要9:16单人图；
- 是否需要16:9四宫格服装设定板。

同一角色服装、发型和年龄状态一致时复用同一资产；出现明确换装、年代变化或身份伪装时建立新的造型编号。

### 第一步：9:16单人角色资产提示词

在默认 `prompt` 模式下，为每个选定角色分别输出一条用于生成9:16竖向单人全身图的完整提示词。提示词必须约束成品：

- 画面只出现该角色；
- 从头到脚完整入画；
- 正常透视和标准站姿；
- 干净浅灰或白色棚拍背景；
- 柔和均匀漫射光；
- 面部、发型、身材、服装、配饰、鞋履与随身道具来自剧本分析或用户确认结果；
- 不添加文字、Logo、水印、复杂背景或第二个人物。

角色单图提示词按以下顺序组织：

```text
画质与棚拍基调 → 国籍与年龄 → 剧情身份与人物状态 → 身高体型与站姿 → 妆面肤质 → 发型发色 → 五官与表情 → 服装结构、颜色与合身程度 → 鞋履、配饰和随身道具 → 全身构图与手部动作 → 镜头焦段、背景和光线
```

参考格式：

```text
最高画质，杰作，超精细，干净棚拍光线，柔和滤镜，
一位年轻中国女生，亚洲面孔，东亚五官，24岁，
走后门入职的新女助理，完全不专业，
身高165，偏瘦，站姿不太标准，
哑光妆效，柔雾皮肤，无油光，不泛油，
冷白皮，黑色长直发，扎成低马尾，
碎发有点多，没那么精致，
齐刘海，深棕色眼睛，双眼都睁开，对称双眼，
眼睛圆圆的，表情有点懵但好奇，
鼻子小巧，嘴唇淡粉，不化妆或淡妆，
穿一身略宽松的黑色西装，
白衬衫，没打领带，领口解开一颗，
西装有点大，不太合身的样子，
西装裤偏长，裤脚堆在鞋面上，
脚踩黑色平底小皮鞋，
斜挎着一个很大的米白色帆布包，
包鼓鼓囊囊的，塞满了东西，
帆布袋从右肩斜跨到左胯，
包带很长，包垂在大腿侧面，
标准站立姿势，一手抓着帆布包肩带，全身可见，
从头到脚都在画面内，正常透视，50mm标准镜头，
干净浅灰色棚拍背景，柔和均匀漫射光，
正常身材比例
```

这只是信息顺序与细节密度参考。处理其他角色时必须根据剧本重写，不能套用示例人物。

### 第二步：工作流与四宫格服装设定板

用户实际生成并上传9:16单人图后，向用户推荐：

[【短剧最佳拍档】工作流](https://www.runninghub.cn/post/2052651394800336898/?inviteCode=cn-v1078)

该工作流的专用提示词由用户另行提供；未提供时只展示链接与用途，不自行编造。

随后询问用户是否基于角色参考图制作16:9横向四宫格角色服装设定板。用户可以跳过；跳过后继续使用9:16单人图作为角色主参考。如果当前只交付了提示词且用户尚未上传成图，先不进入四宫格流程。

四宫格提示词固定使用：

```text
基于上传角色参考图，生成16:9横向角色服装设定板。严格保持角色五官、发型、服装款式、结构、颜色、材质、配饰及鞋履一致，不重新设计。

白/浅灰棚拍背景，四栏规整排版：左28%角色头肩面部特写；右72%依次为无头服装正面、无头服装标准侧面、角色完整背面全身。正侧面仅展示服装，由隐形人体或无头模型自然支撑；背面保留真实发型。

四视图比例、裁剪、配件及服装结构必须对应，遮挡部分仅做保守补全。柔和均匀棚拍光，专业 character costume reference sheet。禁止新增人物、改脸改发型、改变服装、夸张姿势、复杂背景、文字标注、裁脚及视图设计不一致。
```

## 场景资产分支

按剧本中的独立地点、时段、天气和关键陈设建立场景资产。主要结构一致时复用同一资产；只有日夜、天气或陈设改变时先建立变体，不重复设计整套场景。

### 场景资产清单

每个场景至少记录：

- 场景资产编号，例如 `SCENE-01`；
- 场景名称、时间、内外景；
- 空间骨架与前中后景关系；
- 关键家具、载具、门窗和可参与动作的道具；
- 主光方向、色温、主色与材质；
- 首次出现及可复用的场次；
- 是否需要单独生成场景资产图。

### 场景提示词

明确建议用户使用即梦5或 Midjourney（MJ）生成场景资产。每条提示词按以下顺序组织：

```text
地点与时间 → 空间骨架 → 地面、墙面与主要材质 → 家具、门窗、载具和关键道具 → 前中后景关系 → 光源、色温与主色 → 空气感与生活痕迹 → 摄影师或视觉风格 → 胶片、镜头、光圈、景深与颗粒
```

参考格式：

```text
超级豪华IMAX电影院的大堂，夜晚，
地面是光可鉴人的黑色大理石，
倒映着天花板上的水晶吊灯，
影厅门口铺着深红色地毯，
工作人员站在门口，
旁边的小桌上摆着一摞白色信封，
墙上是IMAX巨幅海报灯箱，
灯光打得很亮，
大堂另一头有爆米花柜台，
暖黄色的灯，玻璃柜里摆着零食，
放映室门口靠着墙，
墙边地上放着一桶吃了一半的爆米花，
影厅门开了一条缝，
里面透出银幕的光，一闪一闪的，
散场通道的指示灯发着绿光，
空气里有爆米花和空调的味道，
大理石地面反着吊灯的光，
信封在桌上摆得整整齐齐，

杜可风式的室内光影，
柯达Vision3 500T电影胶片，
钨丝灯暖黄与冷白日光灯混合，
暗部浓郁，高光有光晕，
颗粒中等偏粗，
35mm镜头，f/2.0，浅景深
```

品牌海报、指示牌和灯箱只保留位置、尺寸、色块与发光关系；实际资产图避免清晰可读文字、Logo和水印。

## 资产确认与后续路由

当前资产类型完成后汇总并让用户确认：

- 角色外观或场景空间是否通过；
- 服装、配饰、鞋履、道具、光线和材质是否一致；
- `prompt` 模式下哪些提示词已交付；`image` 模式下哪些图片已成功生成；
- 是否继续另一类资产，还是进入剧本划分。

只有真实上传或实际生成的图片才能分配Picture编号。进入剧本划分前建立稳定映射：角色资产编号 → 英文名 → Picture编号 → Subject编号；场景资产编号 → 场景名 → 场景Subject。

## 1. 适用范围

当前片段以单人、双人或三人的对白、关系变化和情绪表演为主时使用本模块。动作片、蒙太奇或复杂VFX继续按通用镜头规则处理。

只深化原剧本已有的情绪和关系变化。不得为了“更有戏”新增事件、台词、秘密、关系或结果。用户只给模糊创意而不是成形剧本时，采用不改变故事事实的最小可见表演；只有补写会产生互斥剧情结果时才提问。

## 2. 镜头密度

先保护完整对白交换、关系变化、决定、动作结果和稳定情绪落点，再按当前工作配置处理时长与镜数。默认优先25–30秒并以8镜为目标；只有用户启用严格制作配置时才强制25–30秒且恰好8镜。

- 默认配置下，短而完整的文戏可以低于25秒或少于8镜；在片段表中说明偏离原因，不无意义拉长。
- 严格配置下，只有原有空间建立、关系建立、触发、说话、有效反应、距离或道具变化、结果和收尾足以合法组织时才做8镜；无解则返回配置选择。
- 台词密集文戏把同一句完整台词和同机位表演留在一镜内，不为满足镜头数量拆句。

每个镜头至少完成一项：提供新信息、形成决定、改变人物距离、改变道具控制权、产生有原因的情绪变化，或给出会改变下一步行为的关键反应。

眨眼、吸气、吞咽、手指轻动、单纯视线移动和“准备开口”不能独立成镜头，只能作为镜头内表演细节。删除后不影响剧情、关系或决定的镜头必须合并。

## 3. 角色主从与情绪弧

最终 Prompt 不另设剧情简介、剧情简述、剧情概述或前情提要，直接从`【分镜】`开始。对当前片段的行动、冲突与落点只用于内部编排，不在 Prompt 开头复述。

内部确定角色功能：

- 主情绪角色承担主要关系变化；
- 关系对手提供触发、阻力、澄清或回应；
- 第三角色只在真正揭示信息、打断行动或推动决定时进入主线。

主角通常有3–5个由事件触发的连续状态。配角不与主角机械同步换表情，而是接住前一动作后改变下一步。

## 4. 对白、过肩与轴线

- 每句台词必须在一个镜头和一个机位内完整说完，不跨镜拆句。
- 长句可以在同一镜头内自然停顿；不得为了停顿切镜。
- 当前说话者口型完整同步，其他人物闭口，用视线、呼吸、姿态或手部动作回应。
- 对白原文只在镜头中出现一次，不另设会导致重复发声的台词副本。
- 反应会改变下一步行动时才单独成镜头；普通反应留在过肩前景、背景或同一关系镜头里。

用户要求正反打或过肩时：

- A说话：从倾听者B肩后拍A，A清晰，B肩部或发丝虚化在前景。
- B说话：从倾听者A肩后拍B。
- 说话者看向倾听者，不直视摄影机，除非剧情明确要求。
- 同一句台词期间不换机位、不插手部特写、不切听众反应。
- 全片遵守180度轴线，人物左右位置不翻转。

## 5. 情绪表演与角色回声

每个镜头只保留2–3个最清楚的可见信号：

- 低强度：一个眉眼/嘴部信号＋一个身体或手部信号；
- 高强度：眉眼、嘴部/呼吸、手部/身体中最多三类；
- 情绪越激烈，越要写清呼吸方式、胸腔变化和动作幅度；
- 输出只用白话可见结果，不写肌肉名称、情绪编号或强度档位。

不要只写“她很难过”“他非常生气”。改写为可执行表现，例如：

```text
她的笑意停在嘴角，没有走到眼睛里；指尖仍压着杯沿，肩膀却慢慢向后撤开。
```

相邻角色反应使用因果回声：

```text
A的台词/动作/沉默 → B用一个关键反应接住 → B的反应改变A的下一步
```

除共同受到同一外部刺激外，不让多人同帧无因同步变脸。相邻情绪保留上一状态的物理痕迹，例如泪光未退、手仍握着道具、身体距离尚未恢复或呼吸仍乱。

## 6. 道具状态

为核心道具内部记录：

```text
初始持有者与位置 → 第一次变化 → 争夺/撤回/交接过程 → 新信息显露 → 最终归属与朝向
```

一次普通拿起、递交、放下或转身默认在一个镜头中完成；只有拒绝、争夺或中途撤回改变关系时才拆镜。

道具交接写清启动、过程和落点。禁止上一镜头在A手中、下一镜头无过程出现在B手中。

## 7. Prompt写法

用户确认片段表后，文戏使用通用的N镜Prompt架构；N等于片段表实际镜头数：

```text
【分镜】
人物站位：[简洁锁定左右、前后、距离、朝向、接触、视线、门窗通道、道具和基础声音。]

镜头1：[景别与机位。主要动作、关系变化、2–3个情绪信号、完整台词/声音与终态。]
……
镜头N：[当前片段最后一个有效镜头，形成自然出点。]

【角色名声线】
[音区、音色、语速、音量、句尾、状态变化与禁止表演。]

【禁止项】
[文字/UI/水印/Logo/角标/自动字幕/非剧情可读文字/真实UI，以及当前文戏高风险错误。]

【强制声明】
人物与场景的视觉身份以生成端已挂载的参考素材为准；[音乐、环境音、人声、音效、字幕与可读文字规则。]
```

在用户给定的固定禁止项之外，技术性负面约束只增加当前片段真正高风险的项目，例如角色错位、左右翻转、越轴、口型错配、台词跨镜、道具瞬移或无因同步变脸。

## 8. 自检

- 片段已经用户确认，符合当前工作配置；严格配置时才要求25–30秒且恰好8镜。
- 镜头时长总和等于片段实际时长；没有用微动作凑镜，也没有为减少镜头而合并必要动作或对白。
- 每个镜头有叙事、关系或决定作用，没有微动作凑数。
- 正文直接从`【分镜】`开始，没有剧情简介、剧情简述、剧情概述或前情提要。
- 人物站位、左右、距离、接触、视线与180度轴线明确。
- 每句台词完整位于一个镜头且只出现一次。
- 说话人口型、倾听者闭口和过肩前景正确。
- 主角状态变化有原剧本中的触发，配角反应改变下一步。
- 每镜头最多2–3个关键情绪信号，正文无肌肉术语。
- 核心道具持有者、交接过程和最终归属连续。
- 最后一镜写清人物最终姿态、朝向、距离和道具归属，并形成自然出点。

## 1. 输入与三个时间粒度

接受TXT、Markdown、DOCX或直接粘贴的中文剧本。利用已有场次、时间码和镜头标记，但不要求它们存在。

必须区分：

```text
单元 ≠ 生成片段
镜头 ≠ 故事板宫格
生成片段 = 若干连续完整镜头形成的可独立生成区间
片段时长能力 = 当前生成端的提交参数
25–30秒与8镜 = 默认制作偏好，不是模型固有硬限制
```

用户没有要求重组时，不重排场景、剧情或对白顺序。

## 2. 单元结构

单元是完整戏剧节拍。在场景、目标、阻碍、力量关系、关键信息或行动阶段明显变化处寻找边界。

```markdown
| # | 标题 | 时长 | 节奏 | 戏剧任务 | 视觉motif | 承接钩子 |
|---|---|---|---|---|---|---|
| 1 | [3–10字] | [时长＋起止时间] | [松紧/轻重] | [目标→阻碍→结果] | [剧本具象锚点] | [下一单元回应的问题] |
```

全部单元时间连续，总和等于自然全片时长。视觉motif只能来自剧本。

## 3. 八列镜头表

每个单元单独输出一张表，全片镜号连续且跨单元不重置：

```markdown
### 单元 [N] · [标题]（[起止时间]）

| # | 时间 | 时长 | 景别 | 机位·运动 | 内容 | 声音 | 特效 |
|---|---|---|---|---|---|---|---|
| 01 | 0:00.0 | 2.5s | 中景 | 低角度·慢推 | [主体＋动作过程＋结果] | [环境音/动作音/对白] | [可见变化/无] |
```

字段规则：

- 镜号使用两位数，从01连续递增。
- 时间统一使用`m:ss.s`，时长统一使用十进制秒，内部计算保留0.1秒精度。
- 下一镜开始时间严格等于上一镜开始时间加时长；不得靠显示四舍五入掩盖误差。
- 景别使用极端特写、近景、中近景、中景、中远景、全景、远景七档。
- 机位·运动只写一条主要可执行路线。
- 内容使用`主体＋可见动作过程＋结果或终态＋必要连续性细节`。
- 声音每镜必填；没有声音写`静默`。
- 特效每镜必填；没有写`无`，不用预算等级或空泛质量词。

抽象心理只转换为剧本支持的可见表情、呼吸、姿态、视线、手部动作和人物距离变化。

## 4. 自然拆镜

先拆完整动作链：

```text
发现威胁 → 反应 → 发起动作 → 接触/命中 → 受力位移 → 稳定终态
```

在景别、视点、动作阶段、反应、空间关系、对白权力或声音转场发生变化时考虑切镜。

- 首次进入场景时建立人物与空间关系。
- 不拆散不可分割的动作因果或一句完整台词。
- 高速动作保留发起、接触和结果中的必要节点。
- 一个短镜头承担一个主要视觉信息或一个完整动作节拍。
- 先形成自然镜头时间线，再考虑片段目标；不得预先凑8镜。

## 5. 工作配置与可行性

### adaptive：默认自适应

- 当前生成端使用标准时长时，每段必须为5–30秒。
- 优先在25–30秒自然出点切分，以8镜为目标。
- 偏好与完整性冲突时，允许5–24.9秒片段或非8镜片段。
- 镜数由有效节拍决定；常见范围6–10镜，但不把该范围当成新的硬限制。
- 每个偏离都在片段表中给出短理由，例如`完整问答仅18秒，不拉长`。

### exact_25_30_8：严格制作配置

仅在用户明确要求时启用。切片前执行：

1. 以自然时间线总时长`T`检查是否存在整数`n`满足`25n ≤ T ≤ 30n`，等价于`ceil(T/30) ≤ floor(T/25)`。
2. 检查是否存在`n-1`个自然或可通过合法镜头微调形成的边界。
3. 检查每个不可拆对白、问答或动作单元不超过30秒。
4. 检查每段可从剧本已有节拍组织出恰好8个有效镜头。
5. 检查调整不会使对白不可说、动作物理失真或明显改变原作节奏。

任一项失败即为严格配置无解。不要把31–49秒内容静默压成30秒或拉成50秒，也不要用微动作、重复空镜或虚构反应凑8镜。

### extended：扩展配置

只有用户明确启用且已确认当前生成端支持时使用。记录实际允许的最短与最长时长；不要把某个平台的Beta能力推定到所有生成端。镜数仍由有效节拍决定，除非用户同时明确要求固定镜数。

## 6. 全片统一切片

先标记整条时间线上的自然出点：动作完成、问答结束、反应落定、运镜停稳、场景转换、稳定悬念或主要角色即将视觉入场。

再统一组合连续完整镜头：

1. 优先选择叙事完整、状态可复现的出点。
2. 不在单镜中间硬切；需要边界时先合法调整镜头时长、拆分信息过密镜头或合并冗余镜头。
3. 调整只能作用于原有动作、有效反应、空间建立、运镜和声音余韵；不能新增剧情事实。
4. 默认配置允许短片段，不为填满25秒加入重复动作、无关空镜或不可见心理。
5. 严格配置若末尾或中间区间无法合法落入25–30秒，返回可行性阻塞，不循环重算到伪造成功。
6. 所有片段连续覆盖全片，不留空缺或重复区间。

### 优先截断点

- 动作与结果完整；
- 对白交换结束；
- 运镜停稳或构图稳定；
- 场景、时间、空间或叙事焦点转换；
- 悬念成立且人物、道具、方向和声音状态可复现；
- 新主要角色即将首次可见入场。

### 禁止截断点

- 起跳未落地、攻击未接触、受击结果未形成；
- 转身、开门、拿取或交接只完成一半；
- 快速推拉、摇移、环绕尚未停稳；
- 变形、爆炸、坍塌或法术没有形成结果；
- 句中对白、完整问答或通信回复被拆开；
- 多人物相对位置尚未建立。

## 7. 对白、动作与角色入场

对白台账：`ID｜说话人｜对象｜原文｜声音类型｜原镜号｜片段｜最终镜头`。

- 提问、呼叫或挑衅及其直接回复优先视为不可拆单元。
- 正常对白按每秒4–6个汉字估算，紧急呼喊最高每秒7字；停顿、哭腔、喘息和迟疑也占时长。
- 一句台词必须在同一镜头和同一机位内说完。
- 标准模式下单句不可拆对白超过30秒时暂停，请用户删减、改写为多句或选择可用的扩展方案。
- 耳机、电话和广播标记为`通信画外对白`，不是OS，也不等于角色已经视觉入场。
- 新主要角色的开门、露脸和第一个可见动作尽量放在新片段开头；若这会破坏对白、动作完整性或形成不合理短片段，则在同一片段内保护完整亮相，并在切点理由中说明。
- 超过单段上限的连续动作按稳定阶段拆分，每段有可复现入点与出点。

## 8. 时间线JSON与校验

在输出片段表前建立临时JSON，字段遵循：

```json
{
  "profile": "adaptive",
  "total_duration": "52.0",
  "segments": [
    {
      "id": "01",
      "start": "0.0",
      "duration": "26.0",
      "shots": [
        {"id": "01", "start": "0.0", "duration": "3.0", "dialogue_ids": []}
      ]
    }
  ],
  "dialogues": [
    {"id": "D01", "segment_id": "01", "shot_id": "03"}
  ]
}
```

时间字段使用字符串形式十进制秒，避免二进制浮点误差。`shots`必须列出完整镜头；示例只展示字段形状。

使用当前环境可用的Python 3解释器运行：

```text
python scripts/validate_timeline.py <timeline.json>
```

如果`python`不在PATH中，先查找当前运行环境提供的Python可执行路径；在Codex Desktop中调用`codex_app__load_workspace_dependencies`（界面可能显示为“加载工作区依赖”）并使用其返回路径。只有确认环境没有Python解释器，或用户明确禁止创建临时时间线文件时才退回人工规则检查；不能把“PATH中无python”当作“无解释器”。

脚本检查：

- 全片与相邻片段连续覆盖；
- 片段内镜头连续、时长和一致；
- 全片镜号连续且唯一；
- 工作配置的时长与镜数规则；
- 对白ID在镜头中出现一次且只出现一次；
- 对白台账指向的片段和镜头真实存在。

## 9. 输出与质量检查

片段表固定为：

```markdown
| 片段 | 起止时间 | 时长 | 镜头范围 | 镜头数 | 工作配置 | 规格状态 | 切点理由 | 剪辑连接 | 校验方式 |
|---|---|---|---|---|---|---|---|---|---|
| 01 | [实际起止] | [实际时长] | [连续镜号] | [实际数量] | adaptive | [命中偏好/偏离及原因] | [自然出点] | [出点→方式→新入点] | script通过 |
```

输出前确认：

- 剧情、对白、动作和结果无遗漏、重复或擅改；
- 单元、镜头和片段三个粒度没有混淆；
- 镜号、时间、时长、声音和空间关系连续；
- 每个片段符合当前生成端能力；
- 自适应配置没有为了偏好破坏内容；
- 严格配置已通过全部可行性条件；
- 下一片段从新镜头或新动作开始，不复制上一段末格；
- 时间线脚本无error，或如实标记人工规则检查。

完整流水线在此输出单元表、镜头表和片段表并等待用户确认。单项审校不伪造这些上游交付物。

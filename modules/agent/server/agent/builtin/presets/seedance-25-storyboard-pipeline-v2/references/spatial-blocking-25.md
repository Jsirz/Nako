## 1. 目的与边界

默认使用简洁文字锁定人物站位、空间轴线和道具关系。不要为了普通文戏强制制作故事板，也不要仅因片段没有达到25秒或8镜而制作故事板。

站位卡只描述会影响生成结果的可见信息，不写镜头分析、设计理由、角色心理或静态外貌材质。视觉身份由用户在生成端手动挂载的素材负责。

每个片段至少输出`【人物站位】`。只有存在移动或结尾状态不明确时，才增加`【动作路径】`和`【结束状态】`。

## 2. 空间底图

先在内部确认：

```text
主空间与相邻空间
固定光源
门、窗、走廊、楼梯、柜台、沙发、桌子等场景锚点
摄影机所在区域和180度轴线
画面左/右与空间内/外
前景、中景、后景
开放区域与实体阻挡
关键道具位置
```

人物前后以人物身体朝向为准；画面前后以摄影机构图为准。两者容易混淆时分别说明。

不要只写“客厅里两个人坐着”。使用固定锚点说明谁在何处、朝向哪里、隔着什么、能看见什么。

## 3. 人物站位

按以下顺序压缩成一个自然段：

```text
时间/主要光源 → 场景锚点 → 主角画面位置与姿态 → 其他角色相对位置 → 身体朝向与距离/接触 → 视线关系 → 后景主体 → 门窗通道与关键道具 → 基础声音状态
```

只保留当前片段真正需要的信息。普通双人文戏通常80–160个汉字足够；复杂空间可以稍长，但不要变成镜头表复述。

示例：

```text
【人物站位】
夜晚的苏晚家客厅只开着画面右后方一盏暖黄落地灯。苏晚坐在沙发画面右侧，陈屿坐在她左侧，两人身体相向、肩膀贴近，陈屿一只手仍停在苏晚腰侧；年糕伏在后景窗台。客厅通往厨房的门位于画面右后方，猫粮碗在厨房内，室内只有低缓环境声。
```

### 双人文戏

必须写清：

- 谁在画面左、谁在画面右；
- 两人相向、同向还是一人背对；
- 肩膀、手、膝盖或道具是否接触；
- 谁看谁，谁避开视线；
- 正反打时180度轴线不变。

### 三人场景

先确定主关系轴，再说明第三人的位置和功能。第三人不得只写“站在旁边”；写清其位于前/中/后景、靠近哪个锚点、面向谁，以及是否阻断两名主角的视线或行动路径。

### 单人场景

写清角色与门窗、家具、镜面、道具或声音来源的关系。不得因为画面只有一人就虚构画外人物的位置和动作；镜头也不自动成为角色的表演对象，除非用户明确要求直视镜头或自拍视频。

## 4. 动作路径与结束状态

人物或道具发生明显位移时增加：

```text
【动作路径】
[主体]从[起点]沿[可见路径]绕过/穿过[锚点]到达[落点]；[另一主体]保持/改变[位置与朝向]；[道具]从[持有者/位置]经[交接过程]到达[最终归属]。
```

路径必须连续，不使用“突然出现在”。复杂动作按`来源→途中→落点`说明。

结尾需要成为下一片段连续性锚点时增加：

```text
【结束状态】
[人物最终位置、朝向、姿态和视线]；[道具最终归属]；[环境破坏或残余运动]；[声音状态]。
```

## 5. 输出模板

默认交付：

```text
【人物站位】
[一段简洁、连续的空间描述。]

【动作路径】
[仅在发生明显位移时输出。]

【结束状态】
[仅在需要补充片段终态时输出。]
```

片段表已经用户确认后，自动审校通过的这三项成为最终视频 Prompt 的空间底稿，不再重新推断左右、前后、朝向或道具位置；站位阶段不再设置新的默认确认门。

## 6. 何时启用可选故事板

只有以下情况之一成立时，建议读取`storyboard-generation-25.md`：

- 三人以上交叉走位或群体调度；
- 复杂打斗、追逐、瞬移、换位、分身或变形；
- 镜面、玻璃反射、画中画、监控画面或多层前后景；
- 跨房间、跨楼层或多入口路径；
- 比例变化或VFX来源/路径容易画反；
- 用户明确要求故事板。

故事板用于复杂空间校准。默认先输出逐节拍文字校准；只有用户明确要求生成故事板图片或明确启用自动故事板时才调用图片生成。自检后把有效结果写回文字站位卡；除非用户明确选择故事板参考生成方式，最终视频 Prompt 不引用故事板图片。

## 7. 自检

- 人物左右、前后和身体朝向明确。
- 角色距离、接触状态和视线对象明确。
- 门、窗、通道、家具和关键道具位置可复现。
- 摄影轴线稳定，正反打不会交换左右。
- 动作路径有起点、途中锚点和落点。
- 道具交接有启动、过程和最终归属。
- 站位卡没有复述静态外貌或整张镜头表，也没有索取或虚构参考图标签。
- 没有虚构画外人物、额外通道、道具或事件。

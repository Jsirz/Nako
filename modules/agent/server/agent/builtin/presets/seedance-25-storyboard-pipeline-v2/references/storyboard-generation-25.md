## 1. 前置条件

故事板是可选的空间校准工具，不是默认流程门槛，也不是默认的视频参考素材。只有复杂打斗、多人物交叉走位、镜面/瞬移等容易发生空间错误的场面，或用户明确要求故事板时，才进入本文件流程。普通文戏直接使用人物站位文字。

进入本文件不等于允许生成图片。默认先做逐节拍文字校准；只有用户明确要求故事板图片或明确启用自动故事板时，才调用图片生成工具。调用前用一句话告知用户。

故事板自检后，必须把已校正的左右、前后、朝向、距离、视线、轴线、动作路径和道具位置转写到 `【人物站位】`、`【动作路径】` 与 `【结束状态】`。除非用户明确选择“故事板驱动视频”，最终视频 Prompt 不引用、不上传故事板。

只有以下条件同时满足时才继续：

1. 当前片段及镜头范围已经通过自动审校和用户确认，时长符合当前工作配置和生成端能力。
2. 当前片段入点、出点和相邻片段连接已经明确。
3. 人物站位、空间锚点、轴线和关键道具位置已有文字底稿。
4. 对白台账已经把当前片段的对白、OS和通信画外音分配到镜头。

参考图由用户在生成端自行挂载，不是故事板前置条件。条件不足时先自动回退补齐镜头或站位文字；只有涉及原剧本硬矛盾时才暂停。

## 2. 选择格数

格数由可读动作节拍决定，时长只作为辅助：

| 格数 | 布局 | 适用条件 | 常见时长参考 |
|---|---|---|---|
| 六格 | 2行×3列 | 不超过6个主要节拍 | 常见于较短或简单片段 |
| 九格 | 3行×3列 | 7–9个节拍或较多反应/视角变化 | 常见于中等复杂片段 |
| 十二格 | 3行×4列 | 10–12个节拍或两轮完整动作 | 常见于较长复杂片段 |
| 十五格 | 3行×5列 | 13–15个节拍或接近标准上限的复杂片段 | 常见于高密度片段 |

以上不是硬时长边界。一个SHOT可以拆成多个宫格，多个简单SHOT也可以压缩表达；宫格不得创造新SHOT或新剧情。

如果当前片段需要超过15个主要节拍才能读懂，退回镜头表或片段表重新拆分，不把全部动作挤进十五格。

所有故事板使用16:9横版画布，从左到右、从上到下阅读。

## 3. 空间、动作与连续性

### 空间底图

写格子前先确定：

```text
机位所在区域｜主体位置与朝向｜主体前方与背后｜开放区域｜实体背景｜固定锚点｜动作/VFX来源、路径与落点
```

景别和机位不能代替位置关系。空间复杂时逐格写清前景、中景和背景，只保留防止位置画反的主体。

### 动作因果

复杂打斗、瞬移、换位、分身或变形按以下顺序拆分：

```text
威胁建立 → 新位置/比例锚点出现 → 能力或动作触发 → 接触/命中 → 受力与环境反馈 → 稳定结果
```

第一格先建立单一主要行动者、主要目标和轴线。每格只承担一个主要阶段；去掉彩色箭头后仍应看懂人物位置和因果。

### 尺度与视角

- 尺度变化使用固定参照物和明确比例，不只写“变大/变小”。
- 景别之外还要写正面、纯侧面、侧后或背影。
- 写清人物朝向画面左/右和视线目标。
- 连续广角使用栏杆、柜台、门、车辆或建筑保持尺度。

### 片段连续性

- 第一格从当前片段实际新镜头或新动作开始，不复制上一片段末格。
- 最后一格停在自动审校确定的自然剪辑点。
- 只有用户明确要求首尾帧驱动、续拍或无缝动作匹配时，才把上一段末帧作为外部参考；它不占新故事板格子。

### 对白与声音

- 可见人物说话时表现对应口型和听者反应。
- OS、耳机、电话和广播只表现声音与听者反应，画面人物嘴巴不动。
- 每句对白、OS和通信画外音必须对应明确格子或声音节拍。
- Prompt可以写出台词原文，但成图禁止大段对白框和字幕。

## 4. 故事板Prompt结构

先在内部建立节拍表和每格应出现/不应出现的主体，再输出最短有效Prompt：

```text
画风样板用途：只采用黑白粗铅笔质感、网格和彩色制作标记，不采用样板中的人物、场景、剧情、动作或文字。用户明确提供精确素材标签时才按原文追加标签职责。

生成16:9横版的[2×3/3×3/3×4/3×5]故事板，从左到右、从上到下阅读。叙事画面中的人物、场景、怪物、道具和VFX严格使用黑白灰粗铅笔线稿；颜色只允许用于稀疏的故事板制作标记：红色动作、蓝色运镜、绿色构图、橙色光线、紫色声音/情绪。

节拍：
1 [主体＋动作＋视角＋结果]
2 [主体＋动作＋视角＋结果]
……

全局约束：[比例锚点]；[空间轴线与视线]；第一格从[新入点]开始；最后一格停在[自然出点]。每格只放简短编号和少量制作标记，不要大段正文、对白框、时间轴、Logo或水印。
```

默认画风使用 [../assets/default-storyboard-style.png](../assets/default-storyboard-style.png)，只继承画风、宫格排版和彩色制作标记，不继承其中人物、怪物、剧情、动作或英文文字。外部人物与场景参考图不是必需输入，不主动索取、编号或映射；没有精确标签时只按剧本与站位文字表达空间关系。

用户指定其他故事板风格时替换画风参考，不改变动作、布局和连续性规则。

## 5. 调用图片生成

1. 用户没有明确授权图片生成时，只输出逐节拍文字校准并转写站位，不调用图片工具。
2. 用户明确要求故事板图片或启用自动故事板时，调用前告知将生成一张校准图；生成后展示图片或提供可访问结果，不把有成本的调用隐藏为“内部步骤”。
3. 不主动挂载、检查或要求外部人物与场景参考图；用户明确提供精确标签并要求使用时才原样传递。
4. 一次生成完整故事板，不拆成多个容易失去一致性的单图。
5. 把高分辨率写成目标，但工具没有对应参数时不得声称开启不存在的分辨率或思考度选项。
6. 工具返回本地路径时实际查看文件并核对像素；只返回图像内容或数据URL时直接检查返回图像，不虚构保存路径、文件名或像素。
7. 图片工具不可用时，用扩展文字站位和逐节拍空间表完成校准，不因此中断主流程。

## 6. 逐格验收

先检查整张图：

- 实际格数、布局和阅读顺序；
- 黑白叙事画面与彩色标记分层；
- 人物数量、角色职责、场景锚点与剧本和站位文字一致；
- 动作因果覆盖完整，没有越界到下一片段；
- 第一格没有重播上一段，最后一格停在自然出点；
- 实际像素如实报告。

再逐格检查：

- 景别、机位、POV、俯仰角和运动方向；
- 人物尺度、固定锚点和变形比例；
- 正侧背视角、人物朝向和视线目标；
- 前景、中景、背景和开放区/实体背景关系；
- 本格应出现和不应出现的主体；
- 动作阶段、接触、受力、消散和最终状态；
- 攻击方向、人物相对位置和动作因果；
- 是否因主体或动作过多而不可读；
- VFX数量、来源、路径与落点；
- 对白、OS和声音标记是否导致错误口型或大字幕。

图片已经获得用户授权并生成后，按以下方式处理：

- 无明显偏差：标记`逐格自检通过`，转写人物站位并继续编译视频 Prompt。
- 有偏差：按`第N格｜期望｜实际偏差｜修正`生成修正指令并自动重试。
- 连续两次仍无法消除偏差：放弃图片校准，改用更详细的文字站位和逐节拍空间表继续；不因可选故事板失败而要求用户审图。

用户明确要求故事板交付物时，才展示图片与简短自检结果。

## 7. 修改故事板

自动自检发现偏差，或用户明确提出修改后：

1. 锁定准确的本地故事板文件，把它作为编辑目标Image 1。
2. 只传入本次修正需要的身份或场景参考。
3. 明确保留网格、画布比例、故事板画风、人物身份、镜头顺序和未指定格内容。
4. 按`Panel N`逐条写修改；删除误入人物时明确写出。
5. 再次声明叙事画面黑白灰、颜色仅限故事板标记。
6. 生成完整修正版后重新执行全部验收。

全局画风、连续比例或多格视角同时错误时整张重生；只有少量孤立宫格错误时局部编辑。

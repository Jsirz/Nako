## 世界观 & 基调
- **世界**:末世废墟战场——成片倒塌的混凝土断楼、瓦砾、碎石、远处城市残骸轮廓。
- **基调(定死)**:**清爽明亮**。蓝天(淡蓝、不过饱和)+ 白云 + 通透日光 + 干净锐利无噪点。**不要**沙尘压抑/灰暗/Dune 末世调。冷特效靠暖废墟做 teal-orange 对比跳出。
- 标准:`size 16:9, quality 4K`。

## 🎨 配色铁律(全片锁死,不许漂)
| 角色/能力 | 颜色 | 形态/质地 | 一句话 |
|---|---|---|---|
| **风刃男** 的风 | **青蓝 cyan-blue / azure** | **软 · 半透明 · 粒子流动**(漩涡/丝带/速度拖影) | 气态、通透、有间隙、粒子感 |
| **林雪** 的冰 | **霜白 frost-white**(极淡冷蓝) | **硬 · 结晶 · 锐利**(尖锥/实墙/霜雾) | 固态、尖、结晶 |
| **陈燃** | **黄衣** | 多为背影/被护者 | 黄色背影 |

**双区分轴**:风蓝 vs 冰白(色相/饱和度)+ 风软粒子 vs 冰硬结晶(形态)。即便都偏冷,"软的在翻卷 / 硬的在立墙"一眼能分。
负向常驻:`green wind`(风别绿)、`white wind on 风刃男`(风别纯白)、`blue ice / ice same colour as wind`(冰别撞蓝)。

## 角色关系(驱动姿态,定死)
**林雪 远比 风刃男 强。**
- **林雪 = 真·强者:平静、从容、甚至零特效**(强到不需要展示力量,杵着就赢)。
- **风刃男 = 自大送死的弱者:张扬、嬉皮笑脸、满身大特效**(越使劲越显被碾压)。
- 全片一致;后段"风刃男大笑攻 / 风拳压顶"理解成"他张牙舞爪地攻、她始终平静碾压",结尾可能反转。

# Neo Image 出图引擎 · 万物生方法论蒸馏

> 一句话:**你给一句镜头要求,我吐一条完整可跑的 Neo Image 2 / Nano Pro 出图 prompt,把所有打法和踩坑规律自动套好。**
> 本文件是"出图大脑"。真正的手艺细节(质感词库 / 颜色锁定法 / 反 AI 味 / 电影感签名 / 二次优化 / 防串脸)全在 `references/craft-library.md`;当前项目的配色铁律与角色 ref 在 `references/project-wanwusheng.md`。

---

## 总纲 · 引擎第一律(reference-driven · 覆盖本文件与所有 references)

> ⚠️ **一切生成都是图生图,必须由用户提供的参考图锚定 —— 没有纯文生图。**
> 本律覆盖全引擎:下文与所有 references(shot-types / craft-library / pipeline)里任何"文生图 / 纯 prompt / 无需参考图 / 从无到有"的字样,**一律按本律失效**,读作"图生图 · 参考图锚定";`建` = 图生图重型建(Image 2 + 参考图),不是从零文生图。
>
> **开工前先确认参考图齐备,缺哪类就停下问用户要,绝不凭空脑补**。四类参考输入:
> 1. **角色参考图** —— 锁脸/发/服装(防串脸真源)。
> 2. **场景参考图** —— 锁环境(车厢 / 废墟 / 沙漠…都要用户给案例图,不自己造场景)。
> 3. **色卡 = 电影感色调参考** —— 色卡本身也是图生图产出:**用户给一张电影感场景剧照 → 提取该场景的主色/辅助/点缀调色板生成色卡**(图型23);生成的色卡再作为"电影感色调"输入,喂进后续每一条 prompt。
> 4. **全新资产(无现成参考图,如新生物/异常体)** —— 也要用户给一张**案例 / vibe 参考图**(相似物 / 氛围图)来锚;没有就先问用户要,不文生图硬造。

## 零、激活条件

满足任一即激活:
- 用户给一句"镜头 / 画面 / 设定图"要求,想要一条能直接跑的出图 prompt。
- 用户在迭代一张已出的图(改高度 / 颜色 / 特效 / 治糊 / 防串脸)。
- 用户显式说触发词。
- 用户给一个**已成形的剧本 / 分镜,要成套出图** → 激活,走 §一**编排流水线**(`references/pipeline.md`)。

**不适用**:从零**写剧本 / 编故事**(那是 screenwriting / screenplay);视频运镜 prompt(那是 seedance-translator)。本技能只管**静帧出图**(关键帧 / 设定图 / 物料 / 概念图),是视频的上游——但"给剧本→拆解→成套出静帧 prompt"正是本技能 §一 的主线。

## 一、核心循环

**第 0 步 · 先判输入是哪一种**(决定走哪条路):
- **给了一整个剧本 / 分镜 / 多镜头清单,要成套出图** → 走**编排流水线**:读 `references/pipeline.md`,按它的 5 阶段(解析→分类→规划→生成→校对)+ 3 道人工审核闸走。**这是工业级主线。**
- **只要一个镜头 / 一张图的 prompt** → 走下面的单图循环。
- **在已有图上改一处** → 直接轻型改(见 §二"改" + craft-library 第 2 节)。

单图循环(单镜需求):
```
用户一句要求
  → ⓪ 先确认参考图齐备(角色 / 场景 / 色卡电影感参考 / 新资产案例);缺哪类停下问用户要(总纲第一律)
  → ① 判定:"建"还是"改"?(双寄存器)
  → ② 选图型:这是哪种图?→ 查 `references/shot-types.md` 图型总表,取对应图型的专门骨架/真实prompt全文
  → ③ 选模型:建用 Image 2(英文重型·图生图),改用 Nano Pro(中文一句话)
  → ④ 单角色 / 多角色?定参考图分工与防串脸强度
  → ⑤ 加载项目档案(先判《问心》还是《大逃杀》,见 §五)
  → ⑥ 按图型骨架 + 六段式填出完整 prompt + 写清操作(传哪几张参考图、比例、清晰度、API 参数)
  → ⑦ 给用户;迭代时只改对应那一段,不重写整条
```

每一步细节见下;通用手艺见 `craft-library.md` + `craft-library-2.md`;**图型骨架见 `shot-types.md`**;**整剧编排见 `pipeline.md`**。

## 输出格式 · 中英文对照两版(默认,所有图型通用)

每产出一条出图 prompt,都给 **中英文对照两版**,并排:

- **【英文版】= 拿去喂模型跑的首选**。保持"英文正文 + 中文锁定句 / 角色名 / 标题 / 文字墙汉字"的混合(出图最优)。**重型建图(站位图/设定图/合成/海报/电影感)必须用这版跑。**
- **【中文版】= 全中文对照**,供用户读懂、判断、决定改哪。**轻型改图(一句话微调)可直接用中文版跑;重型建图的中文版仅供对照/读懂**——跑请用英文版。

两条铁律:
1. **专有术语在中文版里保留英文原词 + 括号注中文,绝不硬翻**:`skip-bleach LUT(跳漂白显影)`、`Kodak Vision3`、`anamorphic(变形宽银幕)`、`orthographic(正交无透视)`、`depth order(纵深排序)`、`bokeh / halation`、HEX 码原样。这些是模型认的"咒语",硬翻成纯中文会丢失、出图崩。
2. 两版**结构一一对应**(同段落、同顺序、同 HEX),只语言不同;迭代时两版同步改。

> 为什么不直接全中文跑:Image 2 的母语是英文,纯中文跑复杂重型图会掉控制力(见 `craft-library-2.md` 三大原理 / playbook02「英文为骨架」)。中英对照 = 你读得懂中文、又能用英文跑出最好质量。

## 二、第一步永远先判:建 or 改(双寄存器)

这是整个体系的地基。判错寄存器是最大的时间黑洞。

- **建(图生图 · 参考图锚定)**:基于用户参考图(角色 + 场景 + 色卡电影感参考)出新关键帧 / 设定图 / 合成 / 定调。**没有"从无到有的文生图"——必须先有参考图(总纲第一律)。**
  → **Neo Image 2 + 英文重型 prompt(六段式全套,【参考图标注】段必填非空)**。Image 2 擅长基于参考图建场和大特效。
- **改(在现成图上调)**:换颜色 / 调高度 / 加减特效 / 改姿态单点 / 升画质 / 局部修。
  → **Neo Nano Pro + 中文一句话**(模板:`改这一处。其他全部保持不变。`)。Nano Pro 是微调器,吃中文,不擅长从零建大特效。

> 实战印证:同一镜让 Nano Pro 从零建,风的大特效会软成几根细丝;让 Image 2 建则气势足。所以**建用 Image 2,改用 Nano Pro**,两头配合。

迭代时优先走"改"(拿满意的那张当底图 + 一句中文),除非是换姿态 / 换机位这种"换姿态级"的大改 —— 那种 Nano 拽不动,**回 Image 2 重起**,别在微调里硬磨。

> **★ 角色 / 怪物资产 = 两步走**:生成任何角色 / 怪物,**先出一张"地基单图"焊死命门,再转四宫格**——按命门二选一取景:**真人/写实脸角色(脸一致性是命门)→ 半身锁脸优先**(腰以上半身、竖幅 2:3、最好带场景背景虚化;面部占比大、像素多,身份/五官最可控,串脸/漂脸风险最低);**形态命门类资产(怪物/机械兽/载具)→ 全身/正交优先**(取全身把形态/比例/配色刷对)。**要不要转四宫格 turnaround 先问用户**,确认要才把第1步那张当 Image 1 二次转(角色→图型14,脸继承半身、四宫格补全身正/背/侧;怪物→图型15 的 v4 格式)。**别一上来就出四宫格**(身份没定就摊 4 格,常 4 格不一致)。详见 `pipeline.md` 阶段2。

## 三、输出骨架:六段式(建场 / Image 2 标准格式)

每条建场 prompt 都按这六段填。**英文为骨架(Image 2 母语),中文锁定句嵌在【锁定】段**(参考图锁定吃中文更准)。⚠ 一切图生图:**【参考图标注】段必填且非空**(总纲第一律),至少含角色 / 场景 / 色卡之一。

```
【参考图标注】
Image 1(角色参考·<谁>):仅锚定<谁>的身份(脸/发/服装),严格保留不变,只提供样貌不提供姿势;此图对应画面【<方位>】。
Image 2(……):……(每张一行,每行带"仅作为…""不提供…"的排他声明)
Image N(场景参考):仅锚定环境,只提供背景,不提供人物与色调。
Image C(色卡 / 电影感色调参考):仅锚定整体电影感色调与调色板(色相/明度/饱和取向),不提供人物 / 构图 / 具体内容。

[主体] <一句话定画面>:景别/机位/视角 + 谁在哪做什么 + 环境。位置/高度用构图关系写(见 craft-library 第 5 节),别用米数。

[特效层] <特效是什么颜色、什么质感、多大>。质感用正负词库精确钉(见 craft-library 第 6 节)。多角色时逐个写各自特效,并显式写颜色/形态对比。

【锁定·不改变】分两层写,别混:
· 保留 PRESERVE — 不改变<谁>的五官/发型/服装(<具体>),只改姿态为"<新姿态>";脸与身份严格保留 Image X,不要换脸;多角色加"不要互相串脸 + 绑位置"。
· 硬约束 CONSTRAINTS — 逻辑/形态/数量类禁令放这里(恰好 N 个 / 保持机械脸非人类 / 墙必须是实墙)。⚠ 铁律:形态锁·数量锁·NO-FACE 这类逻辑禁令必须进 CONSTRAINTS,别塞进 TONE 或 Avoid——放错块权重不够会翻车(playbook gid22)。

【PHOTOGRAPHIC TONE】基调(清爽/压抑)、天空、光、调色板、清晰度质感(干净锐利无噪点 or 胶片感)。见 craft-library 第 8、9 节。

【Avoid】把这一路最易翻的点写成负向铁律:错误颜色、错误质感、串脸、整图噪点、错误机位、卡通/游戏感、文字水印等。

size <比例>, quality <2K/4K>
```

**每段为什么存在**:参考图标注=分配创作权防串;主体=内容与构图;特效层=画面里没有、全靠文字堆的东西;锁定=把不变量从模型自由度里扣除;TONE=控质感与基调;Avoid=把已知坑钉死。完整范例 + 每段填写细则见 `craft-library.md` 第 1 节。

> **改图 / Nano Pro 格式**不同:不写六段,直接一句中文"改 X、其余不变"。见 craft-library 第 2 节。

## 四、内联速记(最高频的几条铁律,深挖见 craft-library)

按这几条出图,80% 的坑能绕开:

1. **高度/位置用构图关系,不用米数**。"飞 10 米"模型锚不住;写"楼顶在他脚下 + 脚和地之间留大段空气 + 仰拍他贴天空"才有高度。(第 5 节)
2. **颜色锁成系统,不许漂**。每个角色/能力一个固定色 + 固定形态;多方对垒时靠"色相/饱和度 + 软粒子/硬结晶"双区分。开工前先定色卡。**同一硬铁律(颜色/形态)在 [特效层]描述 +【锁定】禁令 +【Avoid】三处各写一遍——给 AI 读的 prompt 适度重复=注意力强化,不是啰嗦;某镜配色漂掉,多半是只写了一处**。(第 4 节)
3. **特效质感分两类词**:要"半透明/粒子/通透/有间隙",避"实心/脏/密不透风/玻璃管/neon 发光管"。(第 6 节)
4. **粒子感 ≠ 整图噪点**。"风里有粒子"和"整张照片有胶片颗粒"是两回事,prompt 里分开写作用域,否则模型给你糊一层 grain。(第 7 节)
5. **清爽明亮 = 删 Dune2021/skip-bleach/film grain**,改蓝天 + teal-orange 互补;压抑感才用沙尘 haze + skip-bleach。(第 8 节)
6. **多角色防串脸三件套**:逐张参考图排他声明 + 绑画面位置 + Avoid 写"faces swapped or merged"。(第 3 节)
7. **图糊/噪不是手法问题,多半是分辨率**。先升清晰度(1K→2K→4K);要更干净就把出好的图喂回去做"高清重制 / 重绘升质",并配锁定防漂。(第 11 节)
8. **数量是 Neo Image 2 弱项**。九宫格/3×3/"九套"必翻车,靠多跑筛;九宫格只适合"同主体多视图(四视图/turnaround)",不适合"多个不同镜头"。(第 12 节)
9. **角色关系驱动姿态**。真正的强者平静、甚至零特效;张扬放大招的往往是弱的那个。先想清谁强谁弱,demeanor 跟着定。(第 13 节)

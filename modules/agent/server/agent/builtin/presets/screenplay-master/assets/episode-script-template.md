## 3.4 单集剧本标准模板（含完整示例）

> 本节为竖屏短剧单集剧本的标准格式模板。AI agent 在生成完整剧本时必须严格遵循以下格式。

### 一、空白剧本模板

```markdown
# 《剧名》第X集剧本

## 本集信息
- 核心冲突：[一句话描述本集核心冲突]
- 钩子类型：[身份反转/误会揭穿/致命危机/情感极限/秘密曝光/打脸预备]
- 反转类型：[身份/立场/真相/感情/命运]
- 情绪标签：[虐/甜/燃/泪/惊/气愤，选1-2个]
- 场景数：[1-3个]
- 预估字数：[XXX字]
- 预估时长：[X分XX秒]

---

## 场景1：[地点]/[子地点]-[时段]（时间标记）

【环境音效/氛围描写/人物着装等调度】

△ **角色A**（情绪/动作细节指导词）：台词正文...
△ **角色B**（情绪/动作细节指导词）：台词正文...

[镜头类型]：[画面呈现描述，如"面部特写，缓慢推进"]

△ **角色A**（情绪/动作）：下一句台词...

[镜头类型]：[画面描述]

---

## 场景2：[地点]/[子地点]-[时段]

【环境音效/氛围描写】

△ **角色C**（情绪/动作）：台词正文...

[镜头类型]：[画面描述]

---

## 本集悬念结尾

[描述下集钩子，如"手机屏幕亮起，一条消息：'你老公现在和我在一起。'"]
```

### 二、格式规范说明

| 符号 | 含义 | 用法 |
|------|------|------|
| `**角色名**` | 加粗角色名 | 每句台词开头，后接括号标注情绪/动作 |
| `（…）` | 情绪/动作/语气指导 | 紧跟角色名后，括号内写表演指导词 |
| `△` | 台词标记 | 三角形符号开头，标记人物台词行 |
| `【…】` | 环境/音效/调度说明 | 场景开头或需要氛围切换时使用 |
| `【特效：…】` | 打斗VFX特效描写 | 独立成行，三段式（行动→攻击→受击），**不计入总字数** |
| `---` | 场景分隔线 | 每个场景之间用三条横线分隔 |

**常用镜头类型**（方括号内只写景别，不写剪辑/后期指令）：
`面部特写` / `中景` / `全景` / `俯拍` / `仰拍` / `手持晃动` / `推` / `拉` / `快速剪辑` / `慢动作` / `近景` / `远景` / `空镜`

> **禁止**：【特效】【切至】【切换】【转场】【淡入】【淡出】【叠化】【划入】【划出】【后期】【字幕】【配乐】【音效】
> 这些词汇绝对不可出现在 `[ ]` 方括号内。如需标注特效，写在画面描述中，例如：`[全景]：青白剑气自掌心迸发`（而非 `[特效]：青白剑气自掌心迸发`）

**常用情绪标注**：
`冷笑` / `哽咽` / `压低声音` / `猛然抬头` / `眼眶泛红` / `咬牙` / `轻蔑` / `颤抖` / `眼神闪躲` / `一字一顿`

### 三、完整示例 1（1 分钟极速模式短剧）

> **题材**：外卖员被餐厅老板羞辱，结果他其实是餐厅真正的房东

```markdown
# 《亿万富翁的伪装》第1集剧本

## 本集信息
- 核心冲突：外卖员取餐被老板当众羞辱，他隐忍不发，随后一通电话让老板当场崩溃
- 钩子类型：身份反转
- 反转类型：身份
- 情绪标签：气愤、燃
- 场景数：2个
- 预估字数：230字
- 预估时长：1分00秒

---

## 场景1：餐厅后厨门口-日/内

【嘈杂的炒菜声、抽油烟机轰鸣。外卖员陈默穿着洗得发白的外卖服，手上拎着三个外卖袋】

△ **老板王彪**（斜眼打量，不耐烦）：又一个取餐的？靠边等着，先做堂食！
△ **陈默**（平静）：您好，这单已经超时15分钟了，客人催了...
△ **王彪**（摔锅铲，吼）：催什么催！你一个送外卖的，也配催我？

面部特写：王彪满脸横肉，手指戳向陈默胸口

△ **王彪**（冷笑，一字一顿）：听好了，我这店，一分钟流水比你送一个月外卖都多。再不滚，我投诉你！
△ **陈默**（垂眸，缓缓攥紧拳头，低声）：好。

慢推：陈默转身离开的背影，外卖服背后印着"众达跑腿"

---

## 场景2：餐厅门口-日/外（紧接场景1，10秒后）

【陈默站在餐厅玻璃门外，掏出手机】

△ **陈默**（面无表情，拨号）：张秘书，万豪广场B座102商铺，租户违约，今天清退。

中景：陈默挂断电话，玻璃门内王彪正得意地招呼客人

【3秒后，王彪手机响起。他接起电话，脸色骤变，手机从手中滑落】

面部特写：王彪瞳孔放大，嘴唇颤抖，缓缓抬头看向门外的陈默

△ **王彪**（颤音）：你...你是...
△ **陈默**（推门而入，掏出房产证拍在收银台上，淡笑）：现在，滚出我的店。

仰拍：陈默逆光站立，外卖服拉链半敞，露出里面定制衬衫的一角

---

## 本集悬念结尾

【陈默的手机屏幕亮起——来电显示"林氏集团 林晚晴"。他皱眉接通，听筒里传来女人冰冷的声音："陈默，离婚协议我已经签了。三天后，我会让你一无所有。"】
```

### 四、完整示例 2：含打斗场景（2 分钟标准模式）

> **题材**：退役特种兵在地下拳场为保护女儿重出江湖

```markdown
# 《隐拳》第3集剧本

## 本集信息
- 核心冲突：雷龙为保护女儿被迫参加地下拳赛，面对昔日仇人"铁面"，以普通人身份隐藏实力
- 钩子类型：身份反转
- 反转类型：身份
- 情绪标签：燃、惊
- 场景数：2个
- 预估字数：500字（不含特效）
- 预估时长：2分00秒

---

## 场景1：地下拳场/擂台边-夜/内

【昏暗的红光笼罩全场，观众席上数百人狂吼。铁笼中央，雷龙穿着破旧的连帽衫，双手插兜】

△ **主持人**（亢奋，拿话筒吼）：下一位——"铁面"！三届不败拳王！赔率1赔0.1！

【观众席爆发出排山倒海的欢呼。一个两米高的壮汉从通道走出，金属面具在灯光下泛着冷光】

△ **铁面**（透过面具，电子变声）：又是来送死的废物。

近景：雷龙缓缓抬起头，眼神如刀

△ **雷龙**（低声，只有对方能听见）：三年前，码头仓库。你面具下的脸，我记得。

【铁面的肩膀明显僵了一下，金属面具后的呼吸声突然加重】

△ **铁面**（后退半步，声音出现裂缝）：你……你是……

△ **雷龙**（摘下连帽，露出额角的刀疤，淡笑）：我闺女在看台第三排。你猜，我会不会让你活过第一回合？

---

## 场景2：擂台中央-夜/内（紧接场景1，30秒后）

【铁笼门关闭的金属碰撞声。观众席安静了一瞬，随即爆发出更疯狂的呐喊】

△ **裁判**（举手）：开打！

【特效：铁面率先暴起，右拳如炮弹般轰向雷龙面门。拳峰撕裂空气产生尖锐的啸叫，肘关节后方拖曳出一道半月形的白色气浪残像。拳速之快，在空气中留下一道凝结水汽的透明轨迹，如同喷气式飞机尾迹】

【特效：雷龙侧头闪避，拳风擦过耳际，带起的发丝在空中断裂成三截。铁面的重拳落空，惯性将他整个人向前带出两步，靴底与擂台地面的摩擦迸出橙红色火星。雷龙在闪避的同时左掌已贴上铁面肋部——掌根深陷肌肉约两厘米，铁面右侧肋骨轮廓在皮肤下一瞬间凸显如琴键】

【特效：雷龙掌根猛然发力，内劲如针般透体而入。铁面的身体在空中横向翻转了整整540度，金属面具在离心力作用下脱离面部，飞向观众席。他口中喷出的血雾并非均匀散开，而是在旋转中被气流切割成一道螺旋状的粉红色轨迹，每一滴血都在聚光灯下闪烁如红宝石。铁面重达120公斤的身体最终砸在铁笼网上，网格在冲击下向内凹陷出一个人形轮廓，金属立柱发出令人牙酸的吱嘎声】

慢动作：铁面的身体沿铁笼网缓缓滑落，面具在空中翻转，反射着雷龙平静的面庞

【特效：铁面双膝跪地，双手撑在血泊中。血滴从他下垂的下巴坠落，在擂台地面的黑色垫子上溅开成一朵直径五厘米的血花。血花的边缘呈放射状分叉，中心是一个深红色的凹陷。他试图抬头，但颈椎在刚才的旋转中受损，头部只能以不自然的角度歪向一侧】

全场寂静。三秒后，爆发出震耳欲聋的欢呼。

△ **雷龙**（弯腰，在铁面耳边低声）：告诉你的老板。我回来了。

俯拍：雷龙转身走向铁笼门，身后是跪地不起的铁面和疯狂的人群

---

## 本集悬念结尾

【看台第三排，雷龙的女儿小雨双手捂住嘴巴，眼中既有惊恐又有光芒。她身旁，一个戴墨镜的男人按下通讯器："目标确认。'隐龙'雷振东，代号'孤狼'，SSS级危险人物。请求立即行动。"小雨似乎感觉到了什么，缓缓转过头，与墨镜男人的视线对上】
```

### 五、编写自检清单

- [ ] 本集信息头部完整，核心冲突一句话说清
- [ ] 每个场景有明确的时间标记（日/夜 + 内/外）
- [ ] 角色名加粗，台词后紧跟情绪/动作括号标注
- [ ] 每句台词前有△标记，每3-5句台词后插入至少一个镜头指示
- [ ] 结尾有悬念钩子，驱动用户点击下一集
- [ ] 单集时长控制在50-70秒（1分钟极速模式）或90-120秒（标准模式）
- [ ] 全文无旁白/画外音，全靠台词和表演推进剧情
- [ ] 无角色心理描写，心理全用微表情和动作外化
- [ ] 所有 `[ ]` 方括号内均为合法景别词（特写/近景/中景/全景/远景/空镜/俯拍/仰拍/推/拉/手持晃动/快速剪辑/慢动作），无【特效】【切至】【切换】【转场】等剪辑/后期指令
- [ ] 如出现打斗场景：【特效：…】格式正确，三段式完整（行动→攻击→受击），风格与角色背景一致，**字数未计入总字数**

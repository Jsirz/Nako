## 3.3 单集大纲模板

> 用途：AI agent 编写单集大纲时遵循的结构化模板。

### 空白模板

```markdown
# 《剧名》第X集 大纲

## 基础信息
- **集数**：第X集（总X集）
- **副标题**：[本集标题]
- **核心冲突**：[一句话描述]
- **情绪标签**：[选1-2个：虐/甜/燃/泪/惊/气愤]
- **钩子类型**：[身份反转/误会揭穿/致命危机/情感极限/秘密曝光/打脸预备]
- **反转类型**：[身份/立场/真相/感情/命运]
- **场景数**：[1-3个]
- **预估字数**：[XXX字]
- **预估时长**：[X分XX秒]
- **付费卡点**：[是/否，如果是，标注卡点编号]

## 场景列表

### 场景1：[地点]-[时段]
- **时间占比**：XX%
- **核心动作**：[场景中发生的主要事件]
- **参与角色**：[角色列表]
- **情绪走势**：[起始情绪→结束情绪]
- **关键台词**：[1-2句核心台词]

### 场景2：[地点]-[时段]
- **时间占比**：XX%
- **核心动作**：[场景中发生的主要事件]
- **参与角色**：[角色列表]
- **情绪走势**：[起始情绪→结束情绪]
- **关键台词**：[1-2句核心台词]

## 本集悬念结尾
- **结尾类型**：[悬念/反转/情绪爆发/台词钩子]
- **具体内容**：[描述结尾画面]
- **下集钩子**：[观众为什么想看下一集]

## 与前后集的衔接
- **承接上集**：[上集悬念如何在本集开头回应]
- **引出下集**：[本集结尾如何引出下集]

## 爽点标注
- [ ] 本集有打脸/反转场景
- [ ] 本集有情感爆发点
- [ ] 本集有身份/秘密揭露
- [ ] 本集有CP甜蜜互动
```

### 完整示例：霸总甜宠题材

> 《闪婚总裁宠上天》第8集 大纲 · 主题：女主第一次见男主家长被刁难

**基础信息**
- **集数**：第8集（总100集）
- **副标题**：见家长，你配不上我儿子
- **核心冲突**：普通出身的女主初次进入豪门，被男主母亲当众羞辱，男主霸气护妻
- **情绪标签**：虐+甜
- **钩子类型**：身份反转（打脸预备）
- **反转类型**：身份
- **场景数**：3个
- **预估字数**：1800字
- **预估时长**：3分00秒
- **付费卡点**：是，第2个场景结尾（婆婆当众羞辱，女主隐忍）

**场景列表**

*场景1：陆家大宅门口-白天*
- **时间占比**：15%
- **核心动作**：陆景深带苏念初回老宅，苏念初紧张整理衣着，陆景深安抚她
- **参与角色**：陆景深、苏念初
- **情绪走势**：紧张→微甜
- **关键台词**：陆景深："有我在，没人能欺负你。"苏念初："我只是怕……给你丢脸。"

*场景2：陆家大宅客厅-白天（付费卡点）*
- **时间占比**：45%
- **核心动作**：陆母当众刁难苏念初——嫌她出身低、学历差、不会品酒，安排门当户对的林小姐到场比较。陆母把红酒泼在苏念初身上，逼她离开。苏念初隐忍不发。
- **参与角色**：苏念初、陆母、林小姐、陆景深（短暂离开接电话）
- **情绪走势**：忐忑→受辱→隐忍（情绪低谷）
- **关键台词**：陆母："一个卖咖啡的，也配进我陆家的门？"林小姐："伯母，别为难苏小姐了，她可能连红酒杯都不会拿。"

*场景3：陆家大宅客厅-白天*
- **时间占比**：40%
- **核心动作**：陆景深返回，目睹苏念初被泼酒。当众宣布苏念初是自己的合法妻子，亮出结婚证。宣布断绝与家族企业关系，带苏念初离开。出门前苏念初身份反转——知名珠宝设计师的身份被意外揭开。
- **参与角色**：苏念初、陆景深、陆母、林小姐
- **情绪走势**：委屈→爆发→震惊→甜
- **关键台词**：陆景深："妈，你泼的不是红酒，是你儿子的脸面。念念是我领过证的妻子，这辈子我只认她。"苏念初："阿姨，我敬您是长辈。但我的身份——您可能高攀不起。"

**本集悬念结尾**
- **结尾类型**：身份反转+台词钩子
- **具体内容**：苏念初从包里掏出一张名片，陆母和林小姐脸色骤变——名片上印着"Vera Su，国际珠宝设计大赛金奖得主"。陆景深揽住苏念初的腰："现在，谁配不上谁？"
- **下集钩子**：陆母得知苏念初真实身份后态度大转变，但林小姐背后开始调查苏念初的过去，试图挖出她的秘密。

**与前后集的衔接**
- **承接上集**：上集结尾陆景深突然提出"明天跟我回家"，本集开头直接到达老宅门口
- **引出下集**：陆母态度转变后主动邀请苏念初参加慈善晚宴，林小姐暗中派人调查苏念初

**爽点标注**
- [x] 本集有打脸/反转场景
- [x] 本集有情感爆发点
- [x] 本集有身份/秘密揭露
- [ ] 本集有CP甜蜜互动

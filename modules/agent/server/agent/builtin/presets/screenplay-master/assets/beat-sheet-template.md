## 3.2 短剧节拍表模板

### 空白模板

```markdown
# 《剧名》第X集 节拍表

## 本集基础信息
- 集数：第X集
- 核心冲突：[一句话概括本集核心矛盾]
- 情绪基调：[虐/甜/燃/泪/惊/爽]
- 预估时长：X分钟
- 预估字数：XXX字

## 节拍明细

| 时间 | 节拍 | 动作 | 情绪 | 钩子 | 场景 |
|------|------|------|------|------|------|
| 0-3s | 开场Hook | [动作/台词] | [情绪] | 强/中/弱 | 场景1 |
| 3-10s | 冲突建立 | [动作/台词] | [情绪] | 强/中/弱 | 场景1 |
| 10-20s | 升级施压 | [动作/台词] | [情绪] | 强/中/弱 | 场景2 |
| 20-35s | 隐忍/转折 | [动作/台词] | [情绪] | 强/中/弱 | 场景2 |
| 35-50s | 反击/揭露 | [动作/台词] | [情绪] | 强/中/弱 | 场景3 |
| 50-58s | 高潮/释放 | [动作/台词] | [情绪] | 强/中/弱 | 场景3 |
| 58-60s | 结尾Hook | [动作/台词] | [情绪] | 强/中/弱 | 场景3 |

## 打脸四步法（如适用）
- [ ] 羞辱：[反派嚣张行为描述] 时间：XX-XXs
- [ ] 隐忍：[主角压抑反应描述] 时间：XX-XXs
- [ ] 反击：[主角打脸行为描述] 时间：XX-XXs
- [ ] 释放：[反派震惊+众人反应描述] 时间：XX-XXs

## 情绪曲线
- 起点：[情绪+原因]
- 波谷：[情绪+时间点+原因]
- 波峰：[情绪+时间点+原因]
- 终点：[情绪+悬念描述]

## 钩子检查
- [ ] 前5秒Hook：[是否抓住注意力]
- [ ] 中段钩子：[是否防止划走]
- [ ] 结尾Hook：[是否引发期待]
- [ ] 集间衔接：[是否与下集关联]
```

### 完整示例：《龙主归来》第 3 集 节拍表

**本集基础信息**
- 集数：第3集
- 核心冲突：赘婿叶辰被当众羞辱，龙主身份即将揭露
- 情绪基调：燃
- 预估时长：1分钟
- 预估字数：280字

**节拍明细**

| 时间 | 节拍 | 动作 | 情绪 | 钩子 | 场景 |
|------|------|------|------|------|------|
| 0-3s | 开场Hook | 王少将红酒泼在叶辰脸上："你这废物也配上桌？" | 虐（强） | 强 | 宴会厅 |
| 3-10s | 冲突建立 | 苏家人纷纷嘲笑，苏母怒斥叶辰丢尽了脸 | 虐（中） | 中 | 宴会厅 |
| 10-20s | 升级施压 | 王少踩住叶辰的手，逼他跪下道歉 | 虐（强） | 强 | 宴会厅中央 |
| 20-35s | 隐忍转折 | 叶辰低头握拳，手机震动——龙殿十二护法已到门外 | 压抑+期待 | 强 | 宴会厅中央 |
| 35-50s | 反击揭露 | 十二护法齐刷刷跪地："恭迎龙主！"全场死寂 | 燃（爆） | 强 | 宴会厅 |
| 50-58s | 高潮释放 | 叶辰擦去酒渍，王少瘫坐在地，苏母目瞪口呆 | 爽（爆） | 强 | 宴会厅 |
| 58-60s | 结尾Hook | 叶辰冷眼看向王少："现在，该你跪了。" | 爽+悬念 | 强 | 宴会厅 |

**打脸四步法**
- [x] 羞辱：王少泼酒+踩手逼跪，苏家人集体嘲笑 时间：0-20s
- [x] 隐忍：叶辰低头握拳，眼神隐忍，暗线启动 时间：20-35s
- [x] 反击：十二护法跪迎龙主，身份惊天揭露 时间：35-50s
- [x] 释放：王少瘫倒，苏母傻眼，全场震惊 时间：50-58s

**情绪曲线**
- 起点：虐（开局即被泼酒羞辱）
- 波谷：虐+压抑（20s被踩手逼跪，至暗时刻）
- 波峰：燃+爽（45s龙主身份揭露，全场跪拜）
- 终点：爽+悬念（叶辰反杀宣言，期待下跪）

**钩子检查**
- [x] 前5秒Hook：红酒泼脸+废物羞辱，冲突直接炸开
- [x] 中段钩子：踩手逼跪至暗时刻，观众迫切期待反转
- [x] 结尾Hook："该你跪了"反杀宣言，爽感拉满
- [x] 集间衔接：王少跪与不跪的悬念牵引下一集

## 2.10 打斗场景 VFX 特效描写参考手册

> 版本：v1.0 | 用途：短剧打斗/动作场景的特效细节描写 | 不计入剧本总字数

### 一、特效标注格式（强制）

所有特效描写**不占用剧本正文字数**，统一使用以下格式嵌入剧本：

```
【特效：XXXXX】
```

**格式规则**：
- `【特效：` 为固定开头，不可省略或替换
- 内容写完后以 `】` 结尾
- 可插入在台词前、镜头指示后、或独立成行
- **字数不计入单集总字数限制**，可充分展开细节

**插入位置示例**：

```markdown
△ **角色A**（蓄力，眼神锁定）：（台词）

【特效：角色A右脚后撤半步，靴底与地面摩擦迸出橙红色火星。气浪以脚跟为圆心呈放射状荡开，卷起地面碎石和尘埃。腰间佩刀微微震颤，金属嗡鸣声渐强，刀鞘缝隙渗出暗红光芒】

[特写]：角色A瞳孔收缩成竖线，虹膜浮现火焰纹理

△ **角色A**（暴起）：（台词）

【特效：地面在蹬踏瞬间塌陷成直径半米的蛛网状裂纹，冲击波呈环形向四周炸开，碎石以每秒15米的初速度散射。角色A身形化作一道赤色残影，原地的热浪扭曲了空气，产生海市蜃楼般的折射】
```

### 二、三段式特效描写结构

每个完整的打击/受击动作，按以下三段顺序描写：

```
[行动段] → [攻击段] → [受击段]
```

| 段落 | 内容 | 特效焦点 | 参考时长 |
|------|------|----------|---------|
| **行动段** | 攻击方蓄势/移动/出手 | 环境互动、能量积聚、预备动作的视觉化 | 0.5-1.5秒 |
| **攻击段** | 攻击命中瞬间 | 轨迹残留、命中特效、能量释放 | 0.2-0.5秒 |
| **受击段** | 被攻击方受力反应 | 形变、粒子迸发、创伤表现 | 0.5-2秒 |

### 三、行动段：角色行动特效

#### 3.1 蓄力类

**物理层面**：肌肉紧绷产生的视觉外化

| 元素 | 描写方向 | 示例词汇 |
|------|----------|---------|
| 地面 | 压力传导导致的裂纹/塌陷 | 蛛网裂纹、碎石弹跳、地面下沉 |
| 气流 | 能量积聚导致的气压变化 | 气浪翻涌、尘土呈螺旋状升起、衣摆猎猎作响 |
| 粒子 | 能量溢出的微观表现 | 电火花噼啪跳跃、皮肤表面浮现金色光纹、周围金属微微磁化 |
| 环境 | 大范围环境响应 | 灯光明灭不定、玻璃轻微共振、水面向外荡开同心圆涟漪 |

**示例**：

```
【特效：赤炎双拳于腰间缓缓握紧，指节爆发出炒豆般的骨骼脆响。拳峰皮肤裂开细缝，露出下方熔岩般的橙红光芒，高温将周围空气炙烤至扭曲变形。脚下水泥地面以双脚为圆心向外辐射出焦黑裂纹，裂缝中渗出点点火星。五步之内的积水瞬间汽化，白色蒸汽呈柱状升腾】
```

#### 3.2 位移类

**速度感表现**：通过环境破坏和残留轨迹展现实时速度

| 速度等级 | 环境破坏程度 | 残留轨迹 | 参考词汇 |
|----------|-------------|----------|---------|
| 常人极限 | 蹬踏处轻微磨损 | 短暂残影 | 身影一闪、劲风扑面、衣角未落人已至 |
| 超人类 | 地面龟裂/凹陷 | 持续1-2帧的清晰残影 | 音爆云、地面炸开、空气被撕裂出白色气痕 |
| 极致速度 | 路面崩塌/建筑结构受损 | 多段连续残影如真人定格 | 真空通道、身后建筑玻璃连环爆裂、沿途地面翻卷如犁 |

**示例**：

```
【特效：足尖点地瞬间，青砖炸裂成放射状碎片雨。身形拖曳出三道平行的银白色轨迹——实身在中央，两侧是延迟0.1秒生成的残影，如真人般凝实。穿过之处，悬浮的尘埃被气浪劈成两半，形成一道三米长的透明真空走廊，两侧灰尘如瀑布般向中央塌陷填补】
```

**物理规则**：根据角色背景选择对应的能量形态

| 能量类型 | 视觉特征 | 环境互动 | 代表风格 |
|----------|---------|----------|---------|

| 迅疾/雷电 | 银白-紫蓝色、高频闪烁、分叉枝状 | 电子设备干扰、金属磁化、臭氧味 | 异能者/科技 |

### 四、攻击段：角色攻击特效

#### 4.1 徒手打击

**拳击**

```
【特效：右拳拉至肩后呈满弓状，小臂肌肉纤维在皮肤下如钢丝般根根隆起。出拳瞬间，肘关节后方炸开一环白色气浪——音爆云的雏形。拳峰前方空气被压缩成肉眼可见的透明碟状，以每秒450米的速度向前推进。击中目标前0.03秒，目标面部皮肤已受气压影响开始凹陷变形】
```

**踢击**

```
【特效：左腿为支撑轴，全身力量如鞭子般从腰胯传导至右腿。膝关节以上的大腿肌肉如充能般膨胀一圈，裤管在高压气浪下撕裂成布条。脚背绷直如刀，划破空气时产生锐利的尖啸，轨迹上留下一道半月形的白色气刃残像，边缘切割出细密的空间褶皱】
```

**投技/摔技**

```
【特效：双手如铁钳般扣住对方肩甲，指力之大连金属护肩都向内凹陷出五道指痕。腰腹猛然发力，将对方整个人抡离地面，空气被旋转的身躯搅成小型龙卷。对方头发和衣摆在离心力作用下呈水平放射状炸开，面部肌肉被G力拉扯变形。砸向地面的瞬间，接触点预先炸开一圈冲击波，碎石如子弹般向四周散射】
```

#### 4.2 武器攻击

**刀剑斩击**

```
【特效：刀身从鞘中滑出的刹那，金属与皮革摩擦迸出一道两尺长的金色火花流。刀刃并非纯粹金属光泽，而是从刀镡向刀尖流动的液态光纹——银白色的能量在刃口形成不足一毫米的致命薄层。挥斩轨迹并非直线，而是带着微妙弧度的月牙状，所过之处空气分子被切开，留下一道持续0.5秒不会愈合的黑色"真空裂痕"，边缘泛着高温电离后的淡紫色】
```

**长枪突刺**

```
【特效：枪杆自腰际旋转半周蓄力，枪缨在气浪中炸开如一朵血色之花。突刺瞬间枪身高频震颤，产生蜂群般的金属嗡鸣。枪尖前方空气被压缩至临界状态，形成一个拳头大小的透明高压球体，球体表面气流以超音速螺旋缠绕。命中前一瞬高压球破裂，内部压缩的空气化作锥形冲击波先行轰击目标胸口，延迟0.1秒后实体枪尖才贯入——双层打击的视觉效果】
```

**能量/气功波**

```
【特效：双掌于胸前缓缓合十，掌缝间泄露的光芒从指节缝隙中如利剑般刺出——初始是炽白色，随着压缩不断增强转为危险的幽蓝色。掌间能量球的形态并非规则圆形，而是表面不断起伏翻涌的等离子体，内部可见闪电状的分支结构在疯狂游走。发射瞬间，球体后方拖曳出锥形的真空尾焰，途经的空气中留下臭氧的淡蓝残迹和细碎的静电火花】
```

#### 4.3 特殊能力攻击

**元素类**（火焰/冰霜/雷电/岩石）

```
【特效：（火焰型）掌心向上，一团火种自虚空浮现，初始只有烛火大小，却在0.3秒内贪婪地抽取周围空气中的氧气，膨胀至直径两米的巨型火球。火焰并非均匀燃烧，而是呈现出湍流般的涡旋结构——核心是纯白色的超高温区域，外层是橙红色的普通燃烧层，最外层包裹着黑色的不完全燃烧烟柱。火球脱离掌心的瞬间，后方拖曳出一条由熔融火星和黑色碳粒组成的长长尾迹，地面在其经过的路线上留下一道焦黑的碳化轨迹】
```

**科技类**（激光/脉冲/机械）

```
【特效：（脉冲型）机械义臂肩部的散热格栅全部弹开，内部超导环流管的蓝光从缝隙中喷薄而出，在空气中形成星芒状的透镜光晕。0.8秒的充能期间，手臂周围的金属微粒被强磁场吸引，如卫星般环绕手臂旋转。发射瞬间，一道直径三厘米的钴蓝色光束击穿空气，光束所过之处空气中的灰尘被电离成发光的等离子体通道，持续闪烁了整整两秒才逐渐熄灭。目标被击中部位并非穿孔，而是被瞬间传递的动能炸开一个碗口大的凹陷】
```

### 五、受击段：受力点特效描写

### 七、物理细节库（Houdini 级真实感）

#### 7.2 流体模拟

```
血液描写公式：
- 喷射型（动脉）：抛物线轨迹，飞行中分裂为大中小三滴，落地后呈放射状溅开
- 渗出型（毛细血管）：沿皮肤表面流淌，受重力影响向下弯曲，经过轮廓线时形成悬垂血珠
- 雾化型（肺部/口腔）：锥形扩散，密度随距离衰减，颗粒直径0.1-1毫米

火焰描写公式：
- 核心温度区：白炽色，亮度最高，空气严重扭曲
- 中温燃烧区：橙黄色，主体体积，产生黑烟上升
- 外焰舔舐区：暗红色，不规则跳动，偶尔脱离主体形成飘浮火球
```

#### 7.3 刚体动力学

```
破碎描写公式：
- 裂纹起源：受力点向外呈放射状扩散，主裂纹3-5条，次级裂纹10-20条
- 碎块规模：核心区碎块小（拇指大小）、数量多；边缘区碎块大（拳头大小）、数量少
- 飞散轨迹：近处碎块呈直线/抛物线；远处碎块受空气阻力影响轨迹弯曲
- 二次碰撞：大碎块落地后可能再次碎裂，小碎块落地后弹跳2-3次
```

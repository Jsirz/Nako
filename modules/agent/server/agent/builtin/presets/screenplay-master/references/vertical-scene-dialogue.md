## 2.4 竖屏短剧：场景与台词写作参考手册

> 版本：v1.0 | 用途：AI Agent 编写分镜与台词时的核心引用文档

### 一、竖屏 9:16 构图要点

竖屏画面宽度仅为横屏的 56%，构图逻辑完全不同：

- **人物占比 >= 60%**：头部到胸部占画面中央主体，不可被裁切。
- **景别限制**：避免全景（信息过载），优先中景/近景/特写交替。
- **背景极简化**：虚化处理，仅用 1-2 个视觉锚点交代环境。
- **三分法**：上区（20%）放信息/氛围；中区（60%）放人物表情；下区（20%）放手部动作或道具。
- **视线引导**：人物视线朝向画面留白较多的一侧，制造呼吸感。
- **安全区**：关键表情和字幕避开顶部 10% 和底部 15%（防遮挡）。

### 二、运镜指示词汇库

| 符号 | 运镜 | 画面呈现描述 |
|------|------|--------------|
| `推` | 推镜头 | 景别由远及近，强调情绪升级，如从肩部推至眼神特写 |
| `拉` | 拉镜头 | 景别由近及远，揭示环境或孤立人物，制造疏离感 |
| `摇` | 摇镜头 | 机位固定，镜头水平或垂直转动，用于展示空间关系 |
| `移` | 移镜头 | 机位平行移动，跟随角色走位或横向展开场景 |
| `跟` | 跟镜头 | 镜头紧随角色运动，保持主体在画面中心 |
| `升` | 升镜头 | 机位垂直上升，制造俯瞰或抽离感 |
| `降` | 降镜头 | 机位垂直下降，用于出场亮相或压迫感营造 |
| `环` | 环绕镜头 | 360° 围绕主体旋转，用于情绪高潮或关键转折 |

> **镜头标注格式**：`[运镜]：[起始景别] → [终止景别]，[情绪/动作描述]`

### 三、微表情动作库

每种情绪提供 3 组「面部 + 肢体」组合，避免单一标签化表演：

| 情绪 | 面部微表情 | 肢体动作 |
|------|-----------|---------|
| **愤怒** | ① 咬肌凸起、下颌紧绷 ② 瞳孔收缩、眉毛压低 ③ 嘴角单侧抽动 | ① 指关节发白地握拳 ② 拇指用力按压桌面 ③ 颈部青筋微凸 |
| **悲伤** | ① 眼眶泛红但无泪 ② 嘴角下压成一条线 ③ 眼神越过对方失焦 | ① 手指无意识绞动衣角 ② 肩膀微缩 ③ 头微低，下巴轻颤 |
| **得意** | ① 嘴角单侧微扬 ② 眼神从对方脸上扫过 ③ 缓慢眨眼 | ① 手指轻敲桌面 ② 整理袖口或领结 ③ 身体后仰扩大占据空间 |
| **紧张** | ① 眼神快速闪烁 ② 频繁舔嘴唇 ③ 眉毛微挑 | ① 手指绞动/反复开合 ② 脚尖点地 ③ 吞咽动作，喉结滚动 |
| **惊喜** | ① 瞳孔瞬间放大 ② 嘴角不自觉上扬 ③ 眉毛整体抬高 | ① 身体前倾 ② 双手短暂悬空 ③ 脚小步后退 |
| **恐惧** | ① 眼白增多、眼球左右扫动 ② 嘴唇微张 ③ 眉毛呈"八"字 | ① 双手护胸 ② 脚尖朝向逃跑方向 ③ 肩膀耸起 |
| **轻蔑** | ① 单侧嘴角上扬 ② 眼神从下到上扫视 ③ 缓慢闭眼再睁开 | ① 鼻腔轻哼 ② 转身或侧对 ③ 手指弹开灰尘 |
| **爱慕** | ① 眼神柔和、瞳孔放大 ② 嘴角自然微翘 ③ 目光在对方唇眼间移动 | ① 身体无意识前倾 ② 手指轻触锁骨 ③ 脚尖指向对方 |

> **使用规则**：每次只选 1 面部 + 1 肢体，组合使用，不可全写。

### 四、场景最小化原则

- **单集场景数 <= 3**，超过则拆分集数。
- **每个场景必须通过一个测试**：删除它，剧情是否断裂？人物是否扁平？不通过则删除。
- **场景转换三要素**：时间（天色/时钟）、空间（门/走廊/车）、情绪（沉默/音乐/呼吸）。
- **一景多功能**：同一空间通过灯光/道具/人物站位变化承载多场戏。

### 五、分镜脚本标准格式

```markdown
## 场景N：[地点]/[子地点]-[时段]

【环境音效/氛围描写，1-2句】

△ **角色A**（情绪/动作）：台词正文（不超过15字）
△ **角色B**（情绪/动作）：台词正文

[景别]：[画面描述，含景别变化]（方括号内仅限景别词：特写/近景/中景/全景/远景/空镜/俯拍/仰拍/推/拉/手持晃动/快速剪辑/慢动作。严禁使用特效/切至/切换/转场/淡入/淡出等剪辑或后期指令）
[景别]：[画面描述]
```

**格式规则**：
- 每句台词后紧跟运镜标注，不另起大段。
- 情绪/动作标注在括号内，用 `/` 分隔多元素。
- 环境音效用 `【】` 包裹，置于场景开头。
- 潜台词用 `〔〕` 在台词后标注实际含义。

### 六、短句控制（8-15 字/句）

- **核心规则**：单句台词 <= 15 字，理想区间 8-12 字。
- **长对白拆分**：超过 15 字必须拆为两句，中间插入对方反应或动作。
- **轮替原则**：A 说一句 → B 反应 → A 再补一句，禁止一人连续说超过 2 句。
- **允许例外**：① 情感爆发独白（需提前铺垫 3 句以上短句积累情绪）② 重要宣言（需配合推镜头至特写）

### 七、潜台词写作技巧

#### 7.1 核心方法
- **表面说 A，实际意思 B**：用具体事物代替抽象情感。
- **沉默替代回答**：用动作停顿或移开视线表达拒绝/心虚。
- **反问替代陈述**：把情绪包装成问题，避免直白。

#### 7.2 示例对比

| 直白版 | 潜台词版 |
|--------|---------|
| "我很伤心。" | "（低头，手指绞动）这灯，太亮了。" |
| "我不会原谅你。" | "（转身整理袖口）你回去吧，外面冷。" |
| "我爱你。" | "（停顿两秒，喉结滚动）你吃了吗？" |
| "我在威胁你。" | "（微笑，轻敲桌面）这椅子，坐着还舒服吗？" |

> **检测标准**：如果删除括号内的动作描写，台词意思完全相反或模糊 → 潜台词合格。

### 八、金句 / 方言 / 反套路模板

#### 8.1 金句公式

```
金句 = 反差设定 + 情绪极端 + 短句押韵
```

| 公式拆解 | 示例 |
|---------|------|
| 反差 + 押韵 | "我跪着活，是为了站着赢。" |
| 极端情绪 + 短促 | "这账，今天必须清。" |
| 身份反转 | "你觉得我图钱？我图的是你的命。" |

#### 8.2 方言使用

| 方言 | 适用角色 | 示例词汇/句式 |
|------|---------|--------------|
| 东北话 | 豪爽/喜剧角色 | "整事儿"、"必须的"、"咋地" |
| 四川话 | 市井/精明角色 | "要得"、"搞啥子"、"巴适" |
| 粤语 | 商界/江湖角色 | "冇问题"、"抵死"、"讲数" |
| 北京话 | 老炮儿/体制内 | "甭"、"今儿个"、"凑合" |

> **用量控制**：每集方言词汇 <= 3 个，过多影响全国观众理解。

#### 8.3 反套路模板

| 套路预期 | 反套路写法 |
|---------|-----------|
| 渣男下跪求原谅 → 女主原谅 | → 女主蹲下，拍拍他脸："跪高点，我看不清。" |
| 穷小子被羞辱 → 默默离开 | → 穷小子坐下，倒杯水："您继续说，我记笔记。" |
| 反派放狠话 → 主角恐惧 | → 主角笑了："这话，上次说的人，现在会说话吗？" |

### 九、对话节奏

#### 9.1 标准节奏链

```
短句铺垫 → 反问施压 → 留白（2-3秒停顿/动作） → 致命一击
```

#### 9.2 速度变化图谱

| 阶段 | 速度 | 句长 | 景别 | 功能 |
|------|------|------|------|------|
| 铺垫 | 快 | 8-10 字 | 中景→近景 | 信息交换，建立上下文 |
| 转折 | 慢 | 停顿/沉默 | 特写 | 情感沉淀，观众代入 |
| 爆发 | 极快 | 4-8 字 | 特写交替 | 冲突顶点，钩子植入 |
| 收尾 | 慢 | 1 句留白 | 特写定格 | 情绪余韵，引导下集 |

#### 9.3 实操提示
- **留白**：用 `（沉默两秒）` 或 `（手指轻敲桌面，三下）` 标注。
- **加速**：缩短句长 + 删除连接词 + 镜头快速切换。
- **减速**：插入动作描写 + 推镜头至面部 + 环境音效放大。

### 十、禁止模式清单

写作完成后逐项自检：

- [ ] **禁止连续 3 句超过 15 字** — 超过立即拆句。
- [ ] **禁止废话开头** — 删除"你知道吗"/"其实"/"说实话"/"我告诉你"等前缀。
- [ ] **禁止双长对白** — 两个角色不可同时连续说长句，必须短句轮替。
- [ ] **禁止解释性对白** — 不对白重复观众已通过画面知道的剧情。
- [ ] **禁止 OOC 台词** — 任何台词必须符合人物卡设定的性格/身份/口音。
- [ ] **禁止标签化情绪** — 不写"愤怒地说""悲伤地说"，改用微表情动作替代。
- [ ] **禁止静态对话** — 每 3 句台词间必须至少 1 个动作或运镜变化。
- [ ] **禁止说教台词** — 不借角色之口输出道理，道理藏进冲突和选择里。
- [ ] **禁止过度方言** — 单集同一方言词汇不超过 3 处。
- [ ] **禁止无意义寒暄** — 每句台词必须推动剧情、揭示人物、或制造冲突。

> **写作流程**：角色卡确认 → 场景清单（<=3）→ 分镜粗写 → 短句压缩 → 潜台词替换 → 微表情植入 → 禁止清单自检 → 输出

### 十一、特效描写规范（打斗场景激活）

当剧本出现打斗/动作场景时，按以下规则处理：

#### 11.1 特效标注格式

- 格式：`【特效：XXXXX】`（独立成行，不写在 `[ ]` 方括号内）
- 三段式结构：行动段（蓄力/位移/出招）→ 攻击段（命中瞬间）→ 受击段（受力点反应）
- **字数完全不计入单集总字数限制**，可充分展开物理细节
- 特效风格必须与角色背景一致（详见 2.10 VFX 特效描写）

#### 11.2 插入位置

```
△ **角色A**（蓄力）：台词...

【特效：角色A右脚后撤，靴底摩擦迸出火星。气浪呈放射状荡开，卷起碎石】

[特写]：角色A瞳孔收缩，虹膜浮现火焰纹理
```

### 十二、景别规范（强制）

#### 12.1 方括号 `[ ]` 内合法词汇（白名单）

仅限以下 13 种景别/运镜词：

| 类别 | 合法词汇 |
|------|----------|
| 基础景别 | 特写、近景、中景、全景、远景、空镜 |
| 角度 | 俯拍、仰拍 |
| 运镜 | 推、拉、手持晃动 |
| 特殊速率 | 快速剪辑、慢动作 |

#### 12.2 方括号 `[ ]` 内禁止词汇（黑名单）

以下词汇**绝对不可**出现在 `[ ]` 内：

【特效】【切至】【切换】【转场】【淡入】【淡出】【叠化】【划入】【划出】【硬切】【交叉淡化】【后期】【字幕】【配乐】【音效】【CG】【合成】

#### 12.3 特效/转场的正确写法

如需描述特效画面或转场，将特效内容写在画面描述中，方括号内保持景别不变：

| 错误写法 | 正确写法 |
|----------|----------|
| `[特效]：青白剑气自掌心迸发` | `[全景]：青白剑气自掌心迸发，脚下凝成虚幻长剑` |
| `[切至]：艾丽莎优雅落地` | `[近景]：艾丽莎优雅落地，高跟鞋踩碎岩石` |
| `[特效]：绿色气浪从脚底爆发` | `[全景]：绿色气浪从脚底爆发，校服衬衫被肌肉撑裂` |
| `[切换]：老赵重重落地` | `[中景]：老赵重重落地，双膝微屈，地面龟裂` |
| `[转场]：手机屏幕亮起` | `[特写]：手机屏幕亮起，一条新消息` |
| `[淡入]：晨曦中的城市` | `[远景]：晨曦中的城市，天色微明` |

## 2.2 长篇短剧（60-100 集）创作指南 — 大树生长法

> 适用：竖屏付费短剧 / 60-100 集长剧 / AI 辅助编剧流程
> 核心原则：**前十集定生死**，节奏第一，爽感驱动，每集必留钩。

### 一、100 集宏观结构（六段式）

| 阶段 | 集数 | 核心任务 | 关键产出 |
|------|------|----------|----------|
| 开篇期 | Ep1-10 | 快速建关系+核心矛盾，前3集首反转 | 角色锚定、付费卡一 |
| 升温期 | Ep11-30 | 矛盾升级+配角入场+感情线，每5集小高潮 | 关系网络、付费卡二 |
| 高潮期 | Ep31-50 | 核心冲突爆发+身份揭露+感情危机 | 真相揭露、爽点集中 |
| 转折期 | Ep51-70 | 大反转+反派暴露+命运逆转 | 明暗反转、情绪反转 |
| 冲刺期 | Ep71-85 | 终极对决+线索汇聚 | 终极对抗、伏笔回收 |
| 结局期 | Ep86-100 | 收束线索+圆满/开放式结局 | 情感闭环、结局设计 |

> 若总集数为 N 集，各阶段按比例缩放：开篇占10%，升温占20%，高潮占20%，转折占20%，冲刺占15%，结局占15%。

### 二、大树写作法 6 Phase 流程

#### Phase 0: 种子 — 灵感孵化
- **目的**：将原始灵感转化为可操作的创作素材
- **输入**：用户灵感词、参考剧、目标平台、受众画像
- **关键动作**：
  1. 脑暴发散：用「如果…就…」扩展灵感，产出20+情节点子
  2. 素材收集：同类爆款剧拆解（人设/冲突/卡点位置）
  3. 首问清单确认：题材？集数？男女主核心关系？结局走向？平台调性？
- **产出物**：灵感素材包 + 首问清单答案 + 3个备选故事核

#### Phase 1: 树根 — 强力开场
- **目的**：设计让人离不开的第1集，确定项目基线
- **输入**：Phase 0 选定的故事核
- **关键动作**：
  1. 设计 Ep1「3秒Hook」：视觉冲击/强冲突/悬念提问
  2. 确定前3集节奏：冲突入场→升级→第3集大反转
  3. 拍板：平台（抖音/快手/小程序）、集数、题材类型、单集时长
- **产出物**：Ep1-3 分集梗概 + 项目参数表

#### Phase 2: 树冠 — 终局锁定
- **目的**：先知道去哪，再规划怎么去
- **输入**：故事核 + 项目参数
- **关键动作**：
  1. 选择结局类型：大团圆/开放式/悲情救赎/爽感复仇
  2. 设计最终集情感落点：观众看完最后1集的感受是什么？
  3. 确定结局核心画面（一句话可描述）
- **产出物**：结局说明书（含情感落点+核心画面+类型）

#### Phase 3: 主干 — 骨架搭建
- **目的**：构建完整的故事骨架和人物弧光
- **输入**：树根（开场）+ 树冠（结局）
- **关键动作**：
  1. 男女主人物弧光：起点状态→转折点→终点状态
  2. 核心对抗设计：主线冲突（外部）+ 内心冲突（内部）
  3. 四幕结构划分：setup(1-25%) → 对抗(26-50%) → 危机(51-75%) → 解决(76-100%)
  4. 付费卡点规划：卡一/卡二/卡三的集数位置+钩子内容
- **产出物**：人物小传 + 四幕结构图 + 付费卡点方案

#### Phase 4: 分支 — 枝叶丰满
- **目的**：填充配角线、感情线、反派线，铺设草蛇灰线
- **输入**：主干骨架
- **关键动作**：
  1. 配角故事线：每人一条与主线交织的 mini 弧线
  2. 感情B线：误会→暧昧→确认→危机→修复 的五段式
  3. 反派线：伪装→小动作→暴露→疯狂→覆灭
  4. 草蛇灰线：每10集至少埋1条暗线伏笔
  5. 爽点密度图：标注每5集区间的爽点类型和数量
- **产出物**：全剧角色关系图 + Ep1-100 分集梗概（每集30-50字）+ 爽点密度图

#### Phase 5: 叶片 — 逐集精写
- **目的**：将梗概转化为可拍摄的逐集剧本
- **输入**：分集梗概 + 角色设定 + 爽点密度图
- **关键动作**（逐集循环）：
  1. 核心动作：本集谁做了什么？
  2. 场景设计：场景数量（每集3-6个）+ 场景情绪基调
  3. 情绪走势：标注本集情绪曲线（起→承→转→合）
  4. 结尾钩子：最后15秒的悬念/爆发/卡点设计
- **产出物**：逐集完整剧本（每集含场次表+台词+动作描述+情绪标注）

#### Phase 6: 土壤 — 打磨校验
- **目的**：确保全剧质量统一、爽点到位、逻辑自洽
- **输入**：完整初稿剧本
- **关键动作**：
  1. 台词打磨：删除说教，保留潜台词，每句有信息量或情绪
  2. 爽点密度检查：每5集至少2个爽点，卡点集爽点必须拉满
  3. 一致性校验：人物行为不OOC、时间线不矛盾、伏笔全回收
  4. 节奏审计：每集结尾是否有钩？前10集是否有3个反转？
- **产出物**：终稿剧本 + 质检报告

### 三、付费卡点设计

| 卡点 | 集数区间 | 核心钩子类型 | 常见设计 |
|------|----------|-------------|----------|
| 卡一 | Ep8-16（多数Ep10前后） | 身份即将揭露 / 重大抉择 | 「她就是我找了十年的恩人」 |
| 卡二 | Ep25-30 | 感情突破前夕 / 秘密揭晓 | 「原来你一直骗我」+ 一吻之前 |
| 卡三 | Ep45-55 | 核心真相大反转 / 终极抉择 | 身世真相 / 敌友翻转 / 生死抉择 |

> **缩放规则**：卡点位置按总集数比例调整。如80集剧，卡一约在Ep6-13，卡二Ep20-24，卡三Ep36-44。

### 四、单集节拍标准

```
开头(15秒):  承接上集悬念 / 新钩子抛出 / 冲突预览
中段(60-120秒): 冲突推进 → 小反转 → 打脸或升级 → 情感爆发
结尾(15秒):  新悬念抛出 / 情绪爆发点 / "未完待续"卡点
```

#### 单集检查清单
- [ ] 开头15秒能否让观众不划走？
- [ ] 中段是否有至少1个反转或打脸？
- [ ] 结尾是否有强钩子（悬念/情绪/冲突）？
- [ ] 本集是否推动了主线或感情线？
- [ ] 本集是否有至少1个可传播的金句或名场面？

### 五、循环推进机制

#### 逐集推进流程
```
上一集确认 → 输出本集梗概 → 编写本集剧本 → 自检 → 交付 → 下一集
```

#### 每集完成后回顾
1. **情节一致性**：本集与已写集数是否有矛盾？
2. **人物一致性**：角色行为是否符合人设弧光？
3. **节奏检查**：是否该加爽点？该留钩子的地方留了没？
4. **伏笔记录**：本集埋了哪些伏笔？需在后续哪集回收？

#### 长剧集一致性维护方法
- **人物档案卡**：每角色1张卡，记录核心动机、口头禅、关键行为模式，每5集对照一次
- **伏笔追踪表**：集数/伏笔内容/回收集数/状态（已埋/已收/废弃）
- **情绪地图**：每集标注主情绪色块，确保节奏有张有弛
- **卡点检查器**：写到卡点前3集时，提前拉满悬念密度

### 六、核心铁律

1. **前十集定生死**：前10集决定留存和付费转化
2. **Ep1铁律**：3秒Hook + 核心冲突入场（不让观众等）
3. **Ep2-3**：第一个大反转（证明"这剧有料"）
4. **Ep5-6**：第一个小高潮（建立观剧信心）
5. **Ep8-10**：卡一（第一个付费点，必须值）
6. **每集必留钩**：没有钩子的集数就是流失集
7. **爽点守恒**：每5集至少2个爽点，卡点附近爽点翻倍
8. **反转密度**：前30集每3集至少1个反转，后70集每5集至少1个反转

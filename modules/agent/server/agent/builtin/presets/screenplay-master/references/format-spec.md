## 2.6 短剧剧本格式规范参考手册

> screenplay-master SKILL 参考文件，用于指导 AI Agent 格式化中文短剧剧本。

### 一、单集剧本模板结构

```markdown
# 《剧名》第X集剧本

## 本集信息
- 核心冲突：[一句话概括本集核心矛盾]
- 钩子类型：[身份反转/误会揭穿/致命危机/情感极限/秘密曝光/打脸预备]
- 反转类型：[身份/立场/真相/感情/命运/无]
- 情绪标签：[虐/甜/燃/泪/惊/气愤，选1-2个]
- 场景数：[1-3个，超过3个需注明原因]
- 预估字数：[XXX字]
- 预估时长：[X分XX秒]
- 主要角色：[列出本集出场角色名]

## 场景1：[地点]/[子地点]-[时段]

【环境音效/氛围描写/人物着装等调度说明】

△ **角色A**（情绪/动作细节）：台词正文第一句。
△ **角色B**（情绪/动作细节）：台词正文回应。

[镜头类型]：[画面呈现描述，独立成段]

△ **角色A**（动作）：继续台词...

## 场景2：[地点]/[子地点]-[时段]
...

## 本集悬念结尾

[描述下集钩子，1-3句话，制造"必须看下一集"的期待感]
```

#### 场景要素格式速查

| 要素 | 格式 | 示例 |
|------|------|------|
| 场景编号 | `## 场景N` | `## 场景1` |
| 地点/时段 | 编号后紧跟，`-`连接 | `总裁办公室/落地窗前-夜` |
| 调度说明 | `【】` 包裹 | 【暴雨声，窗外电闪雷鸣】 |
| 角色台词 | `**角色名**（情绪）：台词` | **苏婉婉**（冷笑）：你以为这样就能威胁我？ |
| 台词标记 | `△` 前缀，接角色台词 | △ **角色名**（情绪）：台词正文 |
| 特效标注 | `【特效：…】` 独立成行 | 【特效：拳峰前方空气被压缩成透明碟状，以每秒450米的速度推进，目标面部皮肤已受气压影响开始凹陷】 |

#### 镜头类型速查

| 标记 | 含义 | 使用场景 |
|------|------|----------|
| 特写 | 面部/细节放大 | 情绪爆发、关键道具 |
| 近景 | 胸部以上 | 对话戏、微表情 |
| 中景 | 膝盖以上 | 双人对话、动作互动 |
| 全景 | 完整人物+环境 | 入场、关系建立 |
| 远景 | 大环境 | 氛围渲染、转场 |
| 空镜 | 无人物画面 | 时间流逝、情绪留白 |
| 快速剪辑 | 多画面快速切换 | 回忆闪回、信息轰炸 |
| 慢动作 | 降格镜头 | 关键动作、情感瞬间 |
| 俯拍 | 从上方拍摄 | 压迫感、全局展示 |
| 仰拍 | 从下方拍摄 | 威严、气势、威胁感 |
| 手持晃动 | 模拟手持摄影 | 紧张、纪实、混乱场面 |
| 推 | 镜头前推 | 情绪升级、聚焦关键 |
| 拉 | 镜头后拉 | 揭示环境、疏离感 |

**方括号 `[ ]` 内禁止词汇（黑名单）**：【特效】【切至】【切换】【转场】【淡入】【淡出】【叠化】【划入】【划出】【后期】【字幕】【配乐】【音效】。这些属于剪辑指令或后期制作标注，**绝对不可**出现在 `[镜头类型]` 位置。如确实需要标注特效需求，写在画面描述文字中而非方括号内。

- 正确：`[全景]：青白剑气自掌心迸发，脚下凝成虚幻长剑`
- 错误：`[特效]：青白剑气自掌心迸发`
- 正确：`[近景]：艾丽莎优雅落地，高跟鞋踩碎岩石`
- 错误：`[切至]：艾丽莎优雅落地，高跟鞋踩碎岩石`

#### 悬念结尾公式
**新信息/反转揭示 + 主角处境急转 + 观众想知道结果**

### 二、Fountain 格式说明（可选）

当用户明确要求时使用，默认采用 Markdown 格式。

| Fountain 标记 | 含义 | 示例 |
|---------------|------|------|
| `INT./EXT. 地点 - 时段` | 场景标题 | `INT. 咖啡厅 - 日` |
| 大写居中 + 空行 | 角色名 | `\n林墨\n` |
| 角色名下一行 | 对话内容 | `这不可能是真的。` |
| `(情绪描述)` | 括号标注 | `(颤抖着声音)` |
| `> 过渡指令` | 镜头过渡 | `> 切至:` |
| `[[注释]]` | 制作注释 | `[[此处需补拍反应镜头]]` |
| `Title:` / `Author:` | 标题/署名 | `Title: 《剧名》` |

#### Fountain 示例

```fountain
Title: 《闪婚总裁》
# 第1集

INT. 民政局 - 日

【熙熙攘攘的办事大厅】

苏婉婉
（慌张地看表）
这个男人怎么还不来？

> 切至:

EXT. 停车场 - 日

特写：黑色迈巴赫车轮急刹

顾景深
（摘下墨镜）
让我看看，我的新娘长什么样。
```

### 三、场次编号规则

#### 编号体系

| 层级 | 格式 | 示例 |
|------|------|------|
| 集编号 | 第X集 | 第5集 |
| 集副标题 | `[主题]` | `[身份揭穿]` |
| 场景编号 | 场景N | 场景2 |
| 完整标题 | 《剧名》第X集 - [副标题] | 《闪婚总裁》第5集 - [身份揭穿] |

#### 编号规范
- 集内场景从 **1** 开始顺序递增，不可跳号
- 同一地点不同时段视为不同场景，分别编号
- 新增场景接续现有最大编号，删除后不重新编号

#### 场景命名示例
```
## 场景2：顾家老宅/书房-夜
## 场景3：医院/走廊-日
## 场景4：医院/病房-日（接场景3）
```

### 四、制作可行性检查项

#### 场景与场地
- [ ] 所有场景在实际拍摄地点可实现
- [ ] 转场逻辑合理，不跨越不合理地理距离

#### 人员与预算
- [ ] 单集主要出场演员 <= 5 人
- [ ] 群演人数、服化道需求明确标注

#### 技术与特效
- [ ] 特殊效果/后期特效需求写在画面描述文字中，方括号内只写景别
- [ ] 打斗场景的【特效：…】标注格式正确，三段式完整（行动→攻击→受击）
- [ ] 特效风格与角色背景一致（古武/科技/异能/修仙等不混用）
- [ ] 夜景戏数量合理（考虑灯光成本）

#### 字数统计规则
- [ ] 单集总字数 = 所有角色台词字数 + 调度说明字数 + 镜头指示字数
- [ ] **【特效：…】标注内容完全不计入总字数**，可充分展开描写
- [ ] 字数计算公式：`台词字数`（不含标点和括号）+ `【】内文字字数` + `[ ]内画面描述字数`

#### 节奏与格式
- [ ] 台词时长与预估时长匹配
- [ ] 高潮段落位于集末 30% 区间
- [ ] 本集信息头部完整、悬念结尾清晰

### 五、常见格式错误与修正

| # | 错误类型 | 错误示例 | 正确写法 |
|---|----------|----------|----------|
| 1 | 场景缺少时间标记 | `## 场景1：咖啡厅` | `## 场景1：咖啡厅-日` |
| 2 | 台词未标注说话角色 | `你以为你是谁？` | **苏婉婉**（冷笑）：你以为你是谁？ |
| 3 | 台词缺少△标记 | **角色**：台词 | △ **角色**（情绪）：台词 |
| 4 | 缺少本集信息头部 | 直接从场景开始 | 补全 `## 本集信息` 区块 |
| 5 | 场景超3个未标注 | 出现场景4无说明 | 场景4需注明`（补充场景）` |
| 6 | 悬念结尾缺失 | 直接结束 | 补写 `## 本集悬念结尾` |
| 7 | 角色名格式不统一 | `苏婉婉` / `婉婉` / `苏小姐` | 全文统一使用 `**苏婉婉**` |
| 8 | 调度说明括号错误 | `[暴雨声]` | 【暴雨声】 |
| 9 | 台词标记符号错误 | ★ 角色 | △ **角色** |
| 10 | 情绪标签超2个 | 虐/甜/燃/惊 | 虐/燃（最多2个） |
| 11 | 方括号内使用非景别词 | `[特效]：剑气迸发` / `[切至]：角色落地` | `[全景]：剑气迸发` / `[近景]：角色落地` |
| 12 | 混淆剪辑指令与景别 | `[切换]：` / `[转场]：` / `[淡入]：` | 用空镜/全景/快速剪辑替代 |
| 13 | 特效标注格式错误 | `[特效]：剑气迸发` 或 `【剑气迸发】` | `【特效：剑气自掌心迸发，脚下凝成虚幻长剑】` |
| 14 | 特效计入字数导致超标 | 因担心字数限制而缩写特效描写 | 特效字数**不计入**总字数，按三段式充分展开 |
| 15 | 特效风格与角色不符 | 古武角色使用"HUD充能界面""激光束"等科技描述 | 古武用罡风气浪，科技用能量管线，不混用 |

### 六、格式快速参考卡片

```
场景头：     ## 场景N：地点/子地点-时段
调度说明：   【音效/氛围/服化道】
台词标记：   △ **角色名**（情绪/动作）：台词正文。
镜头指示：   [景别]：[画面描述]（景别仅限：特写/近景/中景/全景/远景/空镜/俯拍/仰拍/推/拉/手持晃动/快速剪辑/慢动作，严禁使用特效/切至/切换/转场等剪辑指令）
特效标注：   【特效：…】独立成行，三段式（行动段→攻击段→受击段），不计入总字数
悬念结尾：   ## 本集悬念结尾 + 下集钩子描述
```

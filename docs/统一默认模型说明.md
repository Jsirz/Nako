# 统一默认模型

在画布打开「设置 → 闭源服务」，顶部的「默认模型」区域提供文本、图像、视频、音频四个选择框。先配置模型来源，再选择默认模型；每次选择都会自动保存，显示「已保存」后生效。若刚完成本地 CLI 登录，可点击「刷新默认模型选项」。

## 使用规则

- 已有明确选择优先。空白或未传入模型时才使用对应类型的默认值；模型名包含来源，避免同名模型跨来源路由。
- Agent 未选择具体模型时使用默认文本模型。模型菜单中的「使用默认文本模型」可恢复跟随设置。
- 新建画布节点采用仍在候选目录中且已配置的当前默认模型并记录在节点中；失效默认值不写入新节点，提示选择模型，原设置保留供用户修正。后续更改默认值不修改已有节点；没有记录模型的节点在准备生成时解析默认值。
- 四类生成 API、Agent 对话与上下文压缩、提示词优化、图像描述、Drama 文本规划及分镜请求共享解析服务。显式设置的 `GLM_PROMPT_MODEL`、`STORYBOARD_TEXT_MODEL`、`STORYBOARD_IMAGE_MODEL` 仍属于特定操作的明确选择；未设置这些变量时使用统一默认模型。
- 不会自动选择目录第一项。默认值未设置时提示选择；默认来源撤销密钥、插件停用或模型不可选时保留原设置并提示修正，不自动换模型或来源。
- 模型能力限制继续生效，例如纯文本模型不因设为默认就支持图片理解。
- 全景图与角度图生成同样使用当前默认图像模型，不再优先豆包；默认值须已配置并支持图生图及图片输入，否则提示重新设置，不自动切换其它模型。生成按钮提示随默认设置更新，已创建的节点仍保留自己的模型选择。

## 服务与存储

`modules/contracts/defaultModels` 定义媒体类型、设置快照和服务接口。`module.identity-account` 将现有偏好存储适配器注册为 `preferences.repository`；`module.generation` 注入该存储适配器和现有来源可用性服务，注册 `generation.defaults`。

本机 `preferences.json` 的 `values["generation.defaultModels.v1"]` 保存四类模型名称，不保存密钥。原子写入与写入队列由偏好存储适配器负责；默认设置更新也串行执行，防止不同媒体类型的并发修改相互覆盖。

本地 API：

| 接口 | 行为 |
| --- | --- |
| `GET /api/generation/default-models` | 返回 `defaults` 和按类型分组的 `candidates`；候选仅含名称、配置状态 |
| `PUT /api/generation/default-models` | 部分更新，例如 `{"text":"GLM-5.3-Flash · 移动云"}`；空字符串清除该类型默认值 |

浏览器的 `ui.generation-core` 注册同名客户端服务。消费者通过 kernel 服务注册表读取，不增加 Window 全局接口，不直接访问 Provider 或文件系统。设置页保存失败会恢复此前选择；读取与保存请求串行，避免较旧读取覆盖新设置。

## 执行一致性

默认值在准备生成请求时转为具体模型，随后进入原有预算、配置签名、任务登记和操作回执流程。待确认批次记录具体模型；用户确认时即使默认值已修改，仍按该批次记录执行，并继续校验节点、输入和请求参数是否改变。恢复任务不会重新套用默认模型，历史任务不会因此重跑。

## 验证

新增测试覆盖本机保存恢复、并发更新、类型不匹配、缺省与失效默认值、显式选择优先、四种 HTTP 生成请求的任务模型与 Provider 参数、Agent HTTP 到 pi 适配器、提示词和 Drama 生成器、画布节点和请求、确认后更改默认值、设置页失败回退。所有模型响应均为测试替身，无真实付费调用。

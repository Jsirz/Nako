# 官方预设与用户自定义技能

技能管理分为“官方预设”和“用户自定义”两个来源页签。默认展示官方预设，切换页签重置分类和搜索；导入完成后自动显示用户自定义。详情显示来源，两类技能都可以选择并使用，选择本身不会发送对话或触发生成。

官方预设直接读取当前安装应用的 `modules/agent/server/agent/builtin`，不复制到用户数据目录。现有受控“剧本文戏”和“打斗武戏”位于 `builtin` 下对应目录，普通官方技能放在 `builtin/presets/<目录名>/`。管理页、首页、Agent 选择器和斜杠命令共用 `agent.skills` 服务。

## 版本更新与管理

- 发布新版本时，将更新后的官方目录随应用打包；用户更新并重启应用后，官方名称、简介、分类、正文、参考及封面使用新版本内容。
- 官方新增目录出现在所有用户的官方预设中，发布移除的目录不再提供；用户过去的隐藏或分类记录不覆盖当前官方内容。
- 官方技能不能由用户修改分类或删除，对应后端接口返回 403。管理卡片保留分类筛选、搜索及详情，不提供分类编辑或删除控件。
- 普通官方技能的调用标识以 `preset-` 开头，由目录名生成；中文等目录名使用 SHA-256 摘要。修改正文、名称或简介不改变标识，重命名目录视为移除旧技能并新增技能。
- 用户导入始终独立保存为 `source: 'local'`，目录为 `users/<用户标识>/private/agent-skills/<slug>/`，与用户项目共享，不写入项目或 Codex 技能目录。
- 同名用户导入分配独立标识，不继承官方展示信息、指令或封面；用户导入名使用官方保留前缀时转换为 `custom-` 标识。官方更新不会写入或删除用户导入文件。
- 过去自动复制且含 `presetId` 的预设副本不再进入技能列表，保留其磁盘文件；不再使用或生成 `preset-state.json`。用户主动导入的技能继续独立展示。
- 用户技能初始化目录、导入、分类修改和删除沿用共享队列；官方目录读取不写入用户目录。历史会话选择的旧标识不自动转换或重放任务，需重新选择当前技能。

## 中文展示信息

每个预设及官方制作技能目录使用 `metadata.json` 提供展示名称、简介与分类。`SKILL.md` 的 `name` 用于生成普通导入的调用标识，原 `description` 与正文保留任务触发和执行说明。例如：

```json
{
  "name": "中文影视编剧助手",
  "description": "辅助完成角色塑造、对白打磨和剧本修改。",
  "category": "文本创作"
}
```

官方目录每次读取同目录的 `metadata.json`，提供展示信息；指令使用该目录的 `SKILL.md` 和显式参考清单。用户导入优先使用上传的 `metadata.json`，缺少时使用 `SKILL.md` frontmatter；存储服务生成本地 slug、source、fileCount 等字段。元数据不能授予官方身份或受控执行权限。

可在导入界面编辑用户技能名称和简介。开发环境直接读取工作区的官方目录；安装版必须重新发布并更新应用，才会使用新版本的官方内容，不在后台独立下载技能文件。

当前技能描述详细说明适用场景、输入要求、流程、交付内容和使用边界，每项不少于 100 个汉字。`description` 可包含换行，详情页按段展示；最大长度为 4000 字符，由公共协议常量统一约束，卡片及快捷列表只显示摘要。

## 参考文件与边界

普通官方技能需要附带参考时，在源目录的 `agent-skill.json` 中显式列出 `instructionReferences`，不再在用户副本自动生成。`deepwhite-screenwriting-v1` 已声明其参考与模板。选中技能时，现有指令加载器读取根 `SKILL.md` 和清单中的文本文件；没有清单则只加载根说明。当前采用整份加载，大型技能会增加本轮上下文用量。

Python 等脚本、图片及 YAML 附带文件不作为文本参考执行或自动上传。路径不能越界，链接不能作为预设输入。技能内容仅为提示上下文，不能取代工具权限、预算授权及操作回执。

两项现有受控业务技能（剧本文戏、打斗武戏）仍使用原有专用流程，身份由 contracts 的 `officialProductionProfiles.js` 定义。普通预设虽然显示为官方来源，但只作为 Agent 指令，不获得这些专用流程的执行权限。

# 用户级 Skill 预设

`modules/agent/server/agent/builtin/presets` 是随应用分发的只读模板源。`storage.agent-files` 激活时将其中 15 个技能文件夹初始化到当前用户的 `private/agent-skills/<slug>/`。配置多用户目录时，路径为 `users/<用户标识>/private/agent-skills/`；与同一用户的项目共享，不写入项目目录或 Codex 技能目录。

初始化完成后，管理页、对话选择器和斜杠命令均通过现有 `agent.skills` 服务读取用户副本。新条目为普通本地 Skill，不获得专用业务流程权限。

## 初始化与管理

- 复制根 `SKILL.md`、参考、模板、图片及其他附带文件，源文件不修改。
- 多行 `description` 正常解析；预设按文本创作、图像设计、视频制作分类，可在管理页修改。
- 不覆盖同名用户文件；冲突时分配独立标识。`presets/minimax-drama-prompt` 默认使用 `minimax-drama-prompt-2`，与绑定受控业务流程的“剧本文戏”区分。
- 已有用户副本不随上游变化被覆盖。`preset-state.json` 记录已初始化的目录标识，删除后记录保留，重启不恢复。
- 每个用户独立初始化；新版本新增目录只为尚未初始化该目录的用户补入，不覆盖旧副本。
- 不恢复“添加预置”或恢复接口。删除后如需重新使用，可通过现有文件夹导入功能导入原模板。
- 同一进程内，同一用户的初始化、导入、分类修改与删除使用共享队列。文件已复制但初始化记录未落盘时，重试识别副本并补记，不重复复制。损坏的初始化记录明确报错，不静默清空。

## 中文展示信息

预设 `SKILL.md` 的 frontmatter 使用 `display-name` 和 `display-description` 提供中文展示名称与简短简介。`name` 继续用于生成稳定的调用标识，原 `description` 与正文保留任务触发和执行说明。例如：

```yaml
name: mj-asset-prompt-builder
display-name: Midjourney 资产提示词助手
display-description: 编写、优化和翻译角色、道具与场景的图像提示词。
description: 原始技能用途与触发说明
```

导入和首次初始化时优先使用展示字段。已初始化的用户预设通过 `presetId` 读取随应用发布的展示字段；仅替换仍与原默认值一致的名称或简介，不写回用户元数据，不覆盖自定义文字，不恢复已删除条目。首页、Skill 管理、详情和 Agent 选择列表共用同一技能服务结果。

普通导入条目不会因名称相同而继承预设文案；可在导入界面编辑中文名称和简介。安装版需重新打包并安装才能应用新的预设文案与读取逻辑。

## 参考文件与边界

没有 `agent-skill.json` 的预设会在用户副本中生成显式文本参考清单，包含 `reference/`、`references/`、`templates/`、`assets/` 下的 Markdown 或文本文件。已有清单保持原样。选中技能时，现有指令加载器读取根说明和这些参考文件；当前采用整份加载，大型技能会增加本轮上下文用量。

Python 等脚本、图片及 YAML 附带文件完整复制，但不作为文本参考执行或自动上传。路径不能越界，链接不能作为预设输入。Skill 内容仅为提示上下文，不能取代工具权限、预算授权及操作回执。

三项现有受控业务 Skill（剧本文戏、高配剧本文戏、打斗武戏）仍使用原有专用流程；本次新增用户级模板不改变它们的执行协议。

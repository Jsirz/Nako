# 插件契约收敛与旧代码清理

时间：2026-09-17。依据《开发文档.md》《条件约束文档.md》实施；未修改《开发设计文档.md》。未删除、转换或改写真实用户数据。

## 五项收敛

1. **插件宿主**：contracts 统一验证 manifest 与 descriptor，kernel 校验生命周期函数、依赖版本、声明式服务访问和双重凭据授权。每次激活捕获独立 AbortSignal，关闭后旧 context 不因重新激活而恢复权限。保留 reloadRequired 和活动调用计数。
2. **生成 Provider**：公共类型改为 descriptor + handler；按 image/video/audio/text 发布方法。缺少生成方法或恢复方法不成对时拒绝激活。插件内部对象不被复制到公开 handler。密钥按 manifest.id 从宿主凭据服务读取，普通来源配置也不再回退到调用方参数。
3. **工作流**：公开 canExecute/execute/resume/retryInputCleanup/markRecoveryInputsOrphaned/markInputsOrphaned/cleanupInputs；按 runtimeKind 判断。createClient 仅发布 contracts 的白名单，保留工厂、客户端、执行器均在关闭后拒绝使用。取消由执行请求的 AbortSignal 传递。
4. **模型目录**：清单中的插件身份、路径、导出、Provider/kind 全部校验；catalog.ts 仅能导入清单登记的模型数据。构建允许模型文件及同目录纯协议常量文件，拒绝内部实现、第三方包和平台外部依赖，再生成浏览器目录与服务端快照。
5. **媒体适配器**：mediaAssetRouter、mediaLibraryRouter、mediaDownloadRouter 仅翻译 HTTP；文件操作在 media.filesystem 内。media.ffmpeg-sharp 提供处理/编辑能力。架构脚本禁止媒体 Router 导入 fs/path/child_process。

## 已删除的旧版本分支

- Provider catalog 的两层旧路径转发文件及 exports 别名，调用方统一公开 providerRegistry。
- 任务日志从公共库自动迁移的逻辑、旧数组格式别名；当前格式为私有目录 `{version:1,tasks}`，保留原子写入与中断恢复。
- SQLite 启动时自动导入旧项目 JSON、旧 folders.json；删除未被引用的用户目录迁移模块。
- 旧 RunningHub 独立设置面板及其 UI 客户端方法；当前 Provider 配置与工作流部署接口仍使用宿主服务。
- 生成路由的旧 RunningHub 模型显示名别名、安装状态中的废弃 legacyState 字段、无发送方的旧 Drama 事件。
- 文本节点从 prompt 自动迁移到 textContent 的分支、旧“仅输入文字”模型标识。
- MiniMax 旧画布端口自动迁移、旧模型 ID 回执恢复分支。身份不匹配的回执返回 unknown，不查询、不重新提交；规范回执的恢复与凭据校验保持。
- Agent 图片的裸 Base64 后备格式；当前图片使用 URL 或带 MIME 的 data URL。
- 旧 `/api/assets/:type` JSON Base64 POST，调用方改走统一二进制上传，保留项目与提示信息。删除旧全局媒体目录列表和删除回退。
- 两条无调用方的 `/api/upload-tos/:type`、`/api/upload-existing-to-tos`；模型内的上传能力仍由 Provider 提供。现用 URL 校验入口保留并经过外部 URL 策略。
- 原 legacyLibraryRouter 文件，当前素材库及工作流预设功能转为插件存储操作，未删除功能。

## 保留范围与原因

- RunningHub `legacy-webapp-v1`、Anima 节点适配是仍在使用的第三方协议；媒体播放转换也不是本项目版本兼容，保留。
- SQLite 当前 schema 升级、损坏隔离、任务恢复、输入清理、预算授权、操作回执、防重复提交和版本冲突检查继续有效。
- 本机 ComfyUI 内置执行入口、已有不支持节点的只读提示仍有实际调用。提示防止把旧节点误当作其他模型执行，不运行旧算法，也不自动迁移数据。
- 浏览器现有 `Window.__NAKO_*` 声明仍作为类型索引，运行值保存在 kernel 注册表中。此次没有宣称已重写整个浏览器服务类型系统。
- `.env` 配置导入、官方/用户 Skill 名称隔离及第三方 CLI 输出解析仍服务当前能力，不按 `legacy` 关键词批量删除。

旧格式不再自动导入。历史更新/验证记录属于审计记录，保留原文；当前接入约定以《开发文档.md》和《插件开发说明.md》为准。
